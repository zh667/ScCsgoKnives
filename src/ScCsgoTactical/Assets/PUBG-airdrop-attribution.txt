Converted FBX to the game's static GLB format, transformed coordinates, normalized
the crate to a 0.98-block maximum extent and converted UV origin. Original color
texture bytes are preserved. The original normal texture is retained in the source
archive; the existing game static-mesh renderer does not evaluate normal maps.
This download contains no smoke texture or particle system.

# 0.41.0 — 动物听觉、树叶破坏与装配台改版

## 原版依据与范围

- 原版 `SubsystemMusketBlockBehavior` 成功开枪时，除了播放火枪音效还调用 `SubsystemNoise.MakeNoise(position, 1f, 40f)`。噪声是 AI 事件，不是音频文件。
- `ComponentRunAwayBehavior.HearNoise` 在 loudness >= 1 时记录噪声来源；`ComponentFlyAwayBehavior` 在 >= .25 且 AffectedByNoise 时转入危险状态；牛群行为也有自己的响应。接入原生听觉而不是强制覆盖所有生物 AI：没有逃跑行为的生物、正在执行更高优先级行为的猛兽不保证立刻逃跑。
- `Projectile.OnHitTerrain` 对速度大于 10 的投射物比较随机值与命中方块的 GetProjectileResilience，满足条件后调用 DestroyCell(0,x,y,z,0,true,false)。原生多数树叶 ProjectileResilience=.5，所以约一半命中会破坏，不是每枪必碎。
- TACZ 参考：已有 `reference/TACZ` 源码及用户指定 1.1.8-hotfix JAR 的 GunSmithTableScreen（用 CFR 单类反编译核对）。其分类标签、配方列表、独立预览、材料清单和固定制造区作为布局参考；未复制或分发它的代码、贴图或 Minecraft 资源。

## 枪声与动物

- **现有 CS2 枪声音频和播放调用保留，绝不替换为原版火枪声。** 与 0.40.9 逐项比对全部 377 个 Audio 资源，SHA256 全部一致。
- 只有扣弹成功的 Fire 才发送噪声，每次扣扳机一次（霰弹不是每颗弹丸一次）。空枪、事务失败、浏览武器或检视不发送枪声 AI 事件。
- 普通枪 loudness=1 / range=40 格，消音枪 loudness=1 / range=12 格，电击枪 loudness=.5 / range=6 格。消音器缩小惊扰范围，不把 loudness 降到地面动物永远听不到的阈值以下。
- 创造、生存共用同一成功开枪路径，没有只给一个模式接线。动物保留自身听觉/逃跑/飞行/追击优先级规则。

## 子弹破坏树叶

- 子弹仍穿过草、花与树叶，不切回原版实体弹丸系统。射线只读收集命中的树叶格子和距离；确定最近命中动物/墙体后，仅处理实际弹道终点之前的叶子。
- 使用原版 ProjectileResilience 概率与 DestroyCell 标志（不掉落物，显示破坏碎屑）。电击枪不剪树叶。
- 只针对 LeavesBlock；不误删树干、墙体、普通草皮土块，也不扩大到邻居或整个树冠。草、花仍仅穿透。
- 同一扣扳机对一个叶子格最多尝试一次，霰弹不会对同一格反复刷概率；执行前复核该格仍是刚才检测的值。叶子专用随机源不改变枪械散布随机序列。
- 保留真实击中路径的限制：动物身后、墙后、最大射程以外的树叶不会被此发子弹破坏，不强制加载区块。

## 武器装配台

- 主选择页：横向可滚动分类标签，滚动武器/功能列表，独立预览图标，材料图标和“需要 / 持有”数量。原有 35 枪、22 刀具及维修/换肤/计数器/属性入口保留。
- 宽屏三列；普通宽度将预览放在右上、材料右下；窄屏列表和材料分别滚动。极矮窗口优先隐藏预览，保证列表、材料与操作按钮仍可用。
- 保存制作需求的逻辑不变，预览是只读。“下一步”打开精确报价确认，最终“组装/维修/更换/安装”才执行原有事务；确认只能触发一次。
- 所有工作台长确认框（包括维修、皮肤、计数器规则）改成固定边界、滚动文本、底部固定操作按钮。80 行说明也不会把按钮推到屏幕外。
- 选择页和确认页的回调继续核对玩家存活、距离、装配台仍存在、背包及报价修订号；材料不足、空间不足、状态变化仍由原有事务拒绝/回滚。
- 预览使用当前模组已有 BlockIcon 资源；本轮没有增加 TACZ 式自由旋转 3D 检视器，也不引入 Minecraft 素材。

## 检查与交付

- 原生 SubsystemNoise → 地面逃跑监听、鸟类 DangerDetected、消音范围及远处不响应；不靠手写“应该逃跑”判定替代。
- 原生地形射线布置树叶→目标→树叶→墙→树叶，检查只破坏目标前的叶子、原版销毁标志、一次性处理、树干保留及抗性概率。
- 实际 Fire IL 检查：噪声调用在 Commit 后；树叶处理在 TraceBullet 后；CS2 PlaySound 仍存在。
- 创造/生存两类界面上下文、6 组逻辑尺寸（包括 850×270 矮窗口）；全部 57 配方逐个选择，列表/材料/操作区边界，步枪分类，80 行滚动报价和确认只执行一次。原有制作、维修、皮肤、计数器与 0.28.2 迁移回归继续运行。
- 使用用户 Windows 游戏目录引擎 DLL 的额外离线检查：`output/0410-installed-engine-check.json`。Full/Lite 最终包检查：`output/ScCsgoKnives-0.41.0[-Lite]-check.json`。
- 尚需实机验收动物寻路逃离效果、树叶碎屑、手机多指/长列表和界面实际观感；离线检查不是实机截图。
- 不启动或改写玩家世界；只在玩家更新后成功射击时按新增规则破坏叶子。未改变物品布局 v5、记录 schema 3、型号顺序、已有击杀/皮肤/等级或制作材料。用户既有未提交文案、UI 断点与皮肤规划保留。

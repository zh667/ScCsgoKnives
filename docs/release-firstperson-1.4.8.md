# 第一人称角色手臂与手套 — Full 1.4.8 / 战术拓展 1.3.0

选择 CT SAS 或 T Phoenix 玩家外观后，CS 第一人称武器使用该角色的手臂、袖子和默认手套。未选 CS 角色且未设置手套时，保留本体原来的第一人称手臂。角色选择仍走 NekoMeko 原有入口；没有修改 NekoMeko 或 Neorxna 的包。

## 使用

- 安装本体 `[API1.9]CS武器1.4.8-作者ZH667-全量版.scmod` 和 `[API1.9]CS战术同伴拓展1.3.0-作者ZH667.scmod`，不要与旧版本重复启用。
- 在 **枪械台 → 人物外观 → 更换第一人称手套** 选择手套，选择“跟随角色默认手套”可恢复默认。该外观操作免费，生存和创造均可用，不增加物品 ID 或制作配方。
- 五款为运动手套｜树篱迷宫、运动手套｜潘多拉之盒、专业手套｜深红和服、运动手套｜迈阿密风云、驾驶手套｜深红织物，均采用源资源定义的最低合法磨损 **0.06（崭新出厂）**。
- 手套选择随世界按 PlayerIndex 保存，各玩家独立；切换角色会切换袖子，并保留所选手套。不选 CS 角色也可以单独使用手套。
- 角色更换仍需 NekoMeko Model 1.1 与 Neorxna 1.4。仅使用战术功能或五款手套不需要这两个外观提供方，也不需要额外手套包。

## 实现范围

本次覆盖 CS 枪械、刀、投掷物、C4、防爆盾和空手的第一人称显示。手臂沿用当前武器动作，保留原动作时间和枪械位置。空手采用适配姿态与原有手部摆动；投掷物或 C4 离开槽位后，等待仍在显示的动作结束再切换空手，防止叠加。

原生及其他模组的手持物仍走其原有显示路径。新增手套暂不替换玩家或同伴的第三人称手套。没有新增联机传输逻辑；玩家隔离和分屏数据检查不等同于实际联网验证。

CT/T 袖子、默认手套和三类手套网格分别保留自己的骨骼表、逆绑定矩阵与权重；Phoenix 上臂扭转辅助骨骼由当前动作适配。外观提供方缺失或没有选择时，本体可以独立使用；手套数据缓存在世界卸载时清理。

## 素材与重建

素材取自本机 CS2 `game/csgo/pak01_dir.vpk`，合成着色器取自 `game/csgo_core/shaders_vulkan_dir.vpk` 的 `csgo_customglove`。使用 Source2Viewer 20 导出，并将反射所得 GLSL 适配到离线渲染器；不修改原始游戏资源。导出角色 GLB 时必须携带 skin 元数据：使用 `--gltf_export_animations --gltf_animation_list glove_export_bind_only`，不能猜测默认手臂的关节编号。

生成脚本为 `tools/build_appearance_assets.py`。通过 `./tools/dev.ps1 python -X utf8 tools/build_appearance_assets.py --help` 查看参数；`--stage` 提取依赖，`--audit-only` 仅刷新审计信息。依赖提取器及源游戏安装不随 Git 分发，最终运行所需派生素材已包含在战术包内。

五款涂装使用原合成器的材质层、图案、磨损、法线和 ORM，输出 1024 纹理；左右手分别合成。图案偏移固定为 (0,0)，保留配方旋转，不声称等于经济系统某个编号模板。袖子与角色默认手套粗糙度使用 0.7 的适配估值，因此不宣称与 CS2 光照逐像素一致。源及产物哈希、磨损与网格记录见 `firstperson-gloves-assets.json`。

## 一、SCAR-20 / G3SG1 每打一发就退镜

视频 0–13 s：开镜射击，弹数 20→19 时遮罩消失半秒再回来，每发如此。

根因：0.19.0 起所有镜枪照 AWP 的做法——开镜射击就 `LeaveScope`，循环时间后再回镜。CS2 的 vdata 里这是
一个开关 `m_bUnzoomsAfterShot`：AWP、SSG 08 为 true，SCAR-20、G3SG1、AUG、SG 553 为 false。

修法：`cs2_weapons.py` 读出这个字段，`GunSpec` 新增 `UnzoomsAfterShot`（两把栓动为 true，其余四把 false），
`Fire()` 只在它为 true 时退镜。驱动脚本 `cs2_add_gun.py` 以后自动写入。自检 `gun/<gun>/scope.unzoom`
逐把对照 vdata。

## 二、AUG / SG 553：手臂透明、开镜不像 CS2、开镜射击回原倍率

视频 13–24 s（AUG）、31–39 s（SG 553）。三个现象三个原因：

1. **手臂发白透明**（14 s 帧最清楚）。镜片在 0.20.0 里走 `TexturedBatch3D` 叠加混合画，刷新后
   `Display.BlendState` 留在 Additive；`KnifePbrRenderer` 只设深度和裁剪状态不设混合，紧接着画的手臂
   就成了叠加混合——只有带镜片的这两把枪出这个问题。修：PBR 与 `DrawModel` 每次显式 `BlendState.Opaque`。
2. **镜片是个白盘**。0.20.0 把 CS2 的瞄点贴图 `scope_dot_white_color` 铺在镜片三角形上叠加画。查材质：
   - 镜片 `shared_scope_lens.vmat`：`csgo_weapon.vfx`、`F_TRANSLUCENT`，颜色 = `shared_scope_lens_mask` × 0.157，
     金属度 1、粗糙度 0.078，**`g_flOpacityScale = pow(1 - $ent_ironsight, .5)`**——平时是一片深色镜面玻璃，
     开镜后完全透明。
   - 瞄点 `scope.vmat`：`ui.vfx`——是 **HUD 元素**，不在模型上（`body_hd` 只有 `weapon_rif_aug` 和
     `shared_scope_lens` 两个材质，没有点）。
   修：`tools/cs2_scope_lens_texture.py` 按 vmat 烘 `cs2_scope_lens`（mask×0.157）、`_orm`（AO=mask、粗糙 20、
   金属 255）、`_normal` 三张，镜片在手臂之后走 PBR 画，开镜时不画；瞄点改成屏幕中心的 2D 叠加精灵
   `DrawScopeDot`，原生准星同时隐藏（CS2 开镜没有准星）。**瞄点大小是估计值**：导出里没有 panorama 布局，
   取 40/1080 屏高（亮核约 14 px），`ScopeDotScreenFraction` 一处常量。
3. **开镜射击变回原倍率**：同第一条，AUG / SG 553 的 `m_bUnzoomsAfterShot` 也是 false。修好后开镜射击
   用 `ironsight_shoot`，镜不退。

## 三、R8 左键射击手臂糊到脸上

视频 45.3–47.0 s 逐帧（20 fps）：点击后 0.5 s 整屏肤色，然后才是射击后坐。0.5 s 正是 `prepare_shoot` 的时长。

根因：`prepare_shoot_revolver.vnmclip` 是 **`m_additiveType = "RelativeToFrame"`、基准 `FirstFrame`** 的
叠加型片段——DMX 里存的是相对自身第 0 帧的增量（第 0 帧每根骨都是单位），CS2 在 animgraph 里把它加到
当前姿态上。转换器把它当完整姿态读，手骨平移全 0，整条手臂坍缩到相机上。全部 35 把枪 + 22 把刀里
这种片段有 14 个：R8 的 prepare_shoot 和 8 个 chamber_position、M249/内格夫/XM1014 的 bullet_hide、
M249/内格夫的 idle_from_activity——我们只用了 prepare_shoot 这一个。

修法：
- `cs2_gun_rig.py` 读 vnmclip 的 `m_additiveType` / `m_additiveBaseFrame`，写进 JSON（`Additive`、
  `AdditiveBase`、`AdditiveOver = "idle"`——叠在哪个片段上是我们的选择，CS2 叠在当时正在播的姿态上，
  这里取同一时刻的 idle）。曲线数据不动。
- `Cs2Rig.Sample`：叠加片段按"当前值 ⊖ 第 0 帧值"取增量（反编译在 root_motion 和 wpn 上写的是静止
  旋转而不是单位，直接当增量会把整条手臂转 120°，第一版自检就是这么抓到的），旋转在骨骼局部系先乘
  增量再乘基准，平移相加。
- 自检 `rig/<gun>/<alias>.additive`：叠加后 hand_R 离原点 >1 in、与 idle 偏差 <2 in、且有骨在动。
  结果：hand_R 13.56 in、偏差 0、弹巢 cylbullet3 转 0.48 in。

## 四、电击枪不回电、没有射击特效

### 回电

逻辑本来有（`RechargeAt` 30 s），但它只存在每局的内存状态里：存档重进、状态重建后一把 0 电的 Zeus
再也没有计时器，永远空着。视频 57 s 起 Zeus 一直是 0/∞，符合这个情况。

修：状态里没有计时器而电量不满时就起一个（最坏多等 30 s）；空电按左键或 R 显示"充能中，还要 N 秒"
（新语言键 `Recharging`）而不是没反应。30 s 仍是估计值（CS2 的 vdata 里没有）。

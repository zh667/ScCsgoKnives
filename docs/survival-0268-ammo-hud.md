# 0.26.8 弹药显示按真实资源分类

## 原因

旧的 zh-CN/en-US Message.Ammo 都写死为 `{0} / ∞`，射击、切枪和装填时直接弹出；没有读取生存背包。这导致画面误以为有无限备用子弹，也掩盖了通用弹匣和逐发霰弹的区别。

## 新显示

持枪时在原版底部状态栏上方显示一个只读小面板，两行文字，跟随底部布局和 UI 缩放；不接收鼠标/触摸，不增加操作按钮。原版消息区继续保留给正常游戏提示。切到其他物品、死亡、打开菜单/背包时隐藏，玩家离开和世界关闭时移除。

| 类型 | 示例主行 | 次行与规则 |
| --- | --- | --- |
| USP-S 等普通弹匣枪 | 3 / 12 发 · 弹匣 ×3 | 整匣更换 ×1 弹匣 · 丢弃余弹 |
| P90/野牛、机枪 | 枪内弹量 / 容量 · 弹匣 ×实际数量 | 每次分别消耗 2、M249 消耗 3、内格夫消耗 5 个通用弹匣；按现有配方规则显示 |
| Nova、XM1014、截短霰弹枪 | 3 / 8 发 · 霰弹 ×16（容量依型号） | 逐发装填 · 保留余弹 |
| MAG-7 | 3 / 5 发 · 霰弹 ×16 | 整匣更换 ×5 霰弹 · 丢弃余弹 |
| 电击枪有电 | 电击枪 · 就绪 | 可放电 1 次 |
| 电击枪空电 | 充能 9.8 秒 | 自动恢复电量 |

- 左侧斜线只比较同一种单位：枪内剩余发数 / 枪内容量；备用单独用“弹匣”或“霰弹”计数，不折算成散装备用子弹。
- 创造模式仅把备用资源数量显示为 ∞，仍显示实际枪内发数和容量；电击枪继续实际 10 秒充能，不显示无限电量。
- 每帧在武器逻辑执行后读取实际背包，分散在多个格子的同类弹药合计。换弹动画丢匣后枪内归零，装入才扣备用；逐发装填一次变更一发。开背包调整弹药后，关闭立即重新读取。
- 装填期间次行增加“换弹中”或“装填中”；空枪和备用不足以完成一次装填用颜色区分。
- 电击枪倒计时使用现有 RechargeAt，向上取到 0.1 秒，只有实际枪内电量恢复才显示就绪；射击、充能和按换弹不再产生重复弹量小消息。
- 没有修改弹药消耗、弹匣容量、换弹时序、枪械存储位、物品索引或无耐久规则。中英文本同步。

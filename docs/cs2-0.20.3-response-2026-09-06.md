## 一、蝴蝶刀检视末尾刀柄下方的"钉子"——是 CS2 刀身自己的刀根

视频 5.45–5.95 s 逐帧放大（枢轴区域 300×300 px 放大到 600）：在两片刀柄的枢轴圆环上方有一小段刀身色的
尖角。**待机（0.5 s）同一位置也有**，只是检视末尾的持刀角度让它正对镜头。

为了知道它是哪块几何，新写了 `tools/cs2_knife_render.py`：纯 Python 采样 rig、蒙皮 `.cs2.skin`、按
`cs2_placement.py` 摆放投影，每个三角形按所属关节上色。渲染待机 0 s 和 lookat01 末尾 4.05 s：那个尖角是
**`blade` 关节的三角形**——刀身的刀根（tang）在枢轴处保持全宽（z −0.4…1.47 in），而两片刀柄在枢轴处各自只有
一个圆环（rear z 0.19…0.89，front z −0.48…0.21），刀根的刀背角就从 rear 的圆环上方露出约 0.6 in。CS2 的 GLB
只有这一个网格（`body_legacy`，11996 三角、10337 顶点），没有被我们丢掉的部件；蒙皮里也没有多权重或离群
顶点，`weapon`/`ag1_hand_r` 两个关节本来就没有顶点。也就是说这块几何是 CS2 模型自带的，蝴蝶刀实物的刀根
（两根枢轴销之间的方块）就是这样。

**没有改代码。** 0.20.2 那条"混合状态泄漏"的推断对这个现象不成立（几何是不透明的刀身）。如果 CS2 里同一
角度看不到这个角，那就是我们刀身相对刀柄的角度不对，需要一张 CS2 蝴蝶刀检视末尾的截图对照；有的话我再查。

## 二、R8 左键右键都没有伤害——子弹朝后打

击发用的射线是 `input.Dig ?? input.Hit ?? 兜底`。R8 的两种击发都不在按键那一帧：左键是扣锤 0.5 s 后才打，
右键（瞄准键）根本没有 Hit/Dig 射线，全走兜底。兜底写的是 `Vector3.Transform(Vector3.UnitZ, EyeRotation)`，
而这个引擎的朝前是 `Matrix.Forward = −Z`（原版 `ComponentPlayer`、`ChestBlock` 都用
`Matrix.CreateFromQuaternion(EyeRotation).Forward`）。所以 R8 一直朝身后打，曳光也在身后，什么都打不到。
其它枪按下那一帧都有 Hit/Dig，没受影响。

修：兜底改成相机的视线射线（`GameWidget.ActiveCamera` 的位置和方向，正是原版 `ComponentInput` 造 Dig/Hit
用的），没有相机时用 `EyeRotation` 的 Forward。

## 三、AUG / SG 553 开镜画面

0.20.2 的样子（视频 11.5–14.5 s）：整屏黑、中间一个只占屏高 64 % 的圆窗，窗里除了放大的世界还看得到举起来
的枪身和瞄准镜。用户要的：通过镜片往外看，不该看到枪身和瞄准镜，周围不该是一片黑。

CS2 的做法：`m_bHideViewModelWhenZoomed = false`，但 ironsight 时把瞄准镜目镜对到相机上，镜筒把画面框满，
看到的只有镜片里的世界；`scope_filter` 那张 HUD 图就是镜筒的样子。0.20.2 只画了图没对目镜，枪还在原来的
位置上，窗又按屏高画得太小。

修：
- 开镜时和狙击枪一样**不画枪和手臂**（`SetScope` 两种镜都置 `s_scoped`），HUD 图代替镜筒；ironsight 片段
  仍在控制器里跑（声音、时序不变）。
- 圆窗按屏高的 94 % 画（图的窗半径是半边长的 0.64，所以正方形边长 = 0.94 h / 0.64），黑只剩四角，和狙击镜
  的遮罩一个量级。
- 尺寸和窗内色调强度都是估计（导出里没有 panorama 布局），做成可调：`IronsightScopeWindow`（默认 0.94）、
  `IronsightScopeTint`（默认 1，0 = 不染色），在调参文件里改，不用重打包。

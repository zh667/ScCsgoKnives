## 审查发现与修改

| 发现 | 0.40.1 处理 |
| --- | --- |
| StatTrak 只有附件表与资源探测，没有实际绘制调用 | 从 Windows 的 CS2 VPK 导出官方模块与数字图集；新增第一人称、第三人称、掉落物绘制。保留物品栏的原平面图标，精确计数仍在属性／说明中显示。 |
| 附件偏移被提前乘 0.0254，不能直接接入英寸制骨骼 | 明确坐标链：模块英寸 → 官方附件 → 当前骨骼 → 本视图的坐标与单位转换。物品模型单独转入实际 normalized bind frame，不与第三人称米制混用。 |
| “无限”射程仍有 512 格、128 列截断 | 以实际已分配区块数量作为遍历终止证明，遇首个未加载列或 Y=0/256 停止。处理负坐标、接缝与对角线。没有新增 16384 等替代武器上限。 |
| 引擎地形 Raycast 本身截到 1000 格 | 将实际射程连续分段调用引擎，每段不超过 512 格，命中距离换回整条射线。512 是单次引擎调用长度，不是总射程；远墙仍阻挡。 |
| 积压 1024 次后删除最旧击杀凭据 | 不再驱逐已确认凭据；超过阈值报警但保留。计数写入和凭据消费在同一保存保护区结束，失败回滚不消费。事件序号极限重编号保留条目身份。 |
| 损坏／隔离记录导致其待结算击杀被删除 | 读档及结算保留凭据但不应用到错误枪型；不猜测、不凭空创建枪械记录。 |
| 任意旧升级标记可绕过备份；只数文件和解析 XML | 实际磁盘仍是旧 schema 就重新备份，不用历史 marker 豁免。逐文件 SHA-256 比较整个备份与来源，并验证 Project.xml 来源 schema。失败拒绝升级。 |
| 布局编辑器收起按钮把自己一起隐藏；控制栏比面板宽，短屏底部操作不可达 | 增加面板外独立展开按钮；预览拖动排除该按钮；加滚动容器、足够宽度、窄屏操作列和标题换行。 |
| 设置 Create 覆盖与“失败原文件不变”声明不符 | 同目录唯一临时文件、flush、回读验证、覆盖式 rename；不使用引擎先删目的地的 Storage.MoveFile。失败清理本次临时文件，旧文件不被主动截断。 |
| 设置页访问布局编辑器再回来会重置返回目标与编辑起点；布局保存可能顺便写入未确认开关 | 设置页使用本地草稿，返回编辑器保留原设置页和原返回目标；仅点保存才应用。布局独立保存；失败恢复内存原布局。设置页恢复默认只影响本页，布局默认在布局编辑器内操作。 |
| 准星颜色只有五个预设 | 保留预设并补 RGB 三滑条与精确 RGB 预览。 |
| 属性页重建复用控件没有先脱离旧容器、滚动位置未明确保留 | 重建前脱离、保留列表和属性滚动位置；记录修订变化时刷新，并在身份区显示实际击杀数。 |
| 仅计数世界仍显示“已满级”，待应用升级也提前显示满级 | 区分仅计数／已解锁／已应用；仅计数世界不预览不可能获得的下级加成。 |
| 交付验证脚本可能把非零退出、空检查集或旧报告当作通过 | 现在必须退出码为零、检查集非空、报告包与 DLL 哈希吻合、各检查通过；同时修复 Windows 中文输出解码。 |

## 官方模型与数字

输入：`weapons/models/shared/stattrak/stattrak_module.vmdl_c` 及其官方材质。

- 外壳 330 三角形，数字显示面 48 三角形（六位，每位为原模型曲面网格）。
- 数位信息来自 UV 整数部分，按当前击杀数选择官方图集；不画替代字体，不每次击杀生成大纹理，也不建立无限数量的计数缓存。
- 六位饱和到 999999，存档仍保留 64 位真实累计击杀。
- 第一人称本体接入现有 PBR；数字独立无环境压暗。第三人称／掉落物沿用项目对应视图的材质路线。
- 所有 35 枪使用其真实附件，双持手枪为 `weapon_r`；现有 AWP/M4A1-S 旧版涂装选择 legacy 附件。AK 已批准的 HD 枪身不变。
- 这不是 Source 2 着色器逐像素移植：其材质亮度／对比度参数、HDR 发光及环境光照尚不能宣称精确一致。原版纹理尺寸保留，Lite 仅在打包时派生。

可重复导入：`tools/import_cs2_stattrak.py --glb <VRF导出GLB> --materials <反编译材质目录>`。
来源、输入 SHA-256、坐标约定见 `stattrak-module-source-0401.json`。没有修改 CS2 安装或兄弟项目的导出库。

## 存档与旧状态

物品布局 **v5 不变**；记录 **schema 3 不变**；型号顺序、实例 ID、既有记录字段意义不变。

本次不重置击杀／等级、弹量、皮肤、消音器、耐久、充能和补偿。成长平衡保留 VPS 已实现的每级 100 杀、1000 满级、伤害／容量／耐久上限 +50%、电击枪 150→225 与 10→5 秒。
旧 schema 1/2 仍由保留的转换器升级，备份校验加强。0.28.2 专用转换器没有替换；旧备份没有删除。schema 3 世界进入 0.40.1 不需要再做一次 schema 迁移。

损坏记录对应的待结算凭据现在保留，不自动计入别的枪；恢复仍需可信原记录。
设置只写本设备的 `ScCsgoUi.json`，与世界无关。原始世界和现有玩家配置没有用于本轮写入测试。

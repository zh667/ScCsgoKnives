# 0.35.0 复查修正二：枪械实例状态表、投掷出手点、炸烟只影响被炸到的烟、第三人称消音器、超时清理、统一密度

## 1. 耐久跟着枪走：实例 ID + 世界状态表（`World/ScGunRegistry.cs`）

- 物品 data v5：第 0–5 位型号，第 6–15 位实例 ID（0 = 满弹匣的新枪，1023 = 空枪的新枪，1–1022 = 状态表记录），第 16 位永不写出（置位即 v3 旧枪，照旧解码，首次写入时入表）。
- 记录里存弹量、消音器、**精确耐久**（AK 1500 发，每发 1 点）。HUD 显示百分比，物品描述显示 `1290 / 1500`，维修按缺失比例报价。
- 新枪（创造栏、组装、开局赠枪）不占 ID；第一次开枪/换弹/装拆消音器时才分配。ID 单调分配不复用，满 1022 条后新枪不能开火并提示"状态表已满，请新建世界"。
- 复查表里的三种情况都有自检覆盖：同槽换一把全新同款枪不继承磨损；拆消音器不清磨损；换槽/入箱/掉落后耐久不变。创造复制出的同 ID 物品被同一玩家同时持有时，0.5 s 内拆成独立记录（箱子里的复制品要等拿到背包才会被发现）。
- 换弹事务改为先确认弹药足够再写记录，写入后库存步骤仍失败则回滚记录（否则被拒绝的付费换弹会把弹匣填满）。
- 已知边界：ID 上限 1022/世界；表不回收（丢弃、消失的枪仍占记录），后续做持有者扫描回收。

## 2. 投掷出手点

出手点由逻辑层用身体位置、朝向、蹲伏和投掷姿态解出右拳位置（`ScThirdPerson.FistFromLogic`），不再读渲染缓存；第一/第三人称、任何摄像机、没画过人物的帧都得到同一点。渲染只读姿态。

## 3. 高爆开口只影响被炸到的烟

每颗投掷物有世界唯一 ID（随存档保存）。高爆起爆时逐团做视线检查，开口记录能到达的烟的 ID 列表并随存档保存；密度查询、粒子淡出、烟内遮罩、AI 视线都只对列表里的烟扣密度。墙另一侧的烟不受影响（自检 `smoke-opening-bound-to-its-smokes`）。

## 4. 第三人称消音器

烘焙时把 `silencer` 部件单独成组，绘制时按该枪当前记录的消音器状态跳过；M4A1-S、USP-S 装拆后第三人称一致。

## 5. 12 秒超时

未落稳满 12 秒的烟雾弹/诱饵改为**移除且不起效**并写警告（含落地、静止时间、速度），不再空中起烟。

## 6. 统一密度

AI 视线的路径积分改为对同一个带软边的 `Density` 采样（每 0.25 m），与烟内遮罩一致；粒子按贴片覆盖的中心与四边共五点的平均清除度淡出，不再只看中心。

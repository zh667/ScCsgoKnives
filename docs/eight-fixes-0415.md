# 八项修正与旧档兼容边界（0.41.5）

## 存档原则

枪型顺序、物品布局 v5、GunRegistry schema 3 和原有字段均不变。保留公开 0.28.2 的
自动全世界备份升级以及 schema 1/2 转换器，不更改伤害、容量、耐久上限、充能规则。
同格式普通旧档不补满弹药、不修满、不重置计数等级。界面修改不会触碰枪械记录。

## 尸鬼 2.0 主/里世界

分析用户提供的 `[API1.9.2.1]Ghoul尸鬼-v2.0.scmod`（本地只读反编译，无修改第三方包）。
该包 SHA256：`6c0a1d7eec67a612ebbdf51908e3a16de80f126bc753cab3090c255600fb3a3c`。
`SAGhoul.Tartareosity.SubsystemWorld.ChangeWorld` 保存源世界，再把玩家实体 XML 复制到目标世界，
同步的子系统名单含 PolyGunInstances，但不含 ScGunBlockBehavior。
这解释了日志中源世界有 1 条枪械记录、Tartareosity 有 0 条、data 66 缺第 1 号记录。

实现：

- ProjectXmlSave 在玩家 XML 中附加 `ScGunTravel` 携带快照；仅包含玩家各库存 Slots 引用的实例。
- 世界子系统保存独立 `GunTravelIdentities` 映射，不占用枪械 data 位、不改变 schema 3 的严格记录字段。
- 快照随尸鬼的玩家复制一起移动。目标 ProjectXmlLoad 在实际实体加载前，在独立 XML 副本校验并合并。
- 新身份只分配目标表新的 ID，不覆盖目标已有同编号枪。往返同一身份时恢复原映射并更新弹量/磨损等。
- 保留所有严格记录字段：涂装、消音器、计数/等级/待升级、余弹/溢出、耐久、剩余充能。
- 表满、异常记录、未知 schema、身份重复、目标其他持有者冲突、成长规则冲突、待结算击杀/补偿时拒绝；
  不静默克隆/清空记录。不重试直接写真实物品，不把问号恢复成满状态新枪。
- 首次应用跨世界合并前对目标世界作完整快照并校验；备份失败通过加载保护字段阻止子系统加载。
- 仅接受主世界与其直接子目录 `Tartareosity` 往返，不把不相关世界拼接起来。
- 不改变尸鬼自己的源/目标写盘事务；它在调用我们目标加载钩子之前已经复制了目标玩家。
  如果我们拒绝，保留源世界和目标已拷贝的快照，不声称能回滚尸鬼自身的所有写盘。

**使用要求**：先在更新后的主世界正常加载有效枪，保存后再传送。旧版本已制造的问号且没有有效携带快照，
本版不自动猜测恢复；应使用切换前的源世界/备份另做核对。不要丢掉问号物品或删除注册表。
跨维度动物背包、未按标准 Slots 序列化的第三方远程仓储，不在本次随玩家转移支持范围。
旧 DLL 不认识携带协议；测试跨世界往返应始终使用 0.41.5 或后续支持该协议的版本。

## 其余七项

1. 全部武器按键：编辑页增加“选择全部武器按键”列表，可直接选择已有九项与新增开火项；
   大小、位置、开关、透明度、左右手仍使用旧设置。开火新项默认隐藏，旧玩家没有该字段时取关闭默认，
   不突然多出重叠按钮。原版移动/跳跃/背包不接管；原版开火仍可用。自动枪按住、半自动按次。
2. 耐久说明：正常耗尽不消失，损坏后到装配台维修。仅改说明，不改既有损坏保留机制。
3. 装配台返回：会话内保存分类/选择/滚动，确认/返回重开同一页面时恢复；选择涂装返回选枪，
   其他子功能返回功能菜单。材料与候选仍重新读取以避免陈旧报价。
4. 涂装配方：原 pigment:1 改为第二份 pigment:0；两份白色颜料 + 帆布 + 铜锭 → 两份涂装材料。
   修正材料“涂装不改伤害”的过时文案，不更改现有皮肤加成。
5. Sawed-Off：只在 reload 的官方 loop 段显示 shell 辅助几何；待机/检视/射击/拔枪不绘制。
   非永久删模型，正常装填仍可见。
6. CZ75：从现有原 CS2 DMX/VNMCLIP 增补 reload2/reload2_empty（后续换弹）和配套音效触发；
   首次换弹仍用原 reload/reload_empty，官方入弹事件后隐藏已取走的前置备用弹匣，后续选择对应动作。
   前置弹匣是视觉状态，重新装备时重置；不新增弹药、不给枪增加真正备用弹匣、不写入旧枪格式。
   原动画图线索是 weapon_has_front_mag_removed；没有修改原始 DMX，也没有手工伪造抓取动画。
7. 编辑键解除检视：枪与刀的 IsEditable_ 返回 false，编辑回调不触发检视；专用检视按钮保留，
   桌面独立 G 键走检视。其他模组的可编辑物品不修改；投掷物原有编辑菜单（含减弱闪光选项）保留。

## 测试与限制

新测试覆盖：跨世界编号冲突与往返状态、输入 XML 不变、同世界两轮重读幂等、坏快照/满表/
重复身份/不相关世界/未知 schema/其他持有者拒绝、计数涂装与电击枪剩余充能；
装配台分类恢复、霰弹显隐、CZ 前置弹匣显隐、编辑入口禁用、新开火按钮默认关闭。
沿用全部旧存档升级、库存事务、动画、UI 和冷启动测试。

测试不运行用户真实世界，不注入尸鬼 DLL 到游戏进程。反编译、XML 模拟和离线测试不是手机版实测。
需要实机重点验收：带两把不同状态同型枪往返两轮、在里世界存读档/箱子流转、手机开火多指与取消，
CZ 首次/后续/空弹匣/打断换弹以及 Sawed-Off 检视边缘。不能把这份实现说明视为真机画面已验收。

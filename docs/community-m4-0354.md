# 0.35.4 旧世界保存后不再失效；开镜真正打断检视

日期：2026-09-08。对 1f84d77 的审查发现两处。

## 1. [P1] 旧世界保存一次后保护失效

0.35.3 的分类把"存档里有 `GunRegistry`"排在布局戳前面，而旧世界保存时同样会写出 `GunRegistry`，于是"旧世界 → 保存（戳 4 + 记录表）→ 再读"被判成兼容，下一次保存还会写成 5。

现在**显式布局戳优先**：
- 戳 = 5 → 兼容；
- 戳 = 4 → 旧世界，永远保持；
- 其他非零戳（更新版本或未知）→ 一律按旧世界处理，不放行；
- 只有无戳时才按历史键推断：有 `GunRegistry` → 兼容（0.35.0/0.35.1），只有 `ZeusRechargeAt`/`GunWear` → 旧世界，什么都没有 → 新世界。

保存统一走 `ScGunRegistry.StampFor(legacyWorld)`。自检 `world-layout-status` 改为覆盖十种组合，并加入"旧世界读→存→读→存"往返（戳保持 4）和"新世界存→读"往返。

## 2. [P2] 开镜打断检视

原来 `SetScoped` 只改布尔值，检视动画继续播放。现在开镜/切倍率成功时，若当前片段是 `inspect*`：取消动作回到 idle（瞄准姿态由 Zoom 决定），并丢弃尚未播放的检视音效（`Scheduled` 里含 `inspect` 的条目）。AUG/SG553 这类开镜保留枪体的枪不会再出现"视野已放大、枪还在检视"。

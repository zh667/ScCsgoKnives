# 0.19.1 — 剩余 24 把枪 · 第二批：带镜的四把（2026-09-05）

scar20、g3sg1、aug、sg556。前两把是 AWP 那一类（两级放大、开镜时隐藏枪、画遮罩）；后两把是
CS2 里唯一"带镜但不隐藏枪"的枪，机制是新的。

## 一、AUG / SG 553 的开镜

CS2 的 vdata：`m_nZoomLevels 1`、`m_nZoomFOV1 45`（对 90 是 2 倍）、**`m_bHideViewModelWhenZoomed false`**。
开镜后枪留在画面里，用两段专用片段：`ironsight_fidget_*`（1 帧，持镜姿势）和 `ironsight_shoot_*`
（0.267 s）。没有遮罩，屏幕中心仍是游戏自己的准星。

- `GunSpec.ScopeHidesWeapon`（来自 vdata，狙击枪 true，AUG/SG false），驱动脚本按 vdata 写入并带注释。
- `CsmcFirstPersonRenderer.SetScope(on, magnification, hideWeapon)`：不隐藏时只改世界 FOV，不置遮罩帧、不早退。
- 控制器 `State.Scoped`（行为子系统在 `SetZoom/LeaveScope` 时同步）；`IdleClip(variant, empty, scoped)` →
  `ironsightIdle`，`ShootClip(..., scoped)` → `ironsightShoot`；每帧复核，退镜立刻回普通 idle。
- rig 别名新增 `ironsightIdle` / `ironsightShoot`（`cs2_gun_rig.py`），两把枪的 rig 重生成。

**镜片**：AUG/SG 的刚体件里有一小块 `shared_scope_lens`（82 / 58 个三角形），CS2 材质
`materials/models/weapons/shared/scope/scope.vmat` 是 `ui.vfx` + `F_ADDITIVE` + `scope_dot_white_color`
贴图、`g_flIntensity 6`——一块透明玻璃上加法叠一个亮点（准星）。现在这块件不再拿枪身贴图去画
（那会在镜片上贴一块机匣），改为加法、无光照、用镜片自己的 UV 画 `cs2_scope_dot`（原图 128×128 直接装）。
强度 6 没有复现，一次加法叠加，点比 CS2 的柔一点。

## 二、SCAR-20 / G3SG1

与 SSG08/AWP 同路：两级 `[2.25, 6]`、隐藏枪、CS2 遮罩、全自动。SCAR-20 有 `shoot_empty / idle_slide_back /
reload_empty`，空仓逻辑照旧生效。火焰容器 `weapon_muzzleflash_snip_ar` → `uweapon_muzflsh_awp_primaryflash`；
曳光 SCAR-20 `weapon_tracers_rifle_scar`、G3SG1 `weapon_tracers_rifle_ssg`。

## 三、AUG / SG 553 的曳光

`weapon_tracers_assrifle_aug`：和 SMG 一样是 rope，滚动 20500 in/s、周期 100 in，贴图
`bullet_tracer_tintable`（白色，CS2 靠 `C_OP_ColorInterpolate` 染色，这里记为 unmodelled）；半径是
CS2 自己的随机 `0..1 in`（取中值 0.5）。新烘 `cs2_tracer_tintable`。rope 在 80 m 处只有 0.29 px 半宽，
自检对 rope 改在 40 m 判远端下限（清晰的 trail 仍判 80 m）。

## 2. 做了什么

### 图标：换成 CS2 原图，33 张

`tools/install_gun_slot_icons_cs2.py`。先量了 CS:MC 旧图的来历：CS2 的 512×384 渲染图**整帧缩到四分之一**、
居中放进 128 格，就是 CS:MC 的图——ak47 轮廓 491×245 → 123×62（CS:MC 123×62），m4a1s 472×184 → 118×46
（119×47），awp 479×184 → 120×46（121×47）。按这个规则对全部 25 张有旧图的武器（3 枪 + 22 刀）重做，与旧图
的轮廓 IoU 0.94–0.97、RGB 均差 9–18，即同一套图的两次缩放。所以 11 枪 + 22 刀全部换成 CS2 原图，风格一致，
手枪自然比步枪小，与 CS2 购买菜单一样。0.18.2 里我用网格渲染的 8 张作废。

### 手枪空仓

rig 里已有的 `shootEmpty / idleEmpty / reloadEmpty` 接通：

- 打空最后一发 → `shoot_empty_*`（套筒后挂）；空仓时 idle 用 `idle_slide_back_*`，每帧按弹匣数复核，换弹
  写回弹数后立刻放开套筒；空仓按 R → `reload_empty_*`，时长和提示音（`<gun>:reloadEmpty`）都跟着它。
- 控制器新增 `ShootClip(variant, silenced, lastRound)`、`ReloadClip(variant, empty)`、`IdleClip(variant, empty)`，
  行为子系统按同一函数取片段、时长和提示音键。
- 没有这些片段的枪（三把老枪、m4a4、famas、mp9、p90、ssg08）拿到的和以前完全一样，自检逐把断言。

涉及的枪：deagle、glock18、usp_silencer（三把都有全套三段）。

### USP-S 装消音器时的拔枪

`DeployClip(variant, silencerOn)` → `deploySilenced`（`draw_silenced_pistol`，1.0 s，提示音 draw/slideback/
sliderelease 三条）。行为子系统的 BusyUntil 与提示音也按它。

### 8 把新枪的枪口火焰与曳光参数

`tools/cs2_effects.py` 从 3 把扩到 11 把。每把枪播哪个火焰系统来自它自己的模型事件
（`02_models/events_full/<weapon>.analysis.txt` 里的 `AE_CL_CREATE_PARTICLE_EFFECT`，附着点 `muzzle_flash`）：

| 枪 | 容器（模型事件） | 取的火焰子系统 |
| --- | --- | --- |
| deagle | `uweapon_muzflsh_deagle` | `uweapon_muzflsh_deagle_primaryflash` |
| glock18, usp_silencer | `uweapon_muzzleflash_pist` | `uweapon_muzzleflash_pist_fire` |
| usp_silencer 消音 | `uweapon_muzsilenced_subm`（muzzle_flash2） | `uweapon_muzsilenced_subm_smoke` |
| m4a4, famas | `uweapon_muzflsh_riffle` | `uweapon_muzflsh_ak47_primaryflash` |
| mp9, p90 | `uweapon_muzzleflash_subm` | `uweapon_muzzleflash_subm_fire` |
| ssg08 | `weapon_muzzleflash_snip` | `uweapon_muzflsh_awp_primaryflash` |

曳光由 vdata 的 `m_szTracerParticle` 点名：手枪 `weapon_tracers_pistol`（18000 in/s，900 in，半径 1，色
247,213,94..255,245,219），SSG08 `weapon_tracers_rifle_ssg`（30000 in/s，900 in，半径 2），M4A4/FAMAS 与 AK 同
`weapon_tracers_assrifle`。

**SMG 的曳光是另一种东西**：`weapon_tracers_smg` 不移动粒子，而是用 `C_INIT_CreateSequentialPathV2` 在枪口到
命中点之间铺一条 rope（`C_OP_RenderRopes`），把 `bullet_tracer_seq` 贴图以 18000 in/s 沿绳滚动、每 100 in 一个
周期。画在屏幕上就是一段 100 in 长、以 18000 in/s 飞行的光条，正好是现有 ribbon 能画的：滚动速率当速度、
一个周期当拖尾长度、`m_ConstantColor` 247,210,185 当色、半径 2.5 × 0.75。贴图由 `tools/cs2_tracer_texture.py`
新烘 `cs2_tracer_smg`（128×256 原图转置，亮头落在 U=1，即 ribbon 的头端）。rope 没有屏幕尺寸钳制、没有淡入
包络，这些按原样记录在 `Unmodelled`，自检对 rope 用对应的判据（宽度在 5 m 处判，包络须平直）。

**枪口位置改为骨骼优先。** vdata 的 `m_vecMuzzlePos0` 和 rig 的 `muzzle` 骨在 AK/P90/FAMAS/沙鹰上相差 0.001 in，
在 AWP 上差 0.95 in、SSG08 上差 7.73 in——都只沿枪管方向，vdata 在骨骼后面（枪管里面）。模型把火焰粒子
附着在 `muzzle_flash` 附着点，也就是这根骨；所以火焰、曳光起点、headless 工具都改从骨骼取，vdata 只做兜底。
自检对每把枪断言两者在同一条膛线上（横向 < 0.5 in），沿膛的偏移只报告。

### 声音

`cs2_sound_timings.py` 事件查找改为不区分大小写（`Weapon_p250.Clipin` 对 `Weapon_P250.Clipin`），11 把枪的表
字节不变。C2 的两条 Taser 事件可解析（`Weapon_Taser.ChargeNotReady/ChargeReady_Zap` → zap1..3.wav）；Taser
本轮不接入，没有装它的音频。

## 3. 自检新增（Cs2SelfTest，包内 DLL）

- 特效从 3 把扩到 11 把：`effects/<gun>/loaded, muzzle0, muzzle.bone（同膛线）, muzzle1 + flash.silenced（有消音器
  的枪）, flash.*, tracer.speed/length/passes/textures/sizeclamp/radius/trailseconds/envelope`，rope 走自己的判据；
  `tracer/<gun>/origin, width.near, width.far` 11 把全测。
- 空仓/消音：`gun/<gun>/shootClip.empty, idleClip.empty, idleClip.loaded, reloadClip.empty, cues.reloadEmpty,
  deployClip.silenced, deployClip.plain, cues.deploySilenced`——有片段的枪必须选到，没有的枪必须和原来一样。
- rig 段对 `.cs2.parts` 的枪按刚体部件计数；弹匣骨名 `clip` / `magazine`（Glock-18、FAMAS）都认。

证伪：去掉末发选 `shootEmpty` → 3 项失败（deagle/glock18/usp 的 shootClip.empty）；`DeployClip` 不选
`deploySilenced` → 1 项失败；特效表删掉 mp9 → `effects/mp9/loaded` 失败。恢复后 0 失败。

## 5. Windows 最小回归（0.18.3）

包：`output/ScCsgoKnives-0.18.3.scmod`，SHA-256 见第 4 节。装之前核 SHA。

1. 物品栏：33 个图标全部是 CS2 原图；手枪比步枪小、刀与枪同一风格。
2. Glock-18 / USP-S / 沙鹰打空：最后一发套筒后挂并停住；此时按 R 是空仓换弹（套筒在换弹里放开）；
   打到剩几发时按 R 是普通换弹，套筒不动。
3. USP-S 装着消音器时切走再切回：拔枪片段与不装时不同（`draw_silenced_pistol`）；日志里
   `CS2 action: asset=usp_silencer requested=deploySilenced`。
4. MP9 / P90 开火：曳光是短光条（每 3 发一条）；沙鹰/Glock/USP 每发一条淡黄光；SSG08 每发一条。
5. SSG08 与 AWP 开火时火焰在枪口而不是枪管里。
6. 三把老枪走一遍拔枪/开火/换弹/检视，确认没变。
7. `Game.log` 与视频放回原位置。

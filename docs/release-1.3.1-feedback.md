# 1.3.1 全量版：1.3.0 玩家截图问题修正

## 原因与改动

| 反馈 | 查到的原因 | 修正 |
| --- | --- | --- |
| 生成蛋第一人称巨大、贴脸 | 新方块没有原版蛋的展示参数，沿用默认 scale=1、offset=0 | 使用原版蛋 FirstPersonScale=0.4、偏移(0.5,-0.5,-0.6)、旋转(0,40,0)；第三人称 InHandScale=0.3、偏移(0,0.12,0) |
| 小鸡太小 | CS2 GLB 米制原尺寸高约 0.351 格，直接原大小使用 | 模型放大 1.6 倍，约 0.56 格高；碰撞盒改为 0.48×0.58×0.55；包围球同步放大，生命／伤害／跟随规则不变 |
| 右下 HUD 下方空很多 | 原版 LookPadContainer/MovePadContainer 在触摸图案隐藏后仍可见，避让逻辑把空容器当成实体按钮 | 只避让实际可见的方向盘／触摸底图／按钮和快捷栏，不占用隐藏触摸区域；三种横竖屏大小实际 Measure/Arrange 检查底部留白及显示时避让 |
| 创造背包皮肤枪无耐久文字 | ScGunSkinTemplateBlock 是单独的方块类别，旧标签仅识别 ScGunBlock | 已识别皮肤／计数器模板显示其满耐久100%；真实皮肤枪继续读取实际损耗和自身耐久上限。未知模板不猜测，不生成或修改枪械记录 |
| 零件做10个后枪也默认10个 | m_count 属于整个对话框，切换条目没有重置 | 切换到不同物品重置数量和材料报价为1；同物品刷新、修改数量、连续制作保留玩家主动设定。零件、弹匣仍可批量 |
| HUD 想用原作枪图，缺少黄色 | 1.3.0用备用弹匣图标，颜色仅分20%以下与以上 | 从本机CS2 VPK提取35把枪的equipment SVG。对应当前枪型显示轮廓；已装弹部分由左向右着色，空余灰色；>50%绿色、20%～50%黄色、≤20%红色；保留短弹量数字和右下备用数 |

新增轮廓图按原始比例缩放到448×144透明画布，显示尺寸112×36；无AI重绘。M4A1-S映射m4a1_silencer、M4A4映射m4a1、Glock映射glock。其余用原武器资源名。来源、输入／输出哈希见 `hud-weapon-sources-20260919.json`，导入脚本 `tools/import_cs2_hud_weapons.py`。原提取保留在 `.tmp/cs2-hud-weapons-20260919`。

## 复验与边界

- 使用打包DLL、原版字体／Widget及真实数据库检查，不只检查源码常量。
- 遍历全部创造皮肤和计数器模板、所有皮肤对应的已有50%耐久枪；检查格子复用和预览不分配ID。
- 从10件零件切换枪械，数量变1；不同尺寸横／竖屏对话框检查同物品刷新保留10、换物品重置1。
- 隐藏160×160触摸区不再推高HUD；图案显示时仍避让；35张原始轮廓都通过原生图片读取。
- 小鸡继续跑原有动画、跟随、两轮XML和死亡单次爆炸检查，新增模型／碰撞体大小检查。生成蛋展示参数与当前原版BlocksData逐项对照。
- DLL完整回归及包哈希见 `release-1.3.1-evidence.json`，原始报告在 `output/release-1.3.1/`。没有把离线布局、资源预览当作手机GPU实测。
- 生成蛋仍是对地面使用生成；本次解决截图中的手持模型，没有增加新的飞行投掷物机制。
- 不改枪械数据布局或皮肤编号；既有1.3.0包保留。含新增小鸡的世界仍不承诺可降回不支持小鸡的旧版。

## 游戏内检查

1. 拿生成蛋，查看第一人称；生成小鸡应比1.3.0大。旧世界已有小鸡重进后也按新模板大小加载。
2. 桌面／隐藏触摸区时看右下，HUD应靠近底部；启用右侧触摸盘时不压住可见按钮。
3. 满弹→半弹→剩余五分之一：枪械轮廓应依次绿、黄、红；打空只剩灰色。换枪图案同步。
4. 创造背包翻到皮肤枪页：每项应有100%；磨损皮肤枪放回背包仍显示真实百分比。
5. 枪械台选零件数量10，再选任意枪，按钮应为“制作1件”，材料按1件重新报价。

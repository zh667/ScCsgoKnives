# 0.39.0 P1a — 35枪基础手感测试包

用户在2026-09-08明确授权按照功能总规划及35枪审计文件开始实施。本轮只完成首个可独立验收的P1a基础链，不宣称属性页、手机布局、计数器或成长已实现。按规划顺序，实机基础手感验收是后续阶段的门槛。

## 已接入的实际路径

- `gun_handling.json` 包含35枪获批的主／副模式初值，来自规划审计的可重复生成，不改变CS2原始数据文件。
- 统一 `EffectiveGunStats` 提供实际近距攻击力、射程、容量、耐久上限和当前模式；这一阶段容量和耐久仍读取旧状态，不实施成长。
- 站立／蹲下、水平速度0.5～4.5格/秒插值、起跳和离地宽限、落地0.18秒恢复、开镜0.15秒过渡。
- 连射成功后按每把枪独立的实例状态增加Bloom；霰弹一次扣扳机只增加一次，三连发各次增加。停火0.12秒后按表中速率线性恢复；换弹或切枪不直接清空原枪的Bloom，重新取出时按游戏时间衰减。Bloom是本会话瞬态，退出世界清除；不新增保存字段或承诺跨退出保留不足半秒的瞬态惩罚。
- Glock/FAMAS三连发、M4/USP消音、六款带镜枪开镜、R8副攻分别选择真实支持的模式。未支持副模式的枪不因存在数组第二项自动获得功能。
- 每枪射程及分段衰减使用获批表，减少多数非狙击枪的远距离覆盖；近距威力、弹丸数量、爆头倍率、原射速不变。
- 相机后坐力缩减并按T90指数回正，子弹射线在回调、退镜和相机kick前捕获；不将镜头抖动当作散布。
- 精确命中与宽松候选分离。精确部位落空后继续后方候选，不再按0.35粗包围盒直接补成普通伤害。身体最终容差不超过0.08格且不超过最小水平尺寸的10%，头部不膨胀。
- 命中姿态同步当前逻辑参数并采样动画控制器，不调用会推进动画时钟或二次应用root motion的Animate。按帧和身体变换缓存部位矩阵，不要求目标先被摄像机画出。控制器缺失、姿态无效时使用明确的窄身体回退，不判头部；不把无法取得模型误判成确定落空。实际移动生物姿态效果仍需实机确认。

水中和梯子采用规划中的简化满移动惩罚。不是完整CS2姿势／种子弹道；保留模组轻量玩法目标。

## 独立配置，保护旧调参

新配置文件为游戏应用目录的 `ScCsgoGunplay.json`：

```json
{
  "Version": 1,
  "Preset": "survival"
}
```

- 首次没有该文件时，在正常世界加载流程中创建，默认采用本次已批准的轻量手感。
- `survival` 使用35枪新表；`classic`保留此前射程、散布、后坐力和原GunNumbers选择，便于A/B对照。
- 只在进入世界时读取，修改后退出／重进生效，不在一发射击中途切策略。
- 不向 `ScCsgoKnivesTuning.txt` 添加键，也不触发它的默认值版本戳重写，旧视角／光照／手臂调参保持原样。
- 配置未知版本、拼写错误或解析异常时保留文件，记录警告，本会话回退classic；不覆写用户配置。
- 每次进入世界首次持枪显示当前策略说明。尚无新的设置UI，该入口将在P1b/P2实现时补齐。

## 存档、资源与兼容

模组测试版本0.39.0；物品布局仍v5，注册表schema仍2，不增加计数器字段、不为新手感重建实例。
近距伤害、枪型／皮肤ID、现有弹量、当前／最大耐久、消音器、充能、配方、维修、迁移转换器均保留。
枪体、皮肤、法线、图标、动画、音效不替换或删除。Full/Lite使用同一个DLL。

本轮开发没有安装包到游戏Mods目录，没有修改本机调参或实际玩家世界，也没有对World23重新执行迁移。测试使用PackageCheck的独立状态，不用玩家存档验证破坏性边界。

## 实机验收门槛与下一步

P1a代码／离线回归不等于P1a全部验收。尚缺：真实墙面弹点记录、不同体型移动生物的逻辑姿态命中、30/60帧手机多指操作、同机新旧策略A/B性能与手感。尚未宣称手机已变得好用。

建议先测试：AWP站稳不开镜／开镜差异；AK连续扫射和停火恢复；冲锋枪边走边打；霰弹远距离失效；前后站位目标和墙后目标不误伤；旧枪弹量、耐久、涂装仍然正确。保留日志中当前preset与任何 `Gun hit pose unavailable` 警告。

通过后进入P1b属性UI（不显示耐久或原材料），再P2手机布局、P3计数器及兼容、P4成长、P5综合验收。所有后续功能仍未完成，schema 3迁移不应提前发布。

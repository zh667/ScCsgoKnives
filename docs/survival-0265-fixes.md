# 0.26.5 快速切刀与菜单动画

## 原因与修复

- 0.26.4 实机日志中，AWP 射击后约 29–84 毫秒就触发了蝴蝶刀 slash。攻击逻辑更新早于渲染换装，旧枪的 Shoot 状态不算忙，刀攻击直接覆盖型号，导致后续渲染看不到型号变化、漏播 deploy。现在型号尚未切换或切刀动作仍在播放时拒绝刀攻击；切刀完成后恢复正常轻重击。所有枪切刀共用此规则。
- 原菜单分支返回上一帧 Pose，但 KnifeClock 继续走，导致菜单中画面冻结、关闭后直接跳到动作结束。现在保持真实手渲染并逐帧采样，菜单中切换物品立即播放相应切入动作，关闭菜单不重播或跳过。
- 同帧切换后请求检视时，先初始化新武器的 deploy，再将检视排在切入之后，避免旧动作/旧型号干扰。
- 去掉仅用于菜单延期的 DrawWhenVisible。物品索引、资源、伤害、投掷准备及菜单中的玩法操作限制不变。

# 本体 1.4.3 Full + 战术同伴拓展 1.1.3

2026-09-20，用户要求取消子弹命中玩家后的击退和无法转动视角效果。

## 修复

原生 `ProjectileAttackment` 默认施加击退系数 2、眩晕 0.2 秒。敌队每发子弹都沿用这一设置，连续命中会反复刷新原生 `ComponentLocomotion.StunTime`，期间正常移动和转向处理暂停。本体玩家射击也有自己的击退／短晕设置，友军同伴则直接使用原生投射物设置。

现在共用 `ScSurvivalBalance.BulletAttack`，在原生攻击流程最后施加冲量／眩晕的阶段识别玩家目标并跳过这两项。伤害、护甲、命中事件、伤害数字、音效及弹药磨损流程保持原样。此处没有重设速度或清空 `StunTime`，不会抵消其他来源已有的冲量／眩晕；击退参数被其他常规钩子改大也不会恢复这两个子弹效果。

- 本体玩家枪械和同伴枪械经 `GunAttack` 继承新行为。
- 敌队子弹改用 `BulletAttack`，仍不标记为引爆 CS 鸡的 `GunAttack`，避免顺带改变鸡的爆炸行为。
- 怪物／其他非玩家目标继续保留原受击控制。近战、原生箭矢、其他模组自己的攻击类型不在本次修改范围。
- Zeus 电击枪是专门的电击控制，继续沿用确认伤害后的短暂眩晕。本次修改针对普通子弹。

不修改枪型／涂装编号、库存事务、弹药／耐久／充能存档；枪布局 v5、枪记录 schema 6、战术 schema 1 保持原样。

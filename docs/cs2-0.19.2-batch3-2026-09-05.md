## 一、CS2 的霰弹枪换弹是一段 clip 三个区间

CS2 没有给泵动霰弹枪做"装一发"的独立 clip。`reload_nova` 是 1.633 s 的一段，里面用三个
`CNmClipDocEvent_ID` 标出区间，动画图按需把 LOOP 段循环：

```
nova     INTRO 0.000-0.367   LOOP 0.367-0.800 (ADD_AMMO 0.667)   OUTRO 0.800-1.633
xm1014   INTRO 0.000-0.700   LOOP 0.700-1.300 (ADD_AMMO 1.033)   OUTRO 1.300-1.733
sawedoff INTRO 0.000-0.400   LOOP 0.400-0.933 (ADD_AMMO 0.667)   OUTRO 0.933-1.733
mag7     没有 LOOP（弹匣供弹，一段到底 2.467 s）
```

装 8 发 = 0.367 + 8 × 0.433 + 0.833 = 4.667 s。

实现：

- `cs2_gun_rig.py` 本来就把 clip 事件写进 rig 文件；`Cs2Rig.Clip` 现在读 `Events`，
  `Cs2Rig.GetReloadSections(gun)` 从 `WPN_RELOAD_LOOP / OUTRO / ADD_AMMO` 得到区间，没有 LOOP 的枪返回 null。
- `ReloadSections.Duration(n)` 与 `ClipTime(n, elapsed)`：elapsed 落在 INTRO 直接映射；落在循环段按 `LoopStart +
  (elapsed − LoopStart) mod LoopLength`；之后进 OUTRO，超出封顶到 End。控制器 `Update` 用它取样，
  `IsBusy` 与行为子系统的 `BusyUntil` 都按 `Duration(n)`。
- 行为子系统：`StartReload` 算出要装几发，`TriggerReload(player, empty, shells)`；每一发在各自循环的
  ADD_AMMO 时刻写入弹数（`ShellTimes`），弹药数字逐发涨；提示音按区间调度——INTRO 一次、LOOP 每发一次、
  OUTRO 最后一次（`ScheduleLooped`）。
- **开火打断**：装填中按开火（弹匣里有弹），`FinishReloadEarly` 让手里这一发装完就停，跳到 OUTRO（泵动），
  之后自动补上这一枪（`FireAfterReload`）；未装的发数、未到的提示音都丢掉，OUTRO 的提示音按新终点重排。

## 三、自检新增

`gun/<gun>/reload.looped`（nova/xm1014/sawedoff 有分段、其余没有）、`reload.sections`（区间自洽）、
`reload.duration`（满弹匣 = INTRO + n×LOOP + OUTRO，且大于单段 clip）、`reload.cliptime`（INTRO / 第二个循环 /
OUTRO / 超出终点四个时刻的映射）、`reload.seconds`（行为子系统用的时长一致）。
证伪：去掉循环段的映射一行 → 三把枪的 `reload.cliptime` 失败；恢复后 0 失败。

# 0.32.0 社区反馈 M4 枪械耐久 + F07 烟雾画面遮挡（绘制顺序）

日期：2026-09-07。对应规划 F10（C1–C7）和 F07 的画面部分。

## 数据方案（M0 结论）

`Terrain.ExtractData` 对第 17 位做符号扩展，物品 data 只有 17 位可用。v3 布局（型号 6 位 + 弹量 8 位 + 消音器 1 位 + 格式标记）只剩 1 位空闲，
装不下 12 位整数耐久，也装不下实例 ID。规划的"实例 ID + 世界状态表"方案需要把弹量/消音器也搬进表里、改写所有 `GunSpec.GetRounds` 调用、
处理创造复制的 ID 共享和开箱模组配套，风险太大，这轮不做。

采用的 **v4 布局**（`Rendering/GunSpec.cs`）：
- 第 0–13 位：`(弹量 × 2 + 消音器) × 43 + 型号` 混合进制（型号 0–42，弹量 0–150，Negev 的 150 是最大弹匣）；
- 第 14–16 位：耐久等级 0–7（7 = 全新，0 = 损坏）；第 17 位不用。
- 耐久随物品走：换槽、入箱、掉落、拾取、创造复制都不需要额外表；同款两把枪各自有等级。
- **不解码 v1–v3 旧物品**：旧世界里的枪会被读成错误的型号/弹量（规划已定每版新世界）。
- 代价：等级只有 7 档（100/86/71/57/43/29/14/0 %）。每档内的击发数由 `SubsystemScGunBlockBehavior` 按"玩家 × 快捷栏格"计数并随存档保存；
  把枪换到别的格最多损失一档内的进度（对玩家有利）。精确到发的耐久要等实例 ID 方案。

- 只有真正打出的一发才计数，扣弹与扣耐久是同一次写入；空枪扣扳机、换弹、切枪、检视、消音器不计；创造模式不磨损。
- 等级 0 = 损坏：不能射击（提示"枪械已损坏，请到装配台维修"，2 s 限流），仍可换弹、装拆消音器、转移、维修；型号/余弹/消音器保持。
- HUD 第三行 `耐久 86%`；≤20%（即 14%）橙色；损坏红字。物品描述里也有 `耐久 86%（6/7 级，每级约 214 发）`。
- 日志：`gun wear: ak47 slot 2 level 7 -> 6 (214 shots per level)`、`gun repair: … level 2 -> 7 cost 1,1 ok=True`。

## 装配台维修（`World/ScWeaponRepair.cs`）

- 装配台列表第一项"维修背包中的枪械"→ 列出背包里耐久未满的枪（型号 · 耐久 · 第几格）→ 报价 → "维修"。
- 满修材料 ≈ 组装成本的 1/4：金属坯件 `max(1, round(B/4))`，精密机构 `M/4 向下取整`（M≥3 至少 1）。AK：1 坯件 + 1 机构；手枪：1 坯件；机枪：2 坯件 + 1 机构。
- 本次需求 = `ceil(缺失档数/7 × 满修数量)`，所以任何磨损至少消耗 1 件；满耐久的枪不出现在列表里。
- 点击时复核目标格的物品值与材料，扣料失败全部回滚；只改耐久，不动余弹/消音器/型号；创造模式免费但仍需点击。

## F07 画面遮挡（绘制顺序）

原版绘制顺序（本机 DLL 反编译核对）：地形不透明 0、原版模型 99、地形透明 100、发光 110、阴影 200、透明模型 201、粒子 300。
烟雾粒子原来在 **10** 号绘制，只读深度不写深度，之后画的动物、水面、粒子全都盖在烟上——这就是"烟外能看穿"的主因。
现在烟/火/闪光粒子改到 **310** 绘制（手雷弹体仍在 10），烟内遮罩按统一密度取值（深处 alpha 255，随高爆开口减弱），远距离烟的粒子数 12/6 → 16/12。
真机看：烟外看烟内/烟后、烟内看烟外、烟前实体、透明水面后的烟、第三人称镜头进烟。

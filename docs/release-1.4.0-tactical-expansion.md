# 1.4.0 本体＋1.0.0 战术同伴拓展

日期：2026-09-20。用户已授权：没有旧版盾牌资源，采用适配方案，直接制作独立拓展包。

## 安装与上手

同时安装以下两个文件；旧本体换成 1.4.0，不要同时启用两份 CS 武器本体。原有 1.3.3 等输出包保留。

- `output/[API1.9]CS武器1.4.0-作者ZH667-全量版.scmod`
- `output/[API1.9]CS战术同伴拓展1.0.0-作者ZH667.scmod`

本体不依赖拓展，单装本体仍可正常使用。拓展包名 `zh667.ScCsgoTactical`，本体包名保持 `zh667.ScCsgoKnives`。API 原生依赖解析要求本体至少 1.4.0。拓展只包含自己的 DLL 和资源，不重复装入本体或引擎 DLL。

1. 打开枪械台，在“战术拓展”分类制作盾牌、维修包或招募信标；“全部”中也可找到。创造背包另有“CS战术拓展”分类。
2. 拿着人质／CT／T 信标，对准 5 格内空旷地面的上表面使用，生成一名自动跟随的同伴。每位玩家最多一名；召唤落点需留出约两格高度。
3. 距同伴 3 格内，对准它按 **E** 或原版交互操作，打开装备面板。手机可用原版交互，触控映射也可绑定 E。
4. 把实际枪械或盾牌拖入左侧装备格。右侧四格装 CS 通用弹匣／霰弹；可拖回玩家背包。玩家物品栏包含全部十个快捷栏位置。
5. 选择“跟随”“守在这里”“前方掩护”；“停火”可随时切换。装备盾牌后前方掩护会走到主人前面约 2.5 格。
6. 维修时把受损盾牌放在快捷栏，手持维修包使用。修理快捷栏中第一面受损盾，恢复 1000 耐久，最多修至 2000。

## 防爆盾实际保护范围

持在手中即举盾，不能同时射击或近战；换成枪后即失去盾牌保护。盾体约 0.92 格宽、1.44 格高，2000 耐久。耐久按被挡攻击的原始威力向上取整扣除；最后一次挡住后归零，保留损坏盾供维修。创造玩家持盾不扣耐久。

根据命中方向与盾面做相交判定：正面盾面覆盖内的**子弹与近战**会被阻挡，盾后的人或生物也能受保护。侧面、背面、脚部与越过盾面的攻击照常生效。开窗按强化透明护板处理。配有原生可写物品栏的模组生物持盾可走同一逻辑，攻击方是否原版生物不影响标准 Attackment 判定。

这不是万能免伤或实体墙：本版不拦截火焰、环境伤害、爆炸范围伤害；模组绕过标准 Attackment 直接改血的攻击也不能保证拦截。攻击结算时保护身体，并没有把所有第三方投射物改造成与盾模型碰撞的实体。真正的通用爆炸遮挡需要可靠爆心及对应模组伤害接口，未凭攻击者坐标猜测。

## 同伴行为与装备

- 三种外观：CS2 CT SAS、T Phoenix、人质 hostage_a。均为友方同伴，CT/T 不是敌对阵营开关。本次还没有替换玩家自己的模型。
- 不主动搜寻或射击中立生物。主人或同伴受到标准攻击后，同伴在 32 格内还击攻击者；所有玩家、战术同伴和有人骑乘的坐骑视为友方。墙体或其他身体挡在中间时不射击。
- 武器使用同一把真实 CS 枪，保留涂装、实例编号、消音器、计数器、等级、击杀数、耐久及弹量。开火正常扣弹和磨损；普通换弹消耗实际弹匣，霰弹枪逐发装填，电击枪走充能状态。相容的本体生物减伤、击杀计数及电击控制入口继续使用。
- 同伴射击间隔至少 0.12 秒，射程最多 32 格；仍受枪械自身更慢射速、更短射程约束。霰弹以躯干单次命中结算总威力，没有把总伤害乘弹丸数量。本版不是 CS2 完整机器人战术／后坐力模拟。
- 普通跟随导航速度系数 0.7，举盾降为 0.35。超过 80 格原地等待，不瞬移穿墙。路径每 0.5 秒更新，主人受击只通知登记的同伴，不遍历整个世界找同伴。
- 打开装备界面时停止行动与换弹，避免整理物品期间继续消耗装备；关闭原版界面后恢复。玩家死亡或离开时停止跟随并等待；所有权按世界玩家索引保存。
- 死亡掉落携带的枪械、盾牌和弹药，不生成新复制品。解散要求先取空装备，解散不退招募材料。
- 持枪／持盾姿态、开火音效可用；未移植第三人称逐枪换弹动作、完整战术手势和台词。防弹衣、防弹头盔留作后续扩展。

## 资源与手机兼容处理

CT/T/人质网格、骨架、纹理和基础步行动作来自本机 CS2 VPK；原始大型导出未改动。派生资源只保留第三人称身体、手套、七段所需动作，纹理最大 1024。人质缺少探员模型的坐标转换根节点，已单独补齐，避免同名动画套用后横躺。

本机没有盾牌完整模型／举盾动作。盾体及握把是本项目适配几何，使用 CS2 保留的盾牌材质与七个真实中弹音效。同伴举盾采用双臂 IK 调整 CS2 持枪基础动作；第一人称使用本体真实 CS2 蒙皮手臂和 C4 双手持物基础姿态，校准到背面握把。不是声称提取到了原版举盾动画。

API 的 GPU 蒙皮矩阵有容量限制，直接装入 86～94 骨骼的原人物可能截断蒙皮。三个派生模型均限制为 48 个 GPU 骨骼，完整动作骨架保留。依据七段动作各五个时刻的表面误差，把小辅助骨骼权重合并到真实祖先：最大偏移 CT 2.05 厘米、T 2.21 厘米、人质 1.16 厘米，99 分位均低于 0.9 厘米。原始资源不变。

去掉动画 root_motion 平移，导航统一移动身体，避免身体跑出影子再回弹。盾牌第一人称投影与裁剪按每位同屏玩家的视口处理。装备页在窄屏缩减列数并支持纵向滚动。

## 存档与卸载

枪械物品布局仍为 v5，记录 schema 仍为 6；本次不改变枪型顺序、涂装编号和已有枪械字段含义。拓展库存继承原生 ComponentInventoryBase，接入本体枪械持有者扫描、恢复定位和事务，没有另做一份假枪数据。

同伴指令和主人索引用独立 `TacticalSchema=1` 保存；未知版本拒绝读取。拓展添加实体与物品，所以标记为持久模组。以后卸载拓展前应先取回枪械弹药、解散同伴、清理拓展专属物品并备份世界，不能把装过实体的世界当作纯材质包随意卸载。没有新增自动降级承诺。

### 玩家可以这样验收

1. 创造世界取三类信标各试一次；每次先解散前一位。同一玩家第二次招募应被拒绝，信标不消耗。
2. 生存世界给同伴一把有涂装、有计数器且已磨损的枪，以及两个弹匣。先打开装备页确认数值，再找怪物攻击主人，看它还击；有墙／其他生物挡枪时不应继续扣弹。点停火后应停止。
3. 换成盾牌并点前方掩护。玩家站在同伴身后，让正面怪物攻击；再分别测试侧面、背面、脚部和范围爆炸，确认保护边界。盾耐久降至零后应失效但仍可取回和维修。
4. 换弹中打开装备页，拿走枪再放入盾，等待后检查弹匣没被旧换弹扣走；关闭面板后同伴能继续走。离开、保存重进两次，再取回原枪确认涂装/等级/击杀/磨损/弹量符合期间实际消耗。
5. 手机窄屏和双人同屏分别打开装备页与举盾；检查按钮可点、十个快捷栏都在、盾牌不画到另一位玩家视口。观察坡地、楼梯、游泳和快速转向的跟随动作。

## 烟雾弹

烟雾弹每次飞行只响应 **一次人物/生物身体碰撞**。第一次仍保持原先反弹；之后忽略身体射线碰撞，继续受重力、墙壁与地面碰撞约束，避免不断被头顶弹起。

- 地形阻挡仍然有效，落地支撑保持 0.15 秒的判定不变。
- 保留现有引信、烟雾遇火规则和异常超时清理；不引入悬空定时爆烟。
- HE、闪光、燃烧弹、诱饵弹的身体反弹规则保持原样。
- 增加可选飞行字段 SmokeBodyBounceUsed；本次 Full/Lite 保存重读后不会重新获得人物反弹次数，旧存档缺字段时默认尚可碰一次。旧构建可以忽略/丢弃这个新标记，但保留原先位置、速度、时间等字段；跨回旧代码期间自然仍执行旧反弹规则，不能承诺旧版具有新修复。

使用生产 Move 方法、原生人物包围盒射线与可控地面/墙面夹具验证，在 60 FPS、20 FPS 和单帧 0.5 秒的物理小步情况下，烟雾弹从头顶反弹一次后能落稳；包含两次 XML 保存重读、旧字段缺失、墙壁阻挡与其他投掷物回归。此夹具不等同于手机所有坡面/拥挤地形已验收。

## 持续运行开销

人物仍保留完整 580/572 骨骼、完整动作采样和原索引。渲染相机矩阵只计算身体、蒙皮关节、模型网格父骨骼、当前武器辅助骨骼及其父链：

| 角色 | 原骨骼数 | 本轮 35 枪覆盖范围 |
|---|---:|---:|
| CT | 580 | **104–140** |
| T | 572 | **96–132** |

完整公开层级遍历仍保留，死亡姿态、手臂处理等需要它的路径不删骨骼。非蒙皮、带动画参与者、已触发原生根运动回退的路径继续走原生相机计算。模型替换按模型身份重建选择缓存，退出项目清理缓存。

握持姿态另缓存真正有数据的上半身骨骼索引，逐帧只覆盖这些项；仍为同样的局部矩阵，不降低动画帧率、不合并人物独立播放时钟。

原生对照覆盖所有片段正/反向采样、步态与中断、换弹、死亡、多相机时钟；35 种武器逐项检查蒙皮闭包与 0.7/1/1.3 模型缩放下相机矩阵。选择路径的所有实际使用矩阵与完整计算位级相同。

本轮桌面 3,000 次热相机矩阵对照约为 CT 95.49→25.66 ms、T 86.35→24.40 ms（轻量夹具）。这是单段代码的 Windows 测量，且可受其他测试负载影响，**不是手机整帧提升比例，也不承诺稳定 60 FPS**。以前已有的编译动画采样优化未当作本轮新增收益。

## 首用枪械与未知开销

小队装备确定后，尝试提前准备其 NPC 几何缓存：

- 主线程从 ContentManager 取得流并复制自有字节，不把共享流交给后台。
- 后台仅解码和解析纯托管几何数据，不创建纹理或 GPU 对象；最多保留两项待取任务，同一武器去重。
- 首次实际使用时取得结果并进入原有几何缓存；若尚未完成，仍可能等待，等待耗时记入日志。清理后旧任务不会回填新世界缓存。
- 解码/校验失败在使用时明确抛出，不隐藏为重建成功；线程错误被观察，保留原子小队创建与失败回滚行为。

**没有一次性预载全部枪或枪皮。** 纹理和 GPU 上传仍在主线程按需完成，本轮新增了纹理耗时记录；尚未证明所有首次加载尖峰已经消失。预读取最多覆盖部分首用资源，手机上收益需由完成数和等待时间判断。

动画控制器的状态规则快捷求值在速度临界值与原生比较时未能保持一致，已从正式代码撤下。原生状态求值、事件与过渡保持不变，控制器内临时分配暂不宣称已解决；新增分项供下一次实机确定具体原因。

## 新日志

性能 revision 为 **mobile-common-20260927**，公开版本仍为 1.3.0。

- CS_PERF summary：新增进程分配增量、已采样时间合计、实际/完整骨骼计数、骨骼遍历次数、GPU 缓存网格数和预读取计数/等待时间。进程分配含后台分配，不能等同于本 mod 净存活内存。
- CS_PERF long-frame：≥100 ms 帧或战术更新间隔 ≥1 秒时，记录帧号、采样作用域的帧号、GC Gen0/Gen2 增量及各段耗时；每 10 秒最多 6 条，多余记录计数，避免每帧刷日志。
- CS_RESOURCE：单次 ≥10 ms 的冷操作，分别记录 decode、actor-parse、npc-parse、npc-read-ahead、texture；每进程最多 64 条，同一资源/操作去重。作用域耗时包含其子调用，不应重复加总。
- ActionApply：区分持枪姿态/动作覆盖与基础人物动画。

这些日志仍不直接测 GPU 时间、引擎物理或寻路的完整成本。long-frame 的 scopesFrame 与 index 显式保留，不能把不对应的作用域时间强归因到同一帧。下次手机重点比较固定人数的窗口、首次/重复小队召唤、NEO 换模、世界重进，并关注动画更新分配和未覆盖的帧耗时。

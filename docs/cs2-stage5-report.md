# 阶段 5 报告：特效与开镜

日期：2026-09-04。版本：0.16.2。上一版：0.16.1（阶段 4）。

## 1. 做了什么

1. `tools/cs2_kv3.py`：Valve KV3 文本读取器（vpcf / vmat / vnmclip / vnmskel 通用）。
2. `tools/cs2_effects.py`：从各枪 `.vdata` 与它们播放的 `.vpcf` 里抽出枪口位置、
   火光包络、曳光参数，产出 `AnimationData/cs2_effects.json`。
3. `src/ScCsgoKnives/Animation/Cs2Effects.cs`：运行时读这张表。
4. 火光：cs2 profile 下按 CS2 的寿命/序列帧数/颜色/透明度/淡出画，位置用 vdata 的 `m_vecMuzzlePos0/1`。
5. 曳光：`Fire` 每第 N 发记一条，世界空间画一条按 CS2 速度飞行的拖尾。
6. 开镜：换成 CS2 自己的 `scope_circle` 贴图。

## 4. 计划书的一处不成立

计划书 §3 阶段 5.3 说"开镜遮罩改用 `07_scope/materials/dev/scope_mask*` 的真实贴图"。
**那个文件是 1×1 的纯白像素**——`materials/dev/` 下的占位图，没有内容。
CS2 的 HUD 真正画的是 `07_scope/panorama/images/hud/scope/scope_circle.png`（512²，黑色渐晕），
已改用它，并在 §3.C 量出了它的几何。

## 5. 未解决项

1. **火光仍然是一张精灵图，不是粒子系统**。CS2 的 AK 主火光一次发 8 个粒子，各带曲线半径、
   阻力 0.2、还有一遍只进 bloom 的重绘；我们画一张按 CS2 包络（时长/序列/颜色/透明度/淡出）
   变化的贴图。`cs2_effects.json` 里每条 `unmodelled` 就是明确没做的部分：
   AK/M4 是 bloom 重绘，AWP 还多 `C_OP_ColorInterpolate`/`InterpolateRadius`/`SetFloat`/`SpinUpdate`。
2. **曳光的宽度是估计值**：CS2 用 `C_OP_RenderTrails` 配 spark 贴图，宽度由贴图与半径曲线决定，
   我们画的是一条 0.012 引擎单位（约 12 mm）半宽的相机朝向带。速度、长度、淡入、颜色、频率都是读的。
3. **弹壳没做**（计划书说"至少做曳光"）。
4. **AWP 火光的颜色**：`uweapon_muzflsh_awp_primaryflash.vpcf` 没有 `C_INIT_RandomColor`，
   颜色来自贴图，所以退回白色。
5. **开镜的倍率与时间**沿用现有值（本来就是 CS2 的）；镜片脏污 `scope_lens` 和十字虚化
   `scope_line_blur` 没用上，只用了渐晕圈。

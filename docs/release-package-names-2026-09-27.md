# 交付文件名和游戏内介绍调整

按用户要求，六个已验证扩容核心恢复原普通文件名：1.3.0全量／轻量，以及1.0.0、1.2.0双向兼容全量／轻量。游戏内统一显示“CS武器 · 全量版”或“CS武器 · 轻量版”，版本仍由版本字段显示；描述只介绍武器、制作、成长、操作和对应版功能，不显示修订号、schema或玩家恢复诊断。

只有根modinfo和存在时的内嵌核心modinfo中的Name／Description改变。所有DLL、资源、依赖、PackageName、版本和内部兼容元数据与已验收的扩容包相同，未重新编译玩法。逐成员内容及未改动成员的压缩流比对通过，六包游戏原生资源／格式加载检查通过。此前容量、存读、库存和版本往返验证继续适用于相同DLL；没有新增手机实测结论。

`output/release-package-names-20260927/manifest.json` 是当前普通名称包的哈希清单。`output/release-capacity-20260927/manifest.json` 保留为之前修订文件名的验证来源，不是当前包哈希。原普通包和此前带扩容修订后缀的包均移至 `output/history-capacity-names-20260927` 对应子目录，可恢复；不是删除。探员、极简包以及安装目录、世界文件保持原样。

同名不意味着旧文件具有新能力。新版首次正常保存即使用布局6／schema7，之后的双向互换须使用这次配套更新的核心；之前传播的同名旧包不支持新档。此说明保留在发布文档，不写进游戏内功能介绍。

打包入口 `package_capacity_fix.py` 已改用通用展示文本；本次使用 `normalize_package_names.py` 从精确哈希的已验收包仅更新展示字段，生成普通名候选和原生检查报告，再按清单归档旧文件并替换交付。

# 闪光弹修复（1.1.7）

本地 CS2 提取目录中，闪光弹的整屏致盲属于运行时屏幕效果，粒子资源只负责爆炸瞬间的辅助光效。模组原先把普通闪光覆盖的最大透明度限制在 245/255，因此画面不会完全变白；同时存档读取把致盲剩余时间截断到 2 秒。

本版将普通闪光峰值改为完全不透明白色，保留减弱闪光设置的低亮度行为；正面近距离致盲恢复时间提高到约 4.5 秒，并把存档读取上限同步到 5 秒，避免重进世界后突然提前恢复。覆盖仍使用平滑曲线淡出，爆炸后的余闪保留约 1.15 秒。

这次调整的是屏幕致盲和恢复时间。游戏 API 没有按玩家单独衰减全部世界音频的接口，闪光音效继续使用已有 CS2 音效，未伪造全局静音。

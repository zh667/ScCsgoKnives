# 玩家 T / CT 外观 1.0.0，本体 1.4.4 Full，战术拓展 1.1.4

2026-09-20。新增独立可选外观扩展，在 NekoMeko Model 的角色列表选择
`CS2 · CT SAS` 或 `CS2 · T Phoenix`，可切回其默认角色。不会改变玩家阵营、
血量、碰撞或装备属性。NekoMeko 原有玩家索引、模型键／皮肤键和重生缓存继续保存选择。

## 安装和使用

退出游戏后安装，每种模组只启用一个版本：

- 本体 `[API1.9]CS武器1.4.4-作者ZH667-全量版.scmod`。
- 战术拓展 `[API1.9]CS战术同伴拓展1.1.4-作者ZH667.scmod`。
- 外观 `[API1.9]CS玩家T-CT外观1.0.0-作者ZH667.scmod`。
- NekoMeko Model 1.1；未安装时可使用随附的 `[API1.9]NekoMekoModel1.1-源码构建.scmod`。
- Neorxna 1.4，用户游戏内已有；本次不重新分发它。

在玩家编辑界面进入 NekoMeko 的角色／皮肤选择，选择 CT SAS 或 T Phoenix 后确认。
使用游戏原有第三人称或 NekoMeko 肩后视角即可看自己。第一人称持 CS 武器仍使用
原有 CS2 手臂。卸载外观扩展前先切回默认角色。

NekoMeko 源码构建包来自公开仓库提交 `48c8f4fd8269441eb59add85e9538d17d739f95c`，
原始代码和资源未改动，附带 Unlicense 和构建来源；它不是作者发布的二进制原包。
本次没有自动修改已安装 Mods 或世界。

## 模型与眼部修复

外观扩展重用战术包模型，沿用原生 GPU 蒙皮。NMM 的普通刚体骨骼动画、重复持物和
头像小人直接调用路径作了限定适配。本体 1.4.4 在带蒙皮模型上清理旧的普通人形持物姿势，
避免换角色后旧武器残影；持枪、刀、投掷物绑定到 CS2 手骨，盾仍由战术拓展绘制。

战术拓展 1.1.4 同时修复同伴、敌人和玩家共用的眼部：

- CT 的源镜片为金属材质，普通漫反射丢失原反射效果后发白。以源底色／AO 烘焙深色镜片和微弱静态高光。
- T 的源材质启用了专用眼球着色器；现在将源眼球纹理和双眼遮罩烘焙为固定前视虹膜／瞳孔。
- 几何、UV、骨架、蒙皮权重及动画 accessor 与修复前逐项相等，原始 CS2 导出不变。

首版包含待机、行走、跑步、持枪／举盾，以及简化的蹲伏压缩和躺下适配。
没有声称移植动态目光、CS2 金属反射、专用游泳／攀爬／骑乘片段。
头像小人显示待机预览。完整第三人称换弹、切枪、检视是用户新追加的下一阶段。

## 开发复现与清理

运行 `tools/dev.ps1 pwsh -File tools/prepare_appearance_reference.ps1` 准备固定源码。
通过 `-p:NeorxnaDll=<已提取的 Neorxna 1.4 DLL 绝对路径>` 构建
`tools/AppearanceCheck`；`tools/NekoMekoReference` 只编译源码，不运行上游 ModZipper。
使用 `pack_tactical.py`、`pack_appearance.py` 打包，`verify_appearance.py <游戏安装目录>`
验证。暂存文件均在项目 E 盘 `.tmp`，不写入游戏安装目录。

按用户授权清理旧交付包及可重建的小报告／日志，精确路径、哈希和回收状态见
`cleanup-20260920.json`。采用 Windows 回收站；存档、兼容基线、备份、当前包和 CS2
源导出未列入清理。

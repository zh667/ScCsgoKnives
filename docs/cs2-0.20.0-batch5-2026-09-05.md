## 一、R8 左轮

- vdata `m_flCycleTime = [0.5, 0.4]`：第一个是扣锤击发，第二个是扇射。`cs2_weapons.py` 现在保留 pair 的第二个值
  （`CycleSecondsAlternate`），驱动脚本只在 rig 有 `shoot_alt1_*` 时把它写进 GunSpec（手枪的 `[0.15, 0.3]`
  第二个槽 CS2 从不用）。
- 左键：先播 `prepare_shoot_revolver`（扣锤，控制器新增 `Prepare` 动作），到时自动击发 `shoot1`。
  **vdata 没有单独的扣锤时长**，这里取主循环 0.5 s 当扣锤时间——这是本批唯一标"估计"的数。
- 右键（瞄准键，左轮没有镜/连发/消音）：`shoot_alt1_revolver` 立即击发，散布与后坐用 vdata 的 alternate 值
  （散布 4.57° 对 0.14°），循环 0.4 s。
- 未做：`chamber_position_anim_revolver_0..7`（弹巢按剩余弹数转到位）、`dryfire`（空仓扣扳机的咔哒）。

## 二、双持贝瑞塔

- 30 发 = 左右各 15。rig 有 `shoot_left1 / shoot_leftlast / shoot_rightlast / idle_leftempty / idle_leftrightempty`
  五段专用片段，命名本身说明了顺序：**左枪先打**（满弹匣偶数发是左枪），剩 1 发时左枪打出最后一发
  （`shoot_leftlast`，随后 `idle_leftempty`：左枪套筒后挂、右枪还有一发），最后一发是右枪（`shoot_rightlast` →
  `idle_leftrightempty`）。控制器 `ShootClip(..., roundsBefore)` 与 `IdleClip(variant, rounds, scoped)` 按此实现。
- 枪口：rig 有 `muzzle_l / muzzle_r` 两根骨；GunSpec 新增 `LeftMuzzleBone`，行为子系统按选中的片段决定
  火焰和曳光从哪只枪出来；渲染器每帧记录四种枪口骨（muzzle / muzzle2 / muzzle_l / muzzle_r），按名取用。
- 换弹一段 3.77 s，两枪各换弹匣，11 条提示音。

## 三、Zeus x27 电击枪

- 1 发、无换弹片段、`m_flRange 120 in`（3.05 m，`RangeBlocks`）、伤害 500、散布/后坐 0。
- 模型事件里没有枪口粒子，曳光 `weapon_tracers_taser` 是一条电线（rope 无滚动贴图，ribbon 画不了）：
  GunSpec `MuzzleEffects = false`，火焰与曳光都不画；自检改为断言"表里确实没有"。
- 打完后 **30 s 充能**（`RechargeSeconds`）——CS2 的 Zeus 充能时间不在 vdata 里，标"估计"；充好时播
  `Weapon_Taser.ChargeReady`（C2 那批解码的 zap，安装脚本新增"片段之外的提示音"表）。

## 四、其它

## 五、自检新增与证伪

`gun/revolver/altfire`（有 shootAlt 才有替代循环，且等于 vdata pair 的第二值）、`altfire.clip`、`altfire.prepare`；
`gun/elite/dual.alternation`（30→左、29→右、2→左末发、1→右末发）、`dual.idles`（1→左空、0→双空、2→普通）、

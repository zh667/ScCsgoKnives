# CS 武器 1.7.0 反馈修订发布记录

## 本次最新版内容

- 枪械制作等级按“手枪/霰弹枪/冲锋枪 → 步枪/狙击枪”分段，已有枪械不会因等级门槛被锁定。
- 枪械台预览保留快速跳级入口，便于查看高等级属性。
- 手榴弹支持快速投掷；模组设置可切回完整准备动作。
- CT 重刀使用遮蔽派生手臂网格，去除袖子内侧的裸臂穿模；原始网格未改写。
- 探员语音为独立可选附属包，支持中文/英文选择、CT/T 玩家手动选句和 NPC 随机事件语音。
- 默认玩家语音按键为 **Z**。原版 V 键已被相机切换占用，因此不再使用 V；Z 仅作为 CS 语音默认键，仍可在武器按键/触控设置中改绑。
- 不生成自动备份；替换或迁移前由玩家自行备份世界。

## 旧档与兼容

- 枪械 item layout 仍为 5、GunRegistry schema 仍为 6、成长规则存储版本仍为 7；枪型/刀型/皮肤 ID 不变。
- 连狙射速在运行时由当前等级计算，不改击杀数、升级门槛、伤害、弹量、耐久、容量或已有记录。两把连狙仍享受狙击枪原有的升级难度优惠。
- 刀具只修改原有 skin 位，其余物品数据及光照位保持；不分配枪械记录。材料扣除和原刀替换使用既有库存日志，失败回滚；无法立即补偿时写入已有恢复队列，用持久背包归属重试。
- 闪光读取仍用原字段，扩大有限时间夹取上限，同时保持旧存档可读；烟雾状态结构不变，已存在烟雾按新尺寸渲染。
- 本次无新的格式转换，不因本次更新单独生成世界迁移副本。此前旧版升级/跨世界规则的备份保护仍保留。没有承诺任意旧 DLL 都可安全降级。

## 抛壳来源与预算

提取工具为 ValveResourceFormat / Source2Viewer CLI 20.0，输入本机 CS2 `pak01_dir.vpk`，未使用自制替代模型。模型、颜色贴图、事件/挂点来自已提取资源与此次补提取；声音为 CS2 `tink/bullet_casing_01.wav`、`shotgun_shell1.wav`。可复现导入脚本：`tools/import_cs2_casings.py`；哈希与面数：`docs/cs2-casing-sources-2026-09-18.json`。

Full 最多 48 壳、寿命 2.5 秒、最多两次地形接触；512 版最多 16 壳、寿命 1.2 秒、一次接触。落地声全局间隔至少 0.1 秒，24 格外不画。待播事件最多 32 条，迟到超过 0.2 秒或动作/持有槽位改变则丢弃。R8 转轮和 Zeus 开枪不虚构抛壳。高等级连射抢先打断拉栓时，可取消尚未发生的装饰抛壳，不延迟伤害或擅改射速。

这是 Source 2 资源在 SC 的适配：重力、旋转和有限反弹不是完整 Source 2 物理模拟。抛壳依赖本地最近绘制的第一人称挂点，不宣称覆盖独立服务器上的全部第三人称/网络玩家效果。

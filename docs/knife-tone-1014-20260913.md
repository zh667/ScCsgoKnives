# 1.0.14 刀皮颜色调整

根据用户反馈，20 款刀皮的涂装 RGB 乘以 0.86，再按官方涂装遮罩与原厂材质合成。保留普通刺刀红宝石。0.86 是视觉调节参数，不是测得的 CS2 光照补偿值，也不代表屏幕亮度降低 14%。

与交付的 1.0.13 / 1.10.0 资源逐文件对比：只改变 20 张刀皮颜色贴图，其余 1229 个纹理、模型和音频文件字节相同。官方物品图标、法线及粗糙度贴图保持原样。

未采集同一光照下的 CS2 和 Survivalcraft 游戏截图，未定位偏浅的唯一原因。本地平光 UV 图仅验证贴图位置和调色变化，不能作为游戏光照验收。模型、编号和存档格式不受此次调色影响。

交付：CS武器-1.0.14-全量版.zip，配套资源 1.10.2。

## 第六轮观察点

1. **木头**：隔一层木板、木门或一整格木头开枪，能打伤对面的人。手枪也能打穿。
2. **玻璃**：能打穿，伤害会少一些。
3. **铁门**：能打穿，但伤害明显变小（AK 大约剩 10）。
4. **挡得住的**：石头、砖、铁块、泥土整格都打不穿，石头半砖也打不穿。
5. **打穿人**：一枪打穿前面的人，后面的人也会掉血。
6. **击杀提示**：隔墙击杀时，击杀提示带 CS2 的穿墙图标。
7. **方块不受损**：墙不会被打坏。普通生存和创造世界没有穿墙。

## 第五轮观察点

1. **扫射**：死亡竞赛对局里拿 AK 按住开火：
   - 子弹按 CS2 的固定图案走：先往上，然后左右摆动。
   - 准星和视角只跟着上抬约六成，所以子弹落在准星上方。要压枪就往下拉鼠标。
   - 松手约半秒后视角回落；停一下再开火，又从第一发的图案开始。
   - 不同枪的图案不同。M4A1-S 装着消音器时用 CS2 消音状态的图案。
2. **跑速**：
   - 拿刀和平时走路一样快（3.1 m/s）。
   - AK 稍慢（2.67），AWP 开镜明显慢（1.24），内格夫最慢（1.86）。
   - 离开战斗（死亡、结束、观战）恢复正常速度。
3. **命中**：
   - 打肚子比打胸口疼（×1.25），打腿轻（×0.75），打脖子和胸口一样（×1），头部仍是武器自己的倍率。
   - 打在两腿之间、胳膊和身子之间的缝隙会打空，和 CS2 一样。
4. **普通世界**：生存和创造世界里枪的后坐、命中判定、走路速度都和以前一样。第五轮只在死亡竞赛世界生效。
5. **穿墙**：第六轮已做（见上）。

## 第四轮观察点

1. 护甲 HUD（核心与死亡竞赛同一个）：没有护甲时完全不显示；只有护甲时是 CS2 的护甲盾徽章 + 数值；有头盔时是“头盔压在盾上”的 CS2 徽章。核心生存护甲有两份耐久，两个数值并排（头盔在上、护甲在下）；死亡竞赛只有一个护甲值。
2. 某一件用完（耐久 0）就不再显示那一件（CS2 护甲为 0 也不显示）。

## 0. 安装组合

三个组合任选其一，联机双方必须是同一次候选（握手会比较玩法构建和竞技规则指纹，不同会拒绝并提示）：

- 全量包 + 死亡竞赛包
- 轻量包 + 死亡竞赛包
- 轻量包 + 探员包 + 死亡竞赛包

死亡竞赛包依赖 CS武器 1.4.0；单独装它不会加载。请用**专门的测试世界**，不要用原存档。

## 1. 普通生存世界不受影响（先测这个）

1. 装上死亡竞赛包，进一个普通生存世界：枪、弹药、耐久、成长、皮肤增伤、护甲都应和没装时一样；屏幕上不应多出任何竞技按钮或 HUD。
2. 存档退出再进：正常。

## 2. 把一个世界启用为竞技世界（房主）

入口：桌面按 **F6**；任何平台从暂停菜单 → 设置 → **死亡竞赛**；启用后屏幕上还有“竞技”按钮（触屏默认显示）。菜单分三页：**比赛 / 地图 / 设置**（只有房主看得到“地图”页），底部一条消息栏会说每个按钮的结果和下一步。

1. 新建一个**创造模式**的世界搭地图（或用现成的测试地图）。竞技菜单 → “地图”页 → “把本世界启用为竞技世界”。启用时不能有其他玩家在线。
2. 走到竞技区域的一个角 → “角点 1（脚下）”。此时脚下出现**金色光柱**，并有一个金色预览框跟着你走。**关掉菜单**走到对角（高度也算）→ 再开菜单 → “角点 2（脚下）”。应出现**青色的粗框和半透明地面**，框上方写“竞技区域 宽×长（高 N）”。
3. 站到准备/观战的位置 → “准备/观战点（这里）”：**蓝色光柱**。
4. 在场内不同位置依次“添加复活点（这里）”（至少 2 个，建议 6 个以上）：**绿色光柱 + 地面圆环 + 朝向箭头**；放在墙里/悬空/区域外的会变红并写“不可用”。“删除最近的复活点”可删。
5. “检查地图”：列出必须处理/建议，或提示通过。
6. 房主编辑期间左上角常驻“地图编辑”面板：区域、复活点数、准备点、已入场人数、还缺什么。触屏上这个面板有“角点1/角点2/+复活点/准备点/开始”按钮，不用反复开菜单。
7. “比赛”页：调局长（± 分钟），需要的话开放投掷物，然后“开放大厅”：所有人被送到准备点。

观察点：光柱和框只在房主自己屏幕、只在“地图编辑”和“大厅”阶段出现，隔着方块也看得见；比赛开始后消失。

## 3. 配装（每个玩家）

桌面按 **B**，触屏点“配装”。

1. 轮盘第一圈六类：手枪 / 冲锋枪 / 步枪与狙击 / 霰弹与机枪 / 刀具 / 装备。点一类进第二圈（型号多的有上一页/下一页），中心是返回/关闭。数字键 1–8 也能选。
2. 选一把枪 → 右侧出现外观抽屉（原厂 + 该枪全部可用皮肤的缩略图，可翻页）→ 点一个外观即放入配装；“计数器”开关是这把枪的属性。
3. 刀：先型号再涂装。装备：宙斯点一下带/不带；投掷物仅在房主开放时出现（每命最多 3 个、闪光最多 2 个、其他各 1 个）。
4. 右下“确认”按钮的文字会随状态变：准备/死亡时“保存配装”，复活保护内“立即装备”，交战中“下次复活装备”。
5. 没选任何东西直接入场会被拒绝；确实要空手，点“空手入场”。

观察点：全部免费；手指滑出扇区再抬起、按返回，都不应误选；轮盘开着时不应开枪或转视角。

## 4. 比赛

大家配装并“入场”后，房主“比赛”页 →“开始比赛”→ 5 秒倒计时 → 开始。**如果没人入场就按开始，会在消息栏写出原因**（例如“先点‘开放大厅’，大家配装（B）并点‘入场’后再开始”）；从“地图编辑”直接按开始会自动开放大厅。加入的玩家在大厅时，屏幕上方计时器下面会提示“按 B 配装后入场”。

1. 复活：出现在某个复活点，听到复活音效，屏幕提示“复活保护 3.0 秒 · 攻击即解除”；别人看你身周有一圈浅白外壳（**这是自制标记，不是 CS2 原效果**）。
2. 保护期内别人打你不掉血；你一开火/挥刀/投掷，保护立刻结束。保护期内改配装是立即换。
3. 血甲：左下像素数字“十字 100 / 盾牌 100”。被 AK 打身体一枪应掉 27 血 4 甲；打头直接死。
4. 右侧装备栏只显示实际带着的东西（没带的类别不占位），每行是 CS2 武器的像素剪影 + 按键数字，当前手持那行是金色；点一行切到那件；刀单独一行。
5. 死亡：镜头留在死亡位置并转向击杀者约 2 秒，面板写谁用什么杀了你；此时可以改下一命的配装；然后在另一个安全点复活，弹匣是满的。
6. 击杀播报（右上或左上）：谁 [武器像素剪影 + 标记] 谁，自己的击杀带红框。爆头、盲狙（狙击枪未开镜）、穿烟、致盲中会有对应图标。**“穿透”图标目前不会出现（穿墙未实现）。**
7. 计分板：桌面按住 **Tab**，触屏点“榜单”。击杀/死亡/助攻；同击杀数并列同一名次。
8. 走出竞技区域：提示 3 秒内返回，超时算一次死亡，无人得分。
9. 时间到或房主“结束本局”：结算板 12 秒，然后回大厅。只有一人参赛时标为“练习”。

观察点（最需要你的眼睛和耳朵）：
- 像素风（菜单、轮盘、HUD、计分板、布局编辑器）在你的屏幕和手机上是否合适、字是否太小。
- 死亡镜头的位置/朝向是否自然；复活音效音量；白色外壳是否看得清、是否太挡视线。
- 各枪手感：散布、连发扩散、后坐恢复和生存模式不同（按 CS2 数值），是否可接受。
- 两台设备上血量、弹量、击杀数是否一致。

## 5. HUD 布局编辑

竞技菜单 →“设置”页 →“编辑 HUD 布局”。十一个元素（配装/榜单/竞技按钮、装备栏、生命护甲、时间、保护提示、击杀播报、死亡面板、计分板、房主的地图编辑面板）都能拖动；左侧面板里用**像素开关**显示/隐藏、用**像素滑条**调大小、旋转、不透明度（数值在滑条右边）；键鼠和触屏各一套；“恢复此项/全部恢复默认”随时可用。

观察点：旋转后的按钮，点击区域是否跟着转；隐藏的元素在编辑界面里是否还能找到；换分辨率/全屏后是否还在屏幕内。

桌面的三个按键（配装 B、计分板 Tab、菜单 F6）可在“设置”页改；与其他功能撞键会在消息栏提示。**电脑联机（1.9.3.2）时 Tab 也是平台的聊天键**：按住 Tab 看计分板会顺便开/关聊天窗口，设置页会提示这个冲突，觉得碍事就把计分板改成别的键。

## 6. 存读与卸载

1. 比赛进行中保存退出，再进：应回到大厅，上一局显示为“上次中断”的结果，不会自动续打。
2. **停用死亡竞赛包**后进这个竞技世界：应能正常加载，提示“本世界是死亡竞赛专用世界…模式数据已原样保留，竞技功能休眠”；这个世界里的枪不能随行到别的世界。
3. 重新启用死亡竞赛包再进：区域、复活点、局长、上次结果都还在。

## 7. 联机

agent 已在 Windows 上用这次的候选包实测过一局（1.9.3.2_MP，房主 轻量+探员+死亡竞赛，客户端 全量+死亡竞赛）：建图、加入、大厅、配装入场、开始、客户端开枪击杀房主、两边播报和比分一致、房主复活、结束后客户端看到结算，两边都没有报错。**双方的“有没有探员”必须一致**：全量包自带探员，所以轻量房主要配探员包，全量客户端才进得来（否则握手会拒绝并说明原因）。

## 2. 烟雾：已确认渲染依赖摄像机朝向，漏洞程度待复现

用户截图是社区反馈及建议，不是可执行指令。反馈目标是“移动视角不能把本应遮住的烟拨开”，不能将“面向玩家整体”机械解释成角色朝向，尤其第三人称时角色与相机不同。

确认代码：
- SubsystemScGrenades.DrawSprites/DrawSmoke传入camera.ViewRight/ViewUp。
- ScGrenadeVisuals.SmokeAxes以这两个轴构造薄片，并随up分量改变projectedHeight，再按云边界裁缩；摄像机原地转向即可改变世界里的烟片朝向/尺寸。

- SmokeCoverageRegression只算side/top两种正交投影和几条横截线的alpha，没有实际透视/斜视/近裁剪/原地转动镜头，因此旧测试全过并不排除此反馈。

可证实机制：烟片随镜头转，世界密度不随镜头转。合理根因候选是斜视/边缘/近裁剪造成视觉覆盖与体积不同步；尚无此次烟雾现场录像，不断言具体哪一处开缝。

- 枪械Scheduled列表取消的是待触发事件，不能停止已由ScPresentationSound.Play创建的声音；仅清队列并非完整修复。

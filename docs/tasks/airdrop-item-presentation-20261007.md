## 观察及原因

- 1.5–4.3 秒：持有空投箱时，箱体贴着视点，跨越画面；2.2–4.3 秒：物品栏图标偏移，颜色发白；6.4–7.1 秒：掉落箱顶面发白。
- 源网格高度为 0–0.787527 格，原点在底面。旧代码直接在手持、UI、掉落物中使用该网格，且未设置 FirstPersonOffset/InHandOffset，默认零偏移。API 1.9.3.1 的 ComponentFirstPersonModel 在视点上按这些字段放置物品；图标和掉落物同样围绕原点旋转。
- 第一轮为 UI 预建独立、固定光照副本，但没有解决材质混合。用户随后提供两张截图，确认物品栏、掉落物仍发白，截图中的手持也发白；第一轮颜色验收失败。原截图为 `C:/Users/张衡/AppData/Local/Temp/codex-clipboard-0db025eb-f289-4ed9-90aa-6022c1eb8351.png`、`codex-clipboard-1723bdfe-7fde-4676-80ed-33fe1a9fc2bb.png`。
- 第二轮确认：原 PNG 的 98.4711% 像素 Alpha 小于 255，源 FBX 的透明度系数为 0、无透明度贴图；箱体是实体材质。实际 API 1.9.3.1 的 `DrawMeshBlock` 默认使用 AlphaTest 和 `BlendState.AlphaBlend`（One / InverseSourceAlpha），原 RGB 没有预乘 Alpha，背景因此叠加到箱体上。第一轮离线渲染禁用了混合，漏掉了此缺陷；不能把它归因于第三方着色器。
- 本轮只为箱体新增不透明绘制路径，保持原生变换、顶点阴影、世界光照、采样、深度及背面剔除。物品显示和下落箱复用此路径；放置箱本来就是 `SubsetOpaque`，不变。原贴图 RGB/Alpha、GLB、数据库和资源成员全部保持原字节，维修包、拆弹器等仍走原生材质。

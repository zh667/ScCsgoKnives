## 复现（dma2，单机 1.9.3.1 隔离副本，真实按键/鼠标点击）

“房主点开始没反应”的确切原因：

1. 菜单里的“角点 1”只记在菜单面板对象里；关菜单走到对角再打开菜单时，那是一个新面板，角点 1 已丢失，按“角点 2”又只记成新的角点 1——竞技区域永远设不上。
2. 于是“开始比赛”被拒绝，拒绝理由“还没有设置竞技区域的两个角点”写在面板最上方，而“开始”按钮在要往下滚动才看得到的位置——按下去看起来就是没反应。
3. 区域框和复活点是细线、受深度遮挡，站在场地里几乎看不见。

## 改动（第二轮）

- 角点改存在子系统（跨菜单开关保留），设第二个角点即生成区域；“开始比赛”被拒时，菜单底部固定消息条 + 屏幕提示同时显示原因与下一步（如“先点‘开放大厅’，大家配装（B）并点‘入场’后再开始”）；从“地图编辑”直接按开始会自动开放大厅。
- 菜单改为三页（比赛 / 地图 / 设置）不滚动；非房主看不到“地图”页。
- 编辑可视化：始终可见的粗框 + 半透明地面、7 格高的光柱 + 地面圆环 + 朝向箭头 + 带底板的文字标签；角点待定时显示“走到对角”预览框；房主编辑期间左上角常驻“地图编辑”面板（触屏上有角点/复活点/准备点/开始按钮）。
- 丢弃钩子名改为引擎实际调用的 `UpdatePlayerInputDrop`（r1 实测：按丢弃后两把枪都还在）。
- 关键操作写 `[CS_DM]` 日志（启用、角点、区域修订、开始被拒原因、阶段变化、每条命的装备、击杀）。
- 像素风：自绘像素面板/按钮/滑条/数字字体（缺角像素框、CS2 深色面板 + 金色强调，点采样）；CS2 自己的武器/击杀标记 SVG 栅格化成 106 个像素剪影（`tools/build_dm_pixel_icons.py`，记录 `deathmatch-addon-pixel-icons-20261003.json`）。没有拷贝 CSMC 的资源。中文仍用游戏字体（包里没有像素中文字体）。

## r1 实测（单机 1.9.3.1，测试包 dm-r1，作业 `dm-r2-sp-r1-01`，错误 0）

整条流程用真实点击走通：启用 → 角点 → 区域 9×13 → 4 个复活点 → 准备点 → 检查通过 → 无人入场时开始被拒（理由清楚）→ 开放大厅 → B 轮盘买 AK + 沙鹰 → 确认 → 入场 → 开始 → 倒计时 → 进行中（hp100/ap100，枪在 1/2 号位）→ 丢弃无效 → Tab 计分板 → 结束本局 → 结果 → HUD 布局编辑器。

截图看到并在 r2 修正的问题：

- 字体里没有 ✓/✗：编辑面板显示成方框 → 改为文字“已设/未设/已定”。
- 半透明颜色没有预乘（引擎 AlphaBlend 是预乘混合）：区域地面成了一整片亮青、计分板自己那一行成了实心金底金字、复活保护提示底色发白 → 全部改为预乘颜色。
- 3D 文字小且压在亮色地面上看不清 → 加深色底板、放大、随距离放大；站在点上时不再画穿过镜头的光柱和箭头。
- 装备栏每行只显示数字、没有武器剪影 → 加诊断（缺图标时写日志并显示武器名），r2 用探针查原因。
- HUD 布局编辑器还是原版勾选框和滑条、标题重复 → 换成像素开关按钮和像素滑条（数值用像素数字显示）。

## r2 与 dma3 实测发现并已修的问题

- 俯视时 3D 标签被压扁成一条线：引擎的 `camera.ViewUp` 不垂直于视线 → 改用与视线垂直的屏幕上方向。
- 装备栏剪影时有时无（联机客户端有，单机和房主没有）：引擎对同一批次层用不稳定排序，按钮自身的图标与底框同层 → 像素图标统一走批次层 1。dma3 单机与联机截图里两行剪影都在。
- 加入的玩家在大厅只看到“LOBBY”，不知道要按 B → 计时器下面按状态提示“按 B 配装后入场 / 点“配装”选装备后入场 / 已入场 · 等待房主开始”；菜单底部提示也随页面与阶段变化（非房主在编辑阶段看到“房主正在搭建地图…”）。
- 1.9.3.2_MP 平台聊天窗口也用 Tab（`Survivalcraft.Multiplayer.ChatWidget`）：按住 Tab 看计分板会同时开关聊天。没有改平台；按键冲突列表加入“联机平台：聊天窗口”，菜单“设置”页会提示，可改键。
- 测试脚本自身的错误（如实记录，不是产品问题）：联机检查曾把“房主只买手枪”当成没枪、把 JSON 转义的“>”当成没播报；dma3 第一次联机用了“轻量（无探员）房主 + 全量客户端”，被握手按设计拒绝——改成用户实际组合“轻量+探员房主 + 全量客户端”后 11/11。

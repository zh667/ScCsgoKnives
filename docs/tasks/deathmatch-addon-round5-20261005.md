## 2. 实现

| 需求 | 实现 | 区分正确与错误做法的检查 |
|---|---|---|
| R5-1 弹道 | `DmRecoil.cs`：用 vdata 种子和 Valve 均匀随机流生成每把枪的 64 发表（全自动的 0.55 混合、前 4 发 0.75 抑制，出自 CS:GO SDK）；按实测常数连续积分。镜头只带 60%/56%，其余加在子弹方向上。<br>核心：`IScRecoil`、`ScMode.Recoil`；开火时子弹方向 = 自身瞄准 + 弹道偏移 − 视角已带部分；视角部分每帧按增量写入 LookAngles；有模式后坐时不再叠加生存模式的随机后坐 | DeathmatchCheck K01–K07：AK、格洛克、M4A1-S 的表值与独立 Python 实现一致；**9 把 CS2 实测弹道全部复现**（均方根 0.035～0.051°，单发最大 0.21°） |
| R5-2 移速 | `DmMovement.cs`：手持武器的 `m_flMaxSpeed`（开镜取第二个值；手雷取装备块 245，电击枪 230）÷ 250 × 玩家自身行走速度；只在战斗中对本机操控的玩家生效，离开战斗恢复原速 | K30–K31：刀 3.1、AK 2.666、AWP 开镜 1.24、内格夫 1.86 |
| R5-3 腹部 | 部位新增“颈”“腹”（核心枚举在末尾追加）；`DmCombat`：腹 1.25、颈 1.0（护甲覆盖，未实测）、腿 0.75 | K20–K23：CS2 实测的 26/3（有甲胸）、25（腿）、138（头）、44（腹）、35（颈/胸） |
| R5-4 命中盒 | `tools/cs2_dm_hitboxes.py` 从 CS2 的 CT/T 探员模型（两者完全相同）读出 19 个 cstrike 胶囊体，写入 `Data/dm_cs2_hitboxes.json`。<br>站姿按 CS2 实测扫描拟合：胸部以上比绑定姿势低 4.5 单位，双腿各外张 16°，手臂改成持枪位置（建模）。<br>下蹲按 SC 眼高竖向缩放。<br>核心：`ScHitCapsule`、`ScMode.HitCapsules`；命中只认这些胶囊体，胶囊体之间打空 | K10–K15：胶囊求交单元测试；与 Python 参考逐行一致；**与 CS2 扫描 26 行中 24 行一致**（另两行在分界上，误差不到 1 单位）；下蹲、躺下、转身 |

## 3. 与 CS2 的已知差异（如实记录）

- **头部位置**：CS2 bot 瞄准时头偏到一侧，扫描时中线上方没打到头。我们的胶囊体头部保持居中，与 SC 模型一致。
- **姿势是建模的**：CS2 用实时动画摆放命中盒，这些文件里没有动画。
  - 站姿按实测拟合，手臂按持枪位置放置。
  - 不随瞄准俯仰弯腰。
  - 下蹲按 SC 的深蹲（眼高 45%），不是 CS2 的 72%。
- **停火后弹道复位**：采用 CS:GO SDK 的衰减规则（停火超过 1.1 个射击间隔后，约 0.5 秒衰减到一成），未在 CS2 实测。超过 64 发时循环使用弹道表。
- **移速未在 CS2 内实测**：直接用 vdata 数值，见第 1 节。
- **颈部是否吃护甲**：未实测，按胸部处理。

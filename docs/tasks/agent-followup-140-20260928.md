## 3. 刷新设置：必须真正可见、可保存、可控制

建议文案：“开档满30个游戏日后开始”，值为等待整天数，范围0–365，0立即允许。手动输入整数配±按钮，不用难以精准拖动的巨大滑块。暂停不计时、跳到白天不绕过累计时间；如果第三方改变DayDuration，首版明确沿用引擎当前DayDuration换算，不引入未验证的真实时间推断。展示剩余游戏时间以同一函数计算，边界测试29.999/30/30.001天。

设置所有权建议：主菜单配置新世界默认，世界内配置当前世界规则。旧ScUiSettings.NaturalEnemies只作为未初始化世界的一次默认来源（保留已关状态），新世界参数在TacticalEnemies持久化。分屏/多人采用世界负责人权限，客户端展示同步值，不能各玩家各自驱动刷怪。若当前没有多人传输，明确本地主机范围，不假称已网络同步。

保存/取消/默认均有工作副本。不得打开页面就改live参数、取消仍写盘，或“恢复界面默认”顺手覆盖别的世界。主菜单无Project不崩；世界关闭时取消悬挂操作。存档新字段经旧兼容包读写不得丢，必要时接已有兼容保留机制；不要无必要提升枪械layout/schema。

密度必须有可解释含义，建议首轮三档（数值为实验起点）：

## 6. 跳跃和死亡：本轮不能继续只盘点

1.4.0发布记录明确P5未做；实际包七种gait未变，外观适配bin与旧包同哈希。原始ctm_sas/tm_phoenix导出有jump_*/inair_*，上轮仅盘点，没导入/接状态/重烘缓存。当前生成器tools/build_companion_assets.py也只写七个状态；只手改输出JSON，未来再跑生成器会倒退。

必须贯穿“原始资源选择 → 派生生成器 → 包内GLB/scanim → 状态参数 → 上下身混合 → 实际渲染”整条链。角色动作覆盖knife/pistol/rifle的站跳/跑跳/蹲跳，起跳/上升/下落/落地；落地片段若源不存在就明确用过渡，不伪造原始来源。加入IsOnGround、VerticalSpeed、起落沿、空中时长，不能拿水平SpeedAbs当跳跃。NPC和玩家都接，梯子/水中/飞行/死亡不能误触发。

保留持枪上半身掩码，髋腿曲线与动作混合；根运动不得重复推动身体。缓存帧键加入影响姿态的状态，避免同帧重用错误pose；多个相机仍每实体只推进一次。使用原始未剥离GLB，Full/Lite各自烘GLB+scanim并验证一致，NMM/NEO不改。跳跃录像至少30/60/120fps含站跳、跑跳、落地、侧向视角、两角色持枪/盾/空手；腿部关键帧数值变化只证明曲线有动，不能代替视觉。

死亡沿用上轮P5的独立受约束尸体方案，不再整体根旋转90度交差：最后活姿+速度/有限冲量，约10–13个身体段、角度约束、重力/地形接触、坡地墙角求解。源physics/骨骼仅供核对，不承诺可直接导入CS2物理。最多6具活动、30Hz有界子步是实验预算，超限冻结/复用视觉状态，不删真实掉落或复活。保持死亡/装备掉落只一次，关闭世界释放资源；远近LOD只影响视觉不影响伤害/奖励。CorpseDuration从3秒向6–8秒试验时明确存读和性能影响。

本轮完成标准：要有跳跃渲染录像和多方向/地形倒地对照；若仅能完成跳跃，必须写“死亡物理未完成”，不以总回归数通过宣称全部动画修好。

轨迹定义：默认开启、准备投掷时显示本人的预测路径和预计落点，设置可关。首版不显示敌方未来轨迹、不做自动瞄准；已出手实飞尾迹是不同功能，本轮不默认添加。C4不是抛掷物。覆盖六类投掷物、强/弱投、走跑跳、手机/鼠标/手柄和第三人称。

性能起始预算：仅准备态且开启时计算，10–15Hz更新或输入变化触发，重用缓存；模拟最多600个0.02秒步，绘制抽稀至最多96段、最多3次反弹，达到上限明确截断。每帧预算必须实测，动态目标/墙体变化使缓存及时失效。多相机绘制复用同次预测，不在Draw重复跑射线。取消、切武器、死亡、打开菜单立即隐藏；任何失败均不影响真实投掷事务。

2026-10-05。来源：用户 2026-10-04 "穿墙穿透还得谈论一下具体方案，可以先讨论方案再做"，并在选项中选择"按方块材质+厚度（推荐）"。

**用户决定（2026-10-05）**：
- 尺度："这个能木制的都设为容易穿吧"。木头易穿，其他按真实厚度。
- 打穿人："要"。
- CS2 实测："可以"。

材质归类没有改动意见，按第 4 节草案执行。实现、实测和检查见 [round6](deathmatch-addon-round6-20261005.md)。以下是当时的方案原文（历史）。范围与其他第 5 轮内容相同：只在死亡竞赛世界（ScMode 管辖的玩家）生效，生存/创造世界不变。

## 1. 现状

- 核心子弹现在会穿过空气、水、树叶、草类和藤蔓等植物（`ScGunRange.StopsBulletFor`）。碰到其他任何可碰撞方块就停下，没有伤害衰减，也不会继续前进。
- `ScAttackFacts.Penetrations` 字段已经存在，但目前始终为 0。死亡竞赛已经把它传进 `DmHit`，击杀提示可以直接用它显示"穿墙"图标。

## 2. CS2 的规则（要照搬的部分）

| 项目 | CS2 规则 | 数据来源 |
|---|---|---|
| 武器穿透力 | `m_flPenetration`：手枪/冲锋枪/霰弹 1.0，步枪/机枪/沙鹰/R8 2.0，狙击 2.5，电击枪 0 | 已在 `dm_cs2_profile.json` 中（按 vdata 读取） |
| 材质系数 | 每种表面有穿透系数和伤害系数（木、金属、混凝土、玻璃、泥土……） | CS2 `surfaceproperties`，**将从本机 CS2 文件读取**并列表供审 |
| 每穿过一个物体的损失 | 当前伤害 × 材质伤害系数 + 由武器穿透力和材质决定的固定损失 + 与**厚度平方**成正比的损失 | CS:GO SDK 公式（`HandleBulletPenetration`）；CS2 是否完全相同**需实测** |
| 最多穿透次数 | 4 次 | 同上 |
| 单个物体最大厚度 | 约 90 单位（超过就打不穿） | 同上 |
| 玩家身体 | 子弹打穿一个玩家后还能伤到后面的人，伤害按规则衰减 | 同上 |
| 方块本身 | CS2 墙不受损 | 本方案：**方块不受任何破坏** |

## 3. 关键尺度问题（需要你决定）

Survivalcraft 一格方块是 1 米，按核心换算是 **39.37 个 CS2 单位**。CS2 的厚度损失与厚度平方成正比，所以：

- **薄方块**能打穿，伤害损失小：门约 7 单位、活板门、玻璃板、栅栏、梯子、半砖 19.7 单位。
- **一整格木头**相当于近 1 米厚的木墙。按 CS:GO 公式粗估，结果取决于木材的穿透系数：
  - 系数为 1 时，AK-47（36 伤害）打不穿。
  - 系数为 3 时，穿过后约剩 7 点。
  - 手枪基本打不穿。
- **一整格石头、金属、混凝土**完全打不穿。CS2 地图里能被打穿的金属板和砖墙通常只有几英寸厚。

以上数字用的是 CS:GO SDK 的系数，只是**估算**。CS2 的实际材质系数读出来之后会重新计算并列表。

**选择 A（推荐，最贴近 CS2）**：按方块真实碰撞厚度计算，1 格 = 39.37 单位。
- 效果是只有薄方块和木头类能有效穿墙，石头和金属挡子弹。
- 这与 CS2 "厚墙打不穿"的手感一致。

**选择 B（更多穿墙）**：把整格方块当作 CS2 地图里典型的墙厚，例如统一按 8～10 单位计。
- 效果是一整格木头、甚至薄一些的石墙都能打穿。
- 穿墙更频繁，但它不再是 CS2 的真实尺度。

## 4. 方块到 CS2 材质的映射（草案）

按方块已有的声音材质（`GetSoundMaterialName`，核心的弹孔声音也在用）和方块类型归类，未知方块按"默认"处理：

| SC 方块类别 | 对应 CS2 材质 | 预期效果（选择 A） |
|---|---|---|
| 木板、原木、木箱、木门、木梯、木栅栏 | wood | 薄件能穿，整格木头勉强能穿 |
| 玻璃、玻璃板、冰 | glass | 很容易穿（CS2 对玻璃有特殊的低损失规则） |
| 羊毛、地毯 | cloth | 容易穿 |
| 泥土、沙子、沙砾、雪 | dirt / sand | 整格打不穿，薄雪层能穿 |
| 石头、砖、混凝土、矿石 | concrete / rock | 整格打不穿 |
| 铁、铜、金属门、金属栅栏 | metal | 整格打不穿，薄金属件视厚度而定 |
| 树叶、草、植物、水 | （保持现状：本来就不挡子弹） | 不计为穿透次数 |

## 5. 实现要点（确认后才做）

1. **追踪**：沿子弹路径逐格走（体素 DDA），按方块实际碰撞盒算出进入点和穿出点。同一材质的连续方块合并为一个物体，厚度 = 穿出距离 − 进入距离。
2. **规则**：每个物体按 CS2 公式扣伤害，最多 4 次。伤害低于 1 或物体太厚就停。射程仍按武器射程。
3. **命中**：穿透后继续按 CS2 命中盒判定后面的玩家；伤害结算仍走死亡竞赛现有的部位倍率和护甲规则。
4. **反馈**：
   - 进出孔都显示弹孔粒子和声音。
   - 曳光弹画到最终停下的位置。
   - 击杀提示显示 CS2 的穿墙图标（`Penetrations > 0`）。
5. **联机**：服务器权威计算。其他客户端的显示走现有的弹着点广播，需要多带一个"穿出点"列表，涉及协议字段，会走现有的版本握手。
6. **性能**：每发子弹最多追踪约 128 格，体素步进开销很小。

## 6. 验证计划

- **离线**：用手算数字检查公式，覆盖不同材质、厚度和武器的组合；检查最多 4 次、过厚停止、伤害低于 1 停止；检查材质映射覆盖全部原版方块。
- **CS2 实测**（需要再借用你的电脑约 20 分钟）：在 aim_map 选 2～3 种已知厚度的物体（木箱、金属板、玻璃），用 `sv_showimpacts_penetration 1` 加命中日志读取穿透后的伤害，校准材质系数和公式。
- **实机**：联机双人对局，在木板墙、玻璃、石墙后各打一次，核对命中部位、剩余伤害和击杀提示的穿墙图标。

# 手套预览与玩家第三人称 — Full 1.4.9 / 战术拓展 1.3.2

## 使用与范围

枪械台入口改为 **功能 → 人物外观／更换手套**。每款手套有透明缩略图和大图预览，显示名称、磨损和当前装备标记。单击只预览，点击“应用手套”或双击／双点才保存；返回不改变选择。“跟随角色默认手套”恢复原装。

五款手套继续使用最低合法磨损 0.06，不增加制作成本或物品 ID。选用 CT SAS／T Phoenix 时，玩家第一人称与世界中的第三人称同步更换手套；手套随玩家保存，袖子随角色切换。非 CS 角色仍仅改变原有 CS 第一人称路径。同伴 NPC、NMM 角色选择预览和 HUD 人偶保留原装手套。

只需本体 1.4.9 和战术拓展 1.3.2，不新增独立外观／手套包。角色选择仍使用 NekoMeko 的原有入口，需其 1.1 及 Neorxna 1.4；它们依旧是可选依赖，没有修改其安装包。战术拓展二进制最低依赖本体 1.4.9；适配器程序集身份、物品顺序、layout v5/schema6 不变。

## 渲染处理

第三人称使用 CS2 三套 `worldmodel` 手套网格，保留各自逆绑定矩阵及完整手指骨骼。角色 GPU 调色板仍为 48 关节；手套按完整骨骼计算后立即复制到原生批次。选择和骨骼映射按玩家保存，不修改共享模型的 `IsVisible`。原装手套仅从当前角色组件的绘制顺序中排除；重复选择同一角色时也重新应用过滤。

战术 1.3.2 修正世界手套从脚底单个方块取光的问题：脚底落在暗的实心方块内或因浮点误差跨过表面时，旧做法会使手套发黑、明暗突变。改为使用人物原生 `ModelData.Light` 缓存，与身体相同；未注册模型使用原生模型取光计算。继续响应实际环境明暗，不用强制全亮掩盖问题。

源 GLB 和派生网格哈希见 `world-gloves-assets.json`；八张预览图由真实网格生成。原第一人称贴图、人物、武器资源和资源程序集逐字节保留，未修改 CS2 原始导出。此版本没有改变武器接触点和动作时间，也没有新增联机传输。

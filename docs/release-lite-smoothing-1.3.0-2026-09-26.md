## 30 MB 极简包结论

按更严格的 **30,000,000 字节**作为上传上限。当前的普通轻量包已使用加强
标准 Deflate；再次 ZIP 压缩不会提供所需约 70% 的缩减。

| 独立删减测算 | 剩余体积（十进制 MB） |
| --- | ---: |
| 完整优化轻量包 | 107.49 |
| 每把步枪/狙击枪/机枪各留一个额外皮肤，其余枪皮移除 | 104.13 |
| 所有额外枪皮和刀皮贴图都移除 | 101.77 |
| 整个战术/探员/人物外观模块移除 | 67.52 |
| 上一项再叠加“每把主战武器一个枪皮” | 64.16 |

这里的最后两项比“只删探员”范围更大，连战术模块其它专用资源也算入，
用来验证有利情况下能否达标。数值是压缩载荷删减预算，尚未扣除少量 ZIP 目录
开销，也不是可直接使用的包。当前总包初始化要求 Tactical DLL，直接删除会报错；
已有探员/战术世界还需要休眠数据与身份适配，缺失皮肤必须有视觉回退和菜单过滤。
普通轻量包没有实际删减这些内容。

资源大头是：武器动画/模型资源 DLL 26.86 MB、音效 13.55 MB、NPC 武器缓存
16.50 MB、探员动画缓存 12.77 MB、其余贴图 12.49 MB。原本已没有高分辨率枪皮
可供大幅缩减：所有额外枪皮+刀皮贴图总共才 5.72 MB。

**判断：只重压缩、删枪皮和去探员不足以达成 30 MB。** 如果继续做极简版，
建议保持全部枪械数值和存档 ID，先去掉探员/外观，再只留基础刀型与默认手臂、
统一皮肤模型以减少旧式几何副本，然后做音效降采样、贴图进一步缩小、第一人称
动画和网格的专项简化。每一步按实际包大小验收；尚不能承诺保留全部现有第一人称
表现时一定低于 30 MB。不要在保留探员的版本里删除其预烘焙缓存换取体积。

没有发布或覆盖任何极简包。可重复测算工具：`tools/audit_minimal_size.py`；
[逐类预算与所选皮肤](minimal-size-budget-2026-09-26.json)。选取的是每把主战武器
体积最小的现有皮肤，仅用于尺寸计算，不是最终皮肤选择。

## 构建记录

使用 `.tmp/lite-actor` 保存旧轻量 GLB，执行 `ActorLoadCheck bake` 和
`prepare_actor_geometry.py`。不得对 marker GLB 再次烘焙。
`NpcWeaponCheck` 的第五个参数指定 `.tmp/lite-smooth-20260926/baked/Assets`，
并且进程旁的 `ScCsgoResources.dll` 必须是旧轻量包中的 DLL。

运行 `package_lite_smoothing.py` 暂存；变更载荷以 7-Zip 标准 ZIP Deflate
`mx9/fb258/pass15` 重压至阶段目录的 `recompressed.zip`，再次暂存时择小使用。
`prepare_lite_smoothing_fixture.py` 创建隔离资源与工具目录；
`check_lite_smoothing.ps1` 执行上述验证；最后 `package_lite_smoothing.py --publish`
核对源包、全量包、最终包和原生工具 DLL 哈希后替换。所有工具通过 `tools/dev.ps1`。

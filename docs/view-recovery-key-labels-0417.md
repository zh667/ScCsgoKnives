# 0.41.7：显式视角恢复与中文按键说明

日期：2026-09-10（Asia/Shanghai）。不变更枪械存档布局 v5、记录 schema 3 或任何武器数值。

## 这次的视野证据

本机游戏 `Bugs/Game.log` 的 0.41.6 会话（23:52–23:53）多次记录：

```
settings enter baseView=0.44444445 sensitivity=0.22222222
settings leave baseView=0.44444445 sensitivity=0.22222222
```

只读检查 `doc/Settings.xml`，两个保存值也分别为 `0.44444445` 和 `0.22222222`。
因此该会话在进入 CS 设置前，基础视野已是 44.44%，并非这几次退出又把正常视野缩小。
二者恰好等于原版默认值（1、0.5）除以 2.25，与旧版本直接写全局开镜倍率的路径吻合。
仅凭数值不能排除其他修改者，不能把这个结论扩展为所有第三方模组的相机问题已解决。

0.41.6 已停止用开镜修改全局偏好，但不自动覆盖用户偏好，故旧缩放值仍留在原版设置里。

## 新恢复入口

设置 → CS 枪械 → 顶部「恢复正常视角」→ 确认「恢复并保存」。

- 明确说明重置范围：退出 CS 开镜及待回镜，基础视野 100%（原版 80°）、灵敏度 50%。
- 不调整视角朝向或相机模式，不重置其他设置，也不修改武器及世界记录。
- 清除相机投影缓存，立即生效。此独立操作不受 CS 设置页的“取消”影响，确认窗口提前说明。
- 通过原版 SettingsManager.SaveSettings 保存原版偏好，随后只读检查 Settings.xml 的两个数值。
  该 API 内部可能吞掉错误/因锁忙直接返回，所以不能仅凭方法返回宣称保存成功。
- 验证未通过时保留本次已恢复的视角，显示“已恢复；保存未确认，请重试”，并记日志。
- 不在启动时静默复位，不直接编辑玩家运行中的本机设置文件。测试仅在离线隔离状态里重现相同数值。
- 新诊断前缀 `[CS_VIEW_RECOVERY_0417]`，包含恢复前后两项数值及写盘核对结果。

## 按键页显示完整的现有操作

原版的动作映射从 SettingsManager.GetKeyboardMapping 动态读取，不硬编码所有用户都是左/右键：

| 模组功能 | 沿用的原版映射 | 原版默认 |
| --- | --- | --- |
| 开火 / 轻刀、强投 | Hit、Dig（相同键去重） | 鼠标左键 |
| 开镜、消音器、连发、R8 速射、重刀、轻投 | Aim | 鼠标右键 |
| 换弹、检视 | 模组自己的额外键盘绑定 | R、G |

列表同时显示原版操作与额外键盘键，例如“开镜：鼠标右键 ＋ 字母 K”。
没有额外键盘键但仍有鼠标操作时，显示鼠标操作，不再显示笼统的“未绑定”。
选择器明确写“额外键盘键”；清除项写“移除额外键盘键（保留原版操作）”。
此处不修改原版共享的 Aim/Hit/Dig，避免改变原版工具/其他模组的操作。
触屏场景长按不是鼠标右键，手机仍可通过映射额外键盘键调用独立功能。

所有引擎 Key 枚举均有中文显示名：空格键、回车键、退格键、方向键、翻页键、数字键、标点键等；
字母与功能键保留物理键帽标识（“字母 R”“功能键 F1”），组合键保留辅助标识如“控制键（Ctrl）”。
磁盘中的原始键名不翻译，因此已有用户绑定不需要转换，也不会失效。
较长的组合说明允许按钮文字换行，列表继续滚动，保存/取消仍固定在底部。

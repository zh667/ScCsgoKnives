# 0.40.5 — 等级预览、升级提示与植被挡弹

- 属性页支持 Lv0～Lv10，−/+ 按钮逐级切换，点击中间等级恢复实际等级。所有枪（含未安装计数器）可预览，不写入实例或等级；仅计数世界仍可预览，但明确提示加成不会生效。
- 高于当前实际等级时，只有数值/说明发生变化的属性行做两秒周期的柔和透明度变化，最低 alpha=165/255，避免文字消失或强烈闪烁。显示“仅预览”和实际等级，切换枪械恢复对应实际等级。
- 按钮单独占据整行，不塞在预览图旁狭窄的身份文字区。保持最小 48 逻辑单位触控目标；0 和 10 边界禁用相应方向按钮。
- 计数器实例及目录模板名称增加真实 `Lv`，模板为 Lv0。原生 InventorySlotWidget 拖动时使用 `GetDisplayName`，因此拖动标签、查看名称沿用真实等级，不受属性预览影响。无计数器普通枪不显示虚假的成长等级。
- 实际升级提交成功后，手持者收到带枪名、前后等级、满级状态的提示及提示音。增加 contents 校验，不能仅因非枪物品 data 中的数字碰巧匹配 ID 就收到提示。原有“动作结束后再应用等级”时序保留。
- 枪弹地形射线跳过 TallGrassBlock、LeavesBlock（及其派生树叶）、FallenLeavesBlock、IvyBlock。空气/液体仍按既有规则忽略；树干、墙、玻璃和实心草皮土方 GrassBlock 仍阻挡。不破坏植被、不强制加载区块、不扩大射程。只改变枪弹射线，不改变手雷/刀/玩家的碰撞。

## 验证

- 原生 UI 构造及字体 Measure/Arrange：7 组逻辑布局、11 个预览等级、上下界、未来属性闪烁目标、物品值不变；35 枪名称和属性布局原回归继续执行。
- 实际 ComponentChest 取放时名字保留计数器 Lv0；引擎拖动名称源码入口已核对。
- 原生 Terrain/SubsystemTerrain.Raycast 中布置草→树叶→树干：旧谓词被植被挡住，新谓词通过植被命中树干，移除树干后射线无阻挡。植物/固体类型白名单另有独立回归。
- Full/Lite 从相同 DLL 打包，保留 0.28.2 发布包的 1960 种状态迁移及真实备份只读检查。最终报告 `output/ScCsgoKnives-0.40.5[-Lite]-check.json`。
- 无物品布局或 schema 变化，无枪械数值/成长比例/充能/库存事务变化，无玩家世界修改。尚需实机验证柔和闪烁效果、提示音及枪弹穿过实际树冠的观感。

开始本轮时已有的属性伤害说明、两处身份文案、共享 UI 断点和未跟踪皮肤规划保留，未代为提交。

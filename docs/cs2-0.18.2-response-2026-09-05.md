# 0.18.2 — 对 0.18.1 实机问题的答复（2026-09-05）

来源：`SC_VIDEO/…failed to load ssg08… 2026-09-05 15-02-55.mp4`（36 s，1080p60）和
`[Windows]SurvivalcraftAPI_1.9.2.1/Bugs/Game.log`（1401 行）。报告的问题：新加的 8 把枪
拿在手里无法检视、没有手臂、看不到换弹动画、换弹没有声音、物品栏图标风格与旧三把不同、
SSG08 开镜不对。

## 1. 复核结论：前五项是同一个根因

日志里的证据链（时间为日志时间）：

| 时间 | 日志 | 含义 |
| --- | --- | --- |
| 15:02:09.994–.997 | `failed to load deagle … ssg08: Missing embedded CSMC rig resource` ×8 | 渲染器启动时给每个变体解 CS:MC placement，CS2-only 枪没有 CS:MC 动画 |
| 15:02:29.864 | `hook: … asset=ssg08, poseNull=True` | 钩子拿到的 CS:MC 姿态是 null |
| 15:02:36.395 | `InvalidOperationException … at CsmcKnifeRig.GetDuration → KnifeAnimationController.LogActionStart → Update → OnFirstPersonModelDrawing` | 控制器每帧采样 CS:MC rig，抛出后整个钩子中止 |
| 15:03:18.5–20.1 | `CS2 action: asset=p90 requested=idle` 成对出现、间隔 ≈ 75 ms（P90 射速 0.07 s） | 开枪动作请求的是 `idle`：`TriggerShoot` 查的是 CS:MC 片段表，CS2-only 枪一条都没有 |
| 15:03:21.788 | `requested=inspect resolved=lookat01_p90` | 检视动作其实启动了，但没有被画出来 |
| 全程 | 没有一行 `cs2 profile active: gun=ssg08/p90/…` | CS2 绘制路径从未对这 8 把枪运行过 |

视频与之吻合：8 把枪都以 Survivalcraft 原生的"手持方块"方式画在右下角（那是我 0.18.1 为
物品栏加的刚体网格），没有手臂、不动；SSG08 开镜时世界放大了、遮罩没出现、原生十字准星被
放大成一个巨大的"+"。

链条是：

1. `OnFirstPersonModelDrawing` 里 `if (pose is null) return;` —— CS:MC 姿态为 null 就把物品交回
   Survivalcraft 自己画。CS2-only 枪的 CS:MC 姿态永远是 null。
2. 就算不为 null，`CsmcFirstPersonRenderer.Draw` 先检查 CS:MC 资源（`s_parts/s_baseColor`）再分派
   到 `DrawCs2`；CS2-only 枪没有 CS:MC 资源，在门口就被退回。
3. `Cs2Placement.Active` 只看 `GunProfile`；对只有 CS2 rig 的枪，profile 为 0 时也该走 CS2。
4. 控制器的 `TriggerShoot/TriggerReload/TriggerSilencer` 用 `CsmcKnifeRig.HasClip`（CS:MC 表）而不是
   按绘制 profile 查 `HasAlias`；`LogActionStart` 无条件采样 CS:MC rig。
5. 换弹没声音：`cs2_sounds.json` 只有 ak47/m4a1s/awp 的提示音时序（生成脚本手写了三把枪的片段
   表），8 把新枪只装了开火音，没有 clipout/clipin/bolt/draw/消音器螺纹。

SSG08 的开镜不是另一个 bug：遮罩由 `DrawCs2` 里的 `s_overlayFrame` 触发，`IsCrosshairVisible` 也
靠它隐藏原生准星；路径没运行，两者都不发生。vdata 里 SSG08 `m_nZoomLevels = 2`，
FOV 40/15，与 GunSpec 的 `[2.25, 6]` 一致，所以修好路径后它和 AWP 走同一段代码。

## 2. 修复

**路由（渲染器/rig/placement）**

- `CsmcKnifeRig.Sample`：CS2-only 变体返回一个"替身姿态"——只带片段别名、控制器的未截断时间和
  是否循环（`DrawCs2` 从姿态读的就只有这三样），所有绑定查询返回单位矩阵。
- `CsmcKnifeRig.GetDuration/GetMeshCenterOffset/SampleRawBindings/GetBoneRestLength`：CS2-only 分支，
  不再去加载不存在的 CS:MC 资源。
- `Cs2Placement.Active`：CS2-only 变体只要有 CS2 rig 就为真，与 profile 无关。
- `CsmcFirstPersonRenderer.Route(variant, pose)`：新的纯函数，先于任何资源加载决定 `cs2 / csmc /
  none:<原因>`；`Draw` 按它分派，CS:MC 资源门控只对 `csmc` 路线生效；`EnsureLoaded/EnsurePlacement`
  跳过 CS2-only 变体（启动时那 8 行 ERROR 消失）。

**控制器**

- `ShootClip/ReloadClip/SilencerClip`：按绘制 profile 的 `HasAlias` 解析，供 Trigger* 和自检共用。
- `LogActionStart` 对 CS2-only 变体直接返回（`Start` 已记录 CS2 片段和时长）。
- `obscured: … deferring draw` 只在首次延迟时记一行（设备日志里 6.5 s 刷了 939 行）。

**声音**

- `tools/cs2_sound_timings.py` 改为遍历 `guns.json` 里的每把枪、按各自 rig 文件里的片段别名
  取键；`tools/install_gun_sounds_cs2.py --cues` 把片段里引用而模组还没有的事件装成
  `<gun>_<cue>.ogg`（单声道）。新装 62 个文件；`cs2_sounds.json` 现在 49 个片段 203 条提示音，
  203 条全部落到包内 OGG。
- `SubsystemScGunBlockBehavior.Schedule`：老表里没有的枪（CS2-only 八把）无论 profile 都取 CS2
  提示音；拔枪改为优先按 CS2 draw 片段的提示音调度（FAMAS/M4A4 拔枪时的轻拉栓），没有才播单个
  `_draw`；检视按控制器实际选中的片段调度（沙鹰第二段检视自带 9 个 LookAt 音）。

**图标**

- `tools/render_gun_slot_icons.py`：朝向不再"取最长轴"，而是取 rig 根骨 `weapon_offset` 的绑定
  矩阵——11 把枪的 .cs2.parts 全部是 Source +X(前)→网格 +Z、Source +Z(上)→网格 +Y；画左侧、枪口
  朝左，与 CS:MC 三张一致。
- `tools/fit_slot_icon_camera.py`：用 ak47/m4a1s/awp 自己的 CS2 网格渲染、对 CS:MC 图标的轮廓做
  IoU 搜索。结果 yaw 48°、pitch 8°、roll 18°，平均 IoU 0.507（0.18.1 的平面侧视 0.296）。镜像解
  (−48, −8, 18) 得 0.505，按可见面排除：CS:MC 的 AK 图标能看到机匣盖和弹匣前缘，相机在枪的
  前上方。
- `tools/fit_slot_icon_tone.py`：单面光照，按三张 CS:MC 图标的亮度均值/p10/p90 搜索
  ambient/diffuse/gamma → 0.60 / 1.50 / 1.10。参数都在 `tools/reference/slot_icon_camera.json`。
- 真正一致的做法仍是拿 CS2 自己的 `panorama/images/econ/weapons/base_weapons/`（68 张），
  在 Windows 侧待办里。

## 3. 自检新增（这次能溜过去的原因）

`Cs2SelfTest` 对每把枪新增：`sample`（CS:MC 采样非 null 且别名正确）、`route`（渲染器路由 =
期望）、`shootClip/reloadClip/silencerClip`（控制器解析到非 idle 的 CS2 片段）、
`cues.deploy/reload/inspect(/attach/detach)`（CS2 提示音存在）。

证伪：把 `Cs2Placement.Active` 的 CS2-only 特判删掉 → 25 项失败（route/shootClip/reloadClip/
silencerClip）；`ShootClip` 改回查 CS:MC 表 → 8 项 shootClip 失败；`Sample` 不给替身 → 16 项失败
（sample 报 `Missing embedded CSMC rig resource`，route 报 `none:no pose`）。恢复后 0 失败。

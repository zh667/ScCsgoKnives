# 0.35.3 旧格式保护补全：世界级布局校验、无记录拒用、动画入口拦截

日期：2026-09-08。0.35.2 只挡住了第 16 位置位的样本；复查用包内 DLL 又找出三处缺口，本版补齐。

## 1. 世界级布局校验（`ScGunRegistry.Classify`）

读档时把世界归类：
- 布局戳 ≥ 5，或存档里已有 `GunRegistry`（0.35.0/0.35.1 保存的世界）→ **兼容**；
- 布局戳 = 4，或没有戳但有旧版键（`ZeusRechargeAt` / `GunWear`，0.34 及更早每次保存都会写）→ **旧世界**；
- 什么都没有 → 新世界。

旧世界里 `LegacyWorld = true`：**所有**枪械物品（包括之后新造的）一律视为旧格式——不可用、不写入、不分配记录；进入世界时提示一次
"此世界由 0.34 及更早版本保存，本版的枪械在这里全部停用（物品保留原样）。请新建世界。"保存时布局戳写 4，旧世界永远保持旧世界。
不再靠某一位判断全部旧数据。

## 2. 没有记录的 ID 拒绝使用

复查样本 `49154`（0.34 的空弹 AWP，第 16 位为 0）按 v5 位模式读成 ID 768，而该记录并不存在。现在：ID 不是 0/1023 且记录不存在的物品
一律不可用（弹量 0、耐久 0、`IsKnown` 为假、写入不改值、不分配记录），显示为"枪械记录缺失（旧版本数据或损坏存档，已保留）"。
不再"缺记录就按默认值重建"。

## 3. 动画入口拦截

`KnifeAnimationController.ResolveVariant` 对枪械先查 `ScGunBlock.IsKnown`，旧格式/缺记录的物品返回 -1：第一人称不再解析到别的枪型模型，
第三人称同样不画。物品描述对不可用物品也改为固定说明。

## 4. 检视与开镜

`IsBusy` 只算切枪、换弹、装拆消音器、投掷；检视期间开镜是**允许**的（会打断检视），0.35.1 文档里"检视期间禁止"写错了，以代码为准。

`old-format-gun-draws-no-model`（116173、49154 解析为 -1，新枪解析正常）。PackageCheck（含 Content.zip）6162/6162，运行时自检 5891/5891（`community-m4-0353-packagecheck.json`）。VPS 不打包。

日期：2026-09-20。交付全量包，保留 1.3.2 等已有包；枪械编号、物品编码、存档结构均不变。

## 小鸡跑动“被影子拽回去”

用户视频：`D:\下载\QQ20260919-231758-HD.mp4`。视频中的身体与地面影子分离，与模型数据能相互印证。

CS2 的 `run` 动画带有 `root_motion` 向前位移：一轮约 2.65034 米。当前小鸡放大 1.6 倍，模型相对于实际身体可前移约 4.24054 格；循环时归零，视觉上就突然被拉回。原版生物移动系统已经在移动碰撞身体，不能再叠加这段位移。

修复只移除衍生 GLB 中 idle/walk/run 的 root_motion **平移通道**，保留根骨旋转、身体上下起伏、腿部动作、网格、纹理及动画时长。重新导入脚本也执行相同处理，避免重新提取后复发。CS2 原始提取文件未修改。转换前后摘要见 `chicken-in-place-20260919.json`。

验收方法：放出几只小鸡，在平地观察行走/奔跑；对一只交互使它跟随，再拉开距离。身体应跟随地面位置连续前进，跑动循环时不应突然向后弹。斜坡、转弯及多鸡同时奔跑也可检查。

## 手柄默认设置

实际查阅了《使命召唤：黑色行动冷战》的 [Xbox 官方操作说明](https://www.callofduty.com/blog/2020/11/Black-Ops-Cold-War-Controls-and-Settings-Xbox)，以及 [MWIII 官方手柄设置指南](https://www.callofduty.com/guides/training/call-of-duty-modern-warfare-III-play-guides-training-controls-xbox-series-s-xbox-series-x)。常见方案使用 RT 开火、LT 瞄准、X 换弹/交互、右摇杆按下近战；并非所有射击游戏都使用相同默认键。

API 1.9.3.1 原版使用 X 背包、Y 衣物、B 丢弃、RB 蹲下、LB 编辑方块、方向键左右切快捷栏。直接将 X 改成换弹会同时打开背包，因此采用下表，不修改原版全局设置。

| CS 操作 | 默认键 |
| --- | --- |
| 开火、强投、放置 C4 | RT |
| 开镜、副功能、轻投 | LT |
| 换弹、C4 设时 | 按住 LB，再按 X |
| 检视 | 按住 LB，再按 Y |
| 重刀 | 右摇杆按下 |

组合键必须来自同一只分配给该玩家的手柄。LB 用作组合键后，松开不会再触发原版编辑。单按 X/Y 仍打开原版背包/衣物，移动、跳跃、蹲下、丢弃与快捷栏切换沿用原版。LT 由原版瞄准路径处理时不再重复发起 CS 副功能，避免一次输入切两次倍率。若原版自定义设置占用了新增默认键/组合键，优先原版并停用对应默认动作；在 CS 设置选择已占用按键会提示冲突。

已有自定义配置（包括主动清空的键位）保留。想使用本次整套默认方案，在“CS 武器 → 键盘与手柄绑定”点击“恢复默认”再“保存”；这也会恢复该页面的键盘默认值。也可只逐项调整手柄键。

验收方法：两只手柄分别分配给两位玩家，一人 LB+X 换弹、一人单按 X 开背包，确认互不影响；LB+Y 检视不能打开衣物页，松开 LB 不能打开面前的编辑方块；同时检查 LT 单次开镜、RT 连射、右摇杆重刀、断开/重连与菜单内输入。

## 双人/多人同屏

有两处直接原因：自定义第一人称投影忽略了各玩家画面的偏移与缩放；开镜状态原来是共享静态字段。瞄准镜遮罩还使用整个显示目标的尺寸绘制，因此覆盖其他玩家。

现在按照每位玩家的原生 camera.ViewportSize / ViewportMatrix 映射自定义投影，不能从已经变换过的投影矩阵反推长宽比。手臂、枪械和 AUG/SG 553 镜筒使用同一规则；瞄准镜在当前玩家画面内居中，并以短边确定圆形直径。绘制时保存、裁剪、恢复原有 scissor 边界，低分辨率中间渲染目标也只映射一次。

开镜/隐藏准星状态、枪口闪光和电击枪枪口粒子按玩家分别保存。曳光与电弧从发射者最近一次有效枪口位置发出，避免另一位同持同一枪型时借用对方枪口。卸载世界时清理这些临时状态。

验收方法：左右、上下分屏各检查两人腰射；一人 AWP 开镜，另一人拿刀或普通枪；双方同时使用不同倍率，然后一人退出开镜。还应检查 AUG/SG 553、两人同持 M4A1-S 开火、四人同屏及降低画面分辨率。各画面应只受到自己的开镜/枪口效果影响。

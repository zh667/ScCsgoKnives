# 投掷物效果修复（1.1.4）

本次版本处理了烟雾弹、燃烧物和高爆手雷的视觉与交互问题。玩法 DLL 在全量版和 512 轻量版中完全相同，轻量版只降低装饰粒子数量并把纹理和模型压到移动端规格。

## 改动

- 烟雾使用 CS2 本地提取的 `vistasmokev1` 序列帧。烟雾改为中性深灰，采用直通 RGBA 混合，透明区域不会再留下白色底色。
- 高爆手雷中心伤害为 48，伤害半径为 6 格，按距离线性衰减，仍需通过清晰射线；爆炸烟雾改为深灰并延长到约 2.2 秒。
- 高爆手雷在烟雾中形成半径 4.5 格的临时开口，保持 1.5 秒后在 2 秒内恢复。开口同时影响画面、屏幕内烟雾、视线 AI 和烟雾密度；墙体后的烟雾不会被打开。
- 烟雾接触 CS 投掷物燃烧区会立即灭火；飞行中的烟雾穿过火区会提前爆开并灭火。燃烧物在已有烟雾中落地时不会播放点燃音效，也不会保留火区。
- 火焰使用 CS2 `fire_small_sim` 序列帧，增加低矮火舌和少量火星；全量版保留更多装饰火星和烟，轻量版降低这些装饰数量。
- 资源图集由本地 CS2 提取目录导入，来源和哈希记录在 `grenade-effects-1.1.4-sources.json`。这些是 CS2 的粒子贴图帧，不包含 Source 2 的完整体积模拟，因此实际游戏仍使用本模组的有限 sprite 模拟。

## 验证

`PackageCheck` 已使用游戏 DLL 和 API 目录分别检查：

- 全量版：0 个失败；
- 512 轻量版：0 个失败；
- 两版核心玩法 DLL SHA-256 相同；高爆手雷的 48/6 数值、烟雾开口、烟雾灭火、墙体射线、存档字段和两版资源策略均通过离线回归。

PackageCheck 是无图形测试，不能替代真机观察。建议在游戏中各做一次：烟雾投入燃烧区、燃烧瓶投入烟雾、HE 对烟雾、墙后烟雾和远近距离 HE 伤害；重点确认不同 GPU 上烟雾的灰度和透明度。

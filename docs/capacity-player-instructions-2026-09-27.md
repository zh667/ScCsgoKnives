# 玲兰枪械扩容恢复副本使用说明

本次交付两个独立 `.scworld` 副本，原始存档保留。请选一个作为后续游玩的主档，避免两份副本各自推进后混合跨世界物品。

1. 先自行导出当前完整世界备份。本模组不会自动备份。
2. 停用原 CS 核心，选择本次更新后的 `[API1.9]CS武器1.3.0-全量包.scmod` 或 `[API1.9]CS武器1.3.0-轻量包.scmod`。文件名已恢复普通名称，用发布清单的SHA-256确认文件，勿混用之前下载的同名旧包。只启用一个核心，不与旧包或极简包同时启用。
3. 轻量包可搭配现有 1.3.0 探员包，探员包不需要更新。保留原世界依赖的玲兰等其他内容模组。
4. 导入本目录的恢复副本。`安(3)` 保留该原档进度；`安1(3)` 保留它自身的世界进度，但丢失的枪械记录恢复到 `安(3)` 最后可验证的状态，不能还原两个快照之间未知的枪械变化。
5. 首次进入核对背包 SCAR-20：编号 #2、32级、1230击杀、41发、耐久225/980；频道0同步库存 USP-S：编号 #1022、0发、耐久1152/1200。随后验证新枪获取、同频道同步箱取放，以及保存退出后重进两次。

全部1022条旧记录、原编号、身份和枪械属性保留；未清表、未回收或重排编号，没有额外赠枪、补弹或维修。每份恢复副本新增65536条可分配空间。原地形及其他模组数据保持原样；`Project.xml`、`Project.bak` 中仅枪械记录及其跨世界元数据更新。

扩容格式是布局6／记录schema7。可以互换的是本次更新后的1.0.0／1.2.0／1.3.0包；已传播、未更新的同名旧兼容包不支持这个格式。已检查的上一批旧包会拒绝加载；这不代表任意更早版本都有相同保护。不要手改版本标记来强行读档。若必须退回未更新包，只能使用与它匹配的升级前备份。当前普通文件名的包清单见 `output/release-package-names-20260927/manifest.json`。

已完成 Windows 原生离线编码、存读、共享库存适配、版本往返、资源和包加载验证。尚未完成玩家手机内的导入、实际箱子操作、地形加载、连续游玩验收；走动卡死的独立反馈原因仍未确定，本次不承诺解决该问题。

`world-recovery.json` 记录输入和恢复副本的 SHA-256、改动成员及存读检查，可用于确认收到的是配套文件。

# 0.41.11：完整资源前置包、玲兰键名与 M4 环境光

用户要求只交付全量资源，不生成 Lite；并澄清要分离整个大资源集合，而非仅新增涂装。

## 体积与交付结构

旧 0.41.10 包约 245 MB（十进制），压缩占用约：纹理 191 MB、内嵌代码/动画 DLL 41 MB、音频 9.4 MB、外部模型 3.3 MB。
新增涂装的 44 张贴图/图标只是纹理集合中的约 23 MB；“仅拆涂装”不能达到减小日常更新包的目标。

新交付：

- `ScCsgoKnives-0.41.11.scmod`：代码主包，约 0.51 MB；保留原 PackageName `zh667.ScCsgoKnives`、方块定义、语言、配方、游戏参数和着色器。
- `ScCsgoResources-1.0.0.scmod`：完整资源前置，约 244.86 MB；760 个全分辨率纹理/模型/音频文件，及动画/网格资源程序集。
- 资源程序集 `ScCsgoResources.dll` 只含资源与标记类型，不注册方块、实体、ModLoader 或存档字段。
- 全部 `.cs2.animation.json`、`.skin`、`.parts` 从原核心 DLL 移到资源 DLL，资源名不变。
  原动画读取的三个入口改为读取资源程序集；轻量元数据仍在核心，属性页不因拆包重新加载整套骨骼曲线。
- 外部资源路径保持不变，通过引擎已有跨模组 ContentManager 合并；不复制到磁盘、不进行运行时网络下载。
- 这不是压缩质量降低：资源逐字节与 0.41.10 对比。首次安装总体积几乎不变，运行时内存需求也不会因拆包自动降低。
  后续仅改代码、参数、着色器时只更新主包；资源实际变化时才升级前置包。

## 安装与缺包保护

退出游戏，移走 Mods 中旧主包（Full/Lite 任一），放入新主包和资源包各一份，再启动。
不得同时装旧主包和新主包；不能只装约 0.51 MB 的主包。

主包声明精确依赖 `zh667.ScCsgoResources: [1.0.0]`，资源加载顺序在主包前。
资源包 NonPersistentMod=true，不引入独立世界数据，但它仍是主包运行必需项。
引擎缺依赖会禁用主包，游戏加载钩子另校验资源版本/格式/Full 标记，错误时设置枪械拒载标记。
不要忽略游戏的缺失模组警告进入旧世界；检查前置包装齐，而不是把枪械问号当成正常降级。

物品布局 v5、记录 schema 4、枪械/皮肤编号、等级规则均不变，不产生新的枪械数据转换。
0.28.2 / 0.41.4 的既有迁移链保留；已有 schema 4 世界仍按同一格式读取。

## 前置包可复用

打包命令：

```powershell
./tools/dev.ps1 dotnet build src/ScCsgoKnives/ScCsgoKnives.csproj -c Release
./tools/dev.ps1 python tools/pack_scmod.py --edition full --split-resources
```

资源 ZIP 使用固定时间戳、固定条目顺序，资源版本单独维护。
若同名同版本资源包已经存在，重新生成后核对哈希：相同即保留，不同则拒绝覆盖，必须升级资源版本和主包依赖。
主包不会保留资源 DLL 副本或纹理/音频/模型副本；中间 MSBuild 目录不作为发布清单。
来源文件仍全部保存在仓库，未从工作区删除。每个外部资源的路径/SHA256 写入前置包的 `Assets/ScCsgoResources.xml`。
分包体积、SHA256 和迁出清单写入 `output/reports/ScCsgoKnives-0.41.11.split.json`。

## M4A1-S 正午亮度

旧 GunEnvFactor 对所有 M4A1-S 涂装硬编码返回 1，而原枪默认约 .25。
这是之前为发暗问题加的独立环境光补偿；白色印花集在正午的环境光部分因此显著偏亮。
本次删除该特例，所有 M4 皮肤与原枪使用同一环境光系数，仍乘以实际场景照度。

不降低贴图分辨率、不修改原始色彩/纹理、不恢复旧的脏污 AO；保持法线、粗糙度、金属度和遮罩的既有修复。
不改全局曝光，也不改变其它枪械和手臂的系数。原厂图标是独立官方图标，不按场景光烘焙修改。
离线 A/B：`docs/m4-studio-boost-04111.png` 与 JSON；相同模型/纹理，仅环境系数 1 → .25。
印花集平均图像亮度样本 .658 → .417，二号玩家 .530 → .312，金蛇 .401 → .204。
这是固定视角、面法线的离线渲染，不是游戏截图，不能代替正午/阴影/夜晚的实机观感验收。

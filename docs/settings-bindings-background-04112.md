# 0.41.12 — 设置页背景与按键说明

## 用户反馈与证据

- 2026-09-10 截图：入口写着“键盘绑定（适配触控映射）”，下方提及玲兰触控；用户要求取消这种适配说明，恢复中文键名，核对全部武器操作，关闭尸鬼测试入口。
- 只读检查 `E:/EdgeDownload/[Windows]SurvivalcraftAPI_1.9.2.1/Bugs/Game.log`：10:26:44 进入、10:30:26 退出，基础视野始终为 1、灵敏度为 0.5；没有 background 异常堆栈。日志本身不能证明闪烁的像素原因。
- 旧 `ScGunWorldBackground.Draw` 每个 UI 帧重跑 `ViewWidget.Draw`；引擎源码 `ViewWidget.DrawToScreen` 会调用世界绘制和其他模组的 `DrawToScreen` 钩子。原背景合成另用了不透明白色四边形，忽略设置页自身的淡入淡出。这两个实现问题会使暂停背景受逐帧状态影响，不能据此单独归罪于某个第三方模组。

## 修改

1. 入口改为“武器按键绑定”，删除用户界面的第三方模组名称、适配承诺。
2. 所有引擎键使用中文说明；字母、数字、F1–F12 保留键帽标识。修饰键、方向键、翻页键及标点键不再裸露英文枚举名。选择器按字母、数字、功能键、其他键排列，包含引擎所有允许绑定的键；无、退出和手机返回不作为武器键。引擎没有单独定义的小键盘、左右修饰键等，不伪造支持。
3. 页面明确列出 10 项操作并提示下滚：开火／轻刀、换弹、开镜、消音器、连发、速射、检视、重刀、强投、轻投。显示游戏当前原版鼠标绑定和额外键盘键，保留原版右键操作。原有稳定操作 ID、键 ID、配置格式与输入分发均不变，不自动重置玩家绑定。
4. 删除设置中的尸鬼按钮、标题连点解锁逻辑。没有关闭通用跨世界枪械快照与兼容功能；离线校验仍可使用已有检查辅助代码。
5. 设置、键盘绑定、触屏布局三页改为进入时单次离屏取景，页面停留期间复用同一张游戏背景。只在重新进入、分辨率变化、Project 变化、图形设备重置、主动恢复视角时重新取景；退出释放纹理。不写截图文件，不更新或重新排列 GameScreen，不转发输入。布局编辑仍以全屏游戏图像作为位置参照。
6. 世界渲染异常后保持固定底色，不每帧重试；再次进入可以重试。保留 viewport/scissor/render target、视野及 GUI 状态恢复。背景合成遵守页面自身透明度。
7. 新日志 `[CS_BACKGROUND_04112]` 记录单次取景尺寸、视图数、耗时或失败信息，不记录位置。正常停留页面不应持续输出取景日志。

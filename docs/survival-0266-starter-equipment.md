# 0.26.6 生存开局装备

按用户要求，每位新玩家首次在生存类模式出生时获得：

- CT 默认匕首 ×1（按现有 `default_ct` 型号查找）。
- USP-S ×1，12 发满弹，带消音器（按现有 `usp_silencer` 型号查找）。
- 通用弹匣 ×3。

## 发放规则

- 适用无害、生存、挑战、残酷模式；创造和冒险地图不发。
- 使用 SCAPI 的 OnPlayerSpawned 事件，确认初次出生且 SpawnsCount=1 后发放。API 在调用该事件之前已创建并初始化背包、增加出生次数。
- 领取状态按玩家编号存入世界子系统；重复事件、读档、死亡重生不会再次发放。旧世界中的已有角色不补发，新加入世界的角色可在首次生存出生时领取。
- 保留原版/其他模组已有的开局物品和当前选中槽位，按原版背包合并/空槽规则添加。放不下的部分在出生点附近生成掉落物。
- 不弹领取成功提示，不增加物品索引，不改制作配方、等级、武器伤害或弹药规则。

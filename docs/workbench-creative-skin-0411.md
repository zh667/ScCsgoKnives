# 0.41.1 — 创造装配台涂装入口

截图的问题来自 ShowList 的旧创造模式分支：只列出维修、计数器、属性，遗漏 SkinMenu。换肤候选、免费报价和原实例保留逻辑已经存在，并非没有皮肤资源。

两种模式现在使用同一个 MainMenuItems，功能页均显示“更换枪械涂装”。创造模式免费，生存模式维持原材料费用；换肤和去皮仍通过既有报价/事务，不改变 ID、击杀、等级、弹量、耐久或充能。不修改实际存档或数据格式。

新增检查直接取得运行时菜单并构造实际对话框，分别以创造/生存上下文筛选“功能”，确认四个入口都存在，包含 SkinMenu。既有双模式换肤顺序、状态保留和存读档回归继续运行。最终包为 0.41.1 Full/Lite，报告位于 output 同版本 check.json。

操作路径：武器装配台 → 功能 → 更换枪械涂装 → 下一步 → 选择背包中支持皮肤的枪 → 选择皮肤 → 确认。

## 这一版改了什么（详见 `docs/cs2-0.16.6-report.md`）

1. 曳光从**画面上的枪口**出发（原来从眼睛，AK 差 246.9 px）。
2. 曳光用 CS2 自己的两张 spark 贴图、两个 pass、屏幕空间宽度夹紧、按飞行进度的
   alpha 包络和长度生长。近处半宽 21.8 px → 2.10 px，远处 0.14 px → 0.79 px。
3. `Cs2Effects` 首次加载的 NRE 修了；每个 loader 现在公开 `LoadError`，自检直接断言它。
4. 验收改为**直接跑指定 .scmod 里的 DLL**，不再跑工作树重编译。
5. Python 工具统一 UTF-8 解码、查返回码、失败时把子进程 stderr 抛出来。
6. `arms_evidence` 的绕过口子堵了：封闭枚举 + 四张图 + 哈希 + checker 重算。

## 第 1 步（只需这一步）：对墙实拍一段曳光

装 0.16.6，`GunProfile = 1`，其余保持你上次那套：

```
Cs2Arms = 1   GunNumbers = 0   GunSoundProfile = 0
Cs2ViewmodelFov = 68   Cs2ViewmodelOffsetX = 2.5   Cs2ViewmodelOffsetY = 0   Cs2ViewmodelOffsetZ = -1.5
```

固定站位对墙，60 fps，约 10 秒：**AK 连打 6 发、AWP 打 2 发**。不需要重录整套参考素材。

**请站远一点，离墙至少 20 m，或者干脆对空/对远处地形打。** 这一条很重要：
粒子在命中点就被杀掉，曳光的存在时长等于 `距离 / 速度`，而且路程前 20% 是全暗的。
按 60 fps 数帧：

```
        5 m    10 m   20 m   40 m   80 m
ak47    1 帧   2 帧   3 帧   5 帧   10 帧     (5 m 那一帧还在全暗段，等于看不见)
awp     1 帧   1 帧   2 帧   4 帧    7 帧
```

所以 5 m 对墙**拍不到曳光是预期结果**，不是回归。同理，20 m 处淡出只占最后 1.9 ms，
不到一帧，所以"末端一下子没了"也是 CS2 自己的模型。

想看的是四件事，主观描述即可，不必量：

* 曳光是不是从**看得见的枪管口**出来的（不是从准星/贴脸处）；
* 近距离还是不是"一整块亮带"；
* 有没有软边和头尾渐变，还是硬边白条；
* 整条是不是"一帧突然消失"。

顺带确认 `Game.log` 里：

* 出现 `[ScCsgoKnives] CS2 effects: ak47 muzzle0=(37.422,…) flash=1 tracer every 3; …`
* **不再出现** `Could not read AnimationData.cs2_effects.json`。

## 第 3 步（阻塞 HAND，需要你决定要不要做）

`agent / loadout` 仍未定，所以参考帧的手臂到底是不是 `bare_arm_133 + glove_fingerless`
还没有证据，HAND 项照旧 `agent_unverified`。

判定法换了：**不再看色比**（一张渲染帧过了有色光照、阴影和 tone mapping，色比不是贴图的），
改为带基线的四张对比。要的是：

* 同一张图、同一站位、同一 setang、同一 cvar、同一把枪、同一 clip、同一 tick；
* loadout A 拍两张（A1、A2），loadout B 拍两张（B1、B2）；
* 一块**裸露小臂**的矩形 ROI（避开手套、避开武器）。

同 loadout 的两张之间的差异就是基线噪声；跨 loadout 的差异只有落在基线之外才算数。

```
python tools\cs2_capture_probe.py A1.png --repeat A2.png ^
       --other B1.png --other-repeat B2.png --arm-roi X0,Y0,X1,Y1
```

它会打出每一对的 mean / p95 / p99 / p99.9 / max / 超阈值比例，和三种结论之一：

```
independent    跨 loadout 落在基线内 → 手臂与 loadout 无关，任选其一记录
different      超出基线 → 手臂随 loadout 变，得指认是哪个 agent
inconclusive   基线自己就 > 8 级 → 这块 ROI 里场景本身不可复现，换个位置重拍
```

把它打出来的整块统计原样贴进 manifest 的 `cs2.arms_evidence.statistics`，
连同两个 loadout 的 `team/agent/gloves`、四张图的路径与 SHA-256、`arm_roi`。
**checker 会从哈希过的图重算一遍**，对不上就 FAIL——手填数字过不去。

manifest 里 `arms_evidence` 的样子：

```json
"arms_evidence": {
  "method": "loadout_difference",
  "arm_roi": [560, 700, 760, 900],
  "scene": {"map": "...", "weapon": "ak47", "clip": "idle", "tick": "..."},
  "loadouts": {
    "a": {"team": "CT", "agent": "...", "gloves": "...",
          "images": [{"path": "loadout/a1.png", "sha256": "..."},
                     {"path": "loadout/a2.png", "sha256": "..."}]},
    "b": {"team": "T",  "agent": "...", "gloves": "...",
          "images": [{"path": "loadout/b1.png", "sha256": "..."},
                     {"path": "loadout/b2.png", "sha256": "..."}]}
  },
  "statistics": { ...探针原样输出的 baseline_p999 / baseline_mean / cross_p999 / cross_mean / verdict... }
}
```

# 1.3.2：小鸡蛋投掷与可选手柄反馈

日期：2026-09-19。交付全量包，保留之前的版本。

## 小鸡蛋

原因：此前小鸡蛋覆盖 `OnUse`，直接向 5 格内地面做交互射线；没有启用 `IsAimable` 和原版 `ThrowableBlockBehavior`。因此只能在近处生成，不能像原版生物蛋投出。这与上一版第一人称显示位置问题不同。

现在接入原版生物蛋的按住瞄准、松手投出流程，使用原版速度 14、阻尼 0.8、尖端偏移 0.1，碰撞后消失并生成 CS 小鸡。起点沿用原版眼睛位置加右侧 0.4 格，速度包含玩家当前速度和原版力量修正。没有距离 5 格限制。

物品消耗由原版投掷行为负责：取消不扣，无法创建弹射物不扣，成功投出扣一次；创造模式仍由原版创造背包处理。蛋撞墙、地面或生物时生成，不在点击时生成。同一蛋重复收到碰撞回调只处理一次。生成失败按原版生物蛋习惯消失，不反复生成或返还复制；异常不会中断弹射物更新。

沿用独立方块 ID、现有 CS 小鸡模板与跟随/死亡规则，不占用原版或其他模组的生物蛋 data 编号。不更改枪械编号、编码、注册表或存档结构。

实机复现：

1. 创造背包“CS武器”取小鸡蛋，和一个原版生物蛋分别尝试。
2. 对着远处或天空，按住原版投掷/瞄准操作再松开；应看见蛋飞出去，碰撞处出现小鸡，不要求先点中近处地面。
3. 对墙、地面、生物各试一次；一枚蛋只生成一只。生存模式试取消与正常投出，检查数量。
4. 对小鸡按 E/交互仍可切换跟随；刀杀正常，CS 枪杀仍触发原有爆炸。

## 可选手柄反馈

检查来源：用户提供的 `D:\下载\[API1.9]手柄反馈v1.2.0.scmod`，包名 `xianyu.ControllerHaptics`，程序集 `ControllerHaptics.dll`。包版本为 1.2.0，其互操作类的 ApiVersion 为 1.3.0，二者不是同一版本号。

适配使用公开的玩家感知接口：

```csharp
Game.ControllerHaptics.Pulse(ComponentPlayer player, WidgetInputDevice device,
    float strength, int durationMs, bool adaptiveTriggerVibration)
```

加载完毕检测程序集、按完整签名绑定并缓存委托。没有添加程序集引用、模组前置或内置第三方 DLL；未安装、缺少相应接口时直接跳过反馈。反馈调用异常会关闭本次会话的适配并记录一次警告，不影响伤害、换弹或物品事务。

| 事件 | 基础强度 / 时长 | 触发条件 |
| --- | --- | --- |
| 普通枪实际开火 | 0.30 / 45ms | 扣弹与耐久事务成功后，每发一次，非每颗霰弹 |
| 狙击枪、霰弹枪实际开火 | 0.55 / 85ms | 同上，不随等级增加震动强度 |
| 换弹完成 | 0.20 / 65ms | 完成当前换弹动作；取消、切枪、装消音器不触发 |
| 刀击中生物 | 轻击 0.30 / 50ms；重击 0.45 / 80ms | 真实命中，空挥不触发 |
| CS 投掷物掷出 | 0.20 / 45ms | 投掷事务成功，取消不触发 |

传递当前玩家及其输入设备掩码，由反馈模组决定最近输入来源、手柄/手机后端、用户设定强度及短脉冲结束。开火请求支持设备的扳机震动，不实现持续扳机阻力。不接管按键设置、陀螺仪瞄准、触摸板或手柄扬声器。菜单中和死亡后不发送这些动作反馈。小鸡蛋沿用原版投掷，没有额外覆盖其震动行为。

实机复现：先仅安装 CS 包检查投掷和枪械，再同时安装反馈模组、连接受其支持的手柄。用手柄射击、换弹、刀击中生物和投掷手雷，检查对应短震；调低反馈模组强度应生效。测试空枪、取消换弹、空挥、打开背包，以及切回键鼠。不同设备是否支持扳机震动以反馈模组与硬件为准。

# 第三人称接触修正：本体 1.4.6 / 战术拓展 1.2.2

用户视频 `QQ20260920-205936-HD.mp4` 显示换弹时手与弹匣分离、刀具握持方向和穿模问题，
以及切刀后仍维持步枪姿态。本轮修复 T/CT 玩家、召唤同伴和敌对 T 共用的第三人称路径。

## 安装

关闭游戏，用本体 Full 1.4.6 和战术拓展 1.2.2 替换各自旧包，每种只启用一个版本。
玩家外观继续使用原有 NekoMeko Model 1.1 与 Neorxna 1.4；未修改、合并或重新分发
它们的代码。无需独立 CS 玩家外观包。本轮产物位于项目 `output/`，不自动替换游戏 Mods。

## 修正

- 人物和武器部件现在使用同一段 CS2 world 动画及同一播放进度，替代此前人物 world
  换弹与第一人称弹匣动作混用。武器挂点从原始人物 `wpn` 相对 `spine_2` 导出，
  和双手共用上身父节点，避免快速翻刀时对手腕逆变换插值造成接触漂移。
- CT/T 各包含 170 段动画：七段基础步态、102 段拔枪／换弹、61 种独立握姿。
  握姿取完整拔枪末帧；原资源的单武器 idle 为 additive 数据，不能直接作为绝对姿态。
  实际手持物决定握姿，空闲或 NPC 动作清除后也不会回到统一步枪姿态。
- 22 把刀按原关节分组，蝴蝶刀、折叠刀、双持匕首保留独立运动；弯刀跨关节的八个
  三角形逐顶点变换，不粗暴归给某个刀片。枪械已有材质、皮肤、消音器和计数器路径保留。
- 检视和射击微动仍是本项目适配，通过共有上身节点保持双手与武器接触。没有混入
  第一人称的刀具检视翻转。消音器操作仍为适配，未声称原生 CS2 world 检视还原。
- 下半身步态、每实体动作时钟、重复相机保护和眼部贴图保留。GPU 蒙皮仍为 48 骨骼；
  新武器节点不进入人物蒙皮表。原始 CS2 导出、第一人称动画、武器 ID、布局 v5、记录
  schema 6 与战术 schema 1 均未修改。

## 验证

`tools/build_world_contact_fixture.py` 从保留的原始导出生成独立接触基线，共 734 个动作
采样、2,220 个左右手相对武器／弹匣／刀片的变换。原生诊断比较运行时实际骨骼与基线，
同时检查 35 把枪、22 把刀和 C4 的握姿、几何位置、刀具关节覆盖、步态及重复相机。
隐藏弹匣的缩放不作为距离单位，位置误差统一按米计算。原生 GPU 同时出图供人工检查。

最终包证据见 `release-tactical-1.2.2-evidence.json`。验证入口还包括本体打包 DLL 回归、
Full 资源清单、两套引擎上的战术回归和 18 个独立进程的可选前置加载检查。
最终通过：本体 12,156 项、Full 交付 1,325 项、战术两套引擎各 52 组、可选加载
18 进程共 176 项、原生外观／动作 7,494 项、资源保留 1,340 项。原生 GPU 生成
1,016 张动作图，抽查换弹和各类刀具；[诊断预览](thirdperson-1.4.6-preview.jpg)。
2,220 个接触变换最大位置偏差 1.271 cm，最大方向偏差 0.17314 rad；这是所采样骨骼
相对源数据的误差，不是所有帧手指表面的误差或零穿模保证。
这些是原生诊断，不是完整游戏、安卓或联机验收；本轮未加入网络同步。默认方块人物仍为
原先的刚性双臂适配，不属于本轮 T/CT 骨骼接触还原的保证范围。

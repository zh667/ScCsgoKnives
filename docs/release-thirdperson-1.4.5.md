# 第三人称动作首版：本体 1.4.5 / 战术拓展 1.2.0 / 玩家外观 1.1.0

2026-09-20。按用户要求，在可选玩家外观首版和眼部修复完成后继续实现第三人称动作。

## 安装使用

退出游戏后，每种模组只启用最新一个版本：

- `[API1.9]CS武器1.4.5-作者ZH667-全量版.scmod`：本体，自带资源。
- `[API1.9]CS战术同伴拓展1.2.0-作者ZH667.scmod`：信标同伴、敌对 T 小队及共享人物模型。
- `[API1.9]CS玩家T-CT外观1.1.0-作者ZH667.scmod`：可选的玩家角色外观。
- 选择玩家外观还需要 NekoMeko Model 1.1 和 Neorxna 1.4。提供单独的
  `[API1.9]NekoMekoModel1.1-源码构建.scmod`；Neorxna 使用已有版本，不重复分发。

在 NekoMeko 的角色选择中选择 `CS2 · CT SAS` 或 `CS2 · T Phoenix`，也可切回默认人物。
切到游戏自带第三人称相机后，正常换弹、切枪、检视即可看到人物动作；第一人称继续使用
CS2 原手臂。外观选择按玩家保存，不改变阵营、生命或装备属性。

信标同伴在真实换弹、装备更换和开火时显示动作。交互面板新增“检视武器”，非战斗时
持枪同伴可以执行，点击后关闭面板方便观看；进入战斗会中断检视。敌对 T 的有限弹药换弹
也显示相应动作，重载已有 `ReloadLeft` 状态仍能恢复进度。

## 实现与边界

- 玩家动作状态按人物读取，包含动作种类、武器、序号、已用时间、总时间和霰弹循环的
  实际片段时间。动作由更新流程推进，不依赖第一人称是否绘制；旧武器退出画面时不会
  把新武器状态切回去。投掷物/C4 用完后短暂保留的第一人称表现仍按原流程处理。
- CT/T 各含 109 段派生片段：原七段基础姿态加 102 段 world 拔枪/换弹。覆盖 35 把枪
  的拔枪、34 把可装填枪的换弹及已有刀具拔刀。电击枪保留充能机制，没有虚构换弹。
  上半身按真实动作进度采样，下半身继续行走，物理根节点不随片段移动。
- 原生 world 资源没有检视片段。检视、射击微动、消音器操作等是本项目适配；默认人物
  的双臂动作也为适配。人物握持与弹匣/机件使用不同动作集，首版不声称逐帧还原手指接触、
  双持独立手部或刀具翻转。专用游泳、攀爬、骑乘姿态仍未加入。
- 枪械保持绑定在动画右手上；弹匣/机件复用本体的 CS2 武器动画，控制辅助弹壳显示，
  保留没有动画骨骼的装饰件回退。UI 头像保持待机，不播放战斗动作。
- T 的固定前视瞳孔与 CT 暗色镜片修复保留。原 Source 2 眼球着色器、动态目光和金属
  反射没有移植。CT/T 所有嵌入贴图已与前版逐字节核对相等。GPU 骨骼表仍为 48；
  仅派生资源改变，原始导出保留。
- 所有动作状态按实体分开，多相机读取不重复推进，为以后同步留出数据边界。
  **此版尚未实现联机网络同步。** 枪布局 v5、记录 schema 6、战术 schema 1 不变。

## 验证

最终包及测试记录见 `release-appearance-1.1.0-evidence.json`。验证包括本体打包 DLL、
Full 资源清单、战术真实库存/换弹/攻击/死亡/拖放回归，以及安装目录实际引擎上的外观
生命周期、上半身动作、玩家/同伴重复相机、手枪/步枪/霰弹枪动作与持枪原生 GPU 出图。
本体 12,156 项、Full 交付 1,325 项通过；战术拓展 52 组分别在构建依赖和安装目录引擎
通过；安装目录原生外观/动作诊断 542 项通过，包含 80 张人物持枪动作渲染。
包内 DLL、资源与测试输入逐项校验。原生 GPU 诊断不等于完整游戏、安卓设备或联机验收。

复现入口：`tools/dev.ps1`、`tools/pack_standalone_editions.py`、`tools/pack_tactical.py`、
`tools/pack_appearance.py`、`tools/PackageCheck`、`tools/verify_appearance.py`。

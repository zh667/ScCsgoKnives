# 当前模组的素材与发布风险评估

核查日期：2026-09-21。按作者明确的方案：**免费公开发布，不设付费内容**。这是根据当前代码、安装包、来源记录和当日官方网页作出的风险判断，不是律师法律意见，也不是权利人的许可或法院结论。

## 结论

**目前不能把这个包认定为“已取得完整授权、可放心公开再分发”。V 社有提出投诉、要求停止分发或提起诉讼的可能；现有信息不足以预测它是否会这样做，更不能承诺“不收费就不会被告”。** 免费和明确非官方身份是有利因素，但这里是把大量原版游戏素材打包到另一款游戏，而不是只借鉴玩法。

Valve 的非商业同人授权提供了一定支持，不能说“Valve 完全不允许任何同人使用”。但查到的条款没有明确把本项目这种跨游戏、含可提取模型／贴图／音频的完整资源包列为获准用途；Source 模组的明确许可又以官方 SDK 等条件为前提。对当前公开发行，最准确的判断是：**存在实质授权缺口，不能据此给出低风险合规结论**。另有 EA／DICE 音效，其公开政策与当前使用方式的冲突更直接。

还需注意：GitHub 仓库 `zh667/ScCsgoKnives` 已经是 **PUBLIC**，源树也含游戏派生资源。因此“以后才发布 scmod”并不代表此前没有向公众提供素材。此次未改仓库可见性、删除历史或联系任何权利人。

## 官方政策怎么说

1. [Steam Subscriber Agreement](https://store.steampowered.com/subscriber_agreement/) §2.A：内容为许可使用而非出售，通常供个人、非商业使用。§2.F 保留 Valve 及其许可方的权利。§2.G 对复制、发布、改编、反编译、再分发等设限制，同时保留协议明确允许及适用法律的例外。因此不能只引用限制条款、忽略同人条款，也不能只说买了正版就能再分发。
2. 同协议 §2.D **明确允许非商业 Fan Art 包含 Valve 游戏内容**，这是对免费项目有利的条款。但其举例／定义涉及 fan art、fan fiction、audio-visual works，未明确确认这种完整的跨游戏可交互素材移植属于该授权。§2.C 的开发工具许可也不等于任何第三方提取工具产物都获得同样授权。第三方内容仍要自行取得必要权利。
3. [Steamworks：Distributing Source Engine Games / Mods](https://partner.steamgames.com/doc/sdk/uploading/distributing_source_engine) 的默认条件包括：非商业、基于 Valve 官方 SDK、明确是社区项目。本项目基于 Survivalcraft API，不是该页所说的 Source 模组，不能直接套用“符合条件无需单独许可”。页面还明确将付费广告、付费解锁、以捐赠换取物品／功能等视为商业用途；其他项目获准的历史个案也不是普遍授权。
4. [Valve Video Policy](https://store.steampowered.com/video_policy) 写明：**“We're not fine with taking assets from our games (e.g. voice, music, items) and distributing those separately.”** 该页讨论视频政策，不能单靠这一句话裁定所有模组是否合法，但它明确不能成为独立资源分发的许可依据。允许游戏视频或视频平台分成，也不能推导出允许收费资源包。
5. [EA Content Policy](https://help.ea.com/en/articles/security-and-rules/ea-content-policy/) 虽允许有条件的个人项目，但明确反对通过 data mining 获取素材、在文件分享网站分发其游戏和内容，并要求不要把游戏内容与其他第三方产品、服务或品牌结合。当前 BF1 音频提取后进入 Survivalcraft 包，不能仅凭“免费粉丝作品”认定受该政策许可。EA 也不替其他第三方许可素材。

当日抓取的最终 URL、正文摘要、时间与网页哈希见 `legal-sources-2026-09-21.json`。开发者社区 Wiki 未作为具有决定性的授权依据。政策以后可能变化，正式发布时应复查。

## 免费公开发布与“会不会被起诉”

| 使用方式 | 相对暴露与主要判断 |
| --- | --- |
| 仅本机私人使用，不提供素材副本 | 公开传播的暴露较小；仍要分别看提取、使用方式和适用协议，不能称绝对合法 |
| 朋友群分享含资源的包 | 仍向他人提供副本；群小、没有收费不会自动变成纯私人使用 |
| **免费公开发行（你的方案）** | 无商业收费是有利因素，但完整素材随包及公开仓库使复制／分发问题直接存在；目前没有足够依据认定这些都获许可 |
| 付费模组、收费入群取包、广告支持项目、赞助解锁皮肤／功能 | 增加商业许可问题；没有明确书面许可不应沿用本次免费方案的判断 |

投诉到 GitHub／网盘、要求下架、停止分发函与诉讼是不同路径；**不能保证先警告再起诉，也不能给出可信的起诉百分比**。权利人的执行意愿、项目规模、具体素材、授权往来、争议法域与发布方式都会影响结果。免费、注明来源、“侵删”、已有类似模组，都不是免责证书。非营利也不自动满足中国或其他法域的合理使用条件；复制完整表达并公开提供用途，不能只靠“学习交流”四字解释。

当前是独立游戏中的外观与玩法，没有证据表明它修改 CS2 官方服务器或 Steam 市场库存；本评估不把它误当 CS2 官方服假库存插件。但这同样不解决著作权授权。

## 对免费发行的建议（尚未自动执行）

1. **优先替换 BF1 击杀音效**，改成原创、明确可再分发的音频，或玩家自选外部音效。两份文件的实际分发都要考虑，不能只关开关。此次按用户要求评估，没有擅自删掉这个功能。
2. **为 CS2 跨游戏素材使用取得明确书面许可，或改成原创／具有适当许可的资源。** 询问须明确是 Survivalcraft、免费公开、哪些模型／纹理／声音／动画、素材随 scmod 与公开源码仓库分发；不能只问模糊的“能做免费 mod 吗”。本次没有代发邮件或工单。
3. 如暂不能取得许可，可研究只分发自己有权发布的代码，让用户从本机合法安装导入所需资源，以减少直接再分发素材的行为。**这不是保证合法的绕过办法**，仍须审查提取、改编、最终用途、工具与协议，不应分发绕过访问控制的工具。
4. 保留原作者与来源，但将代码许可和素材权利清楚区分；核验 CSMC／TaCZ 等授权是否真的覆盖当前保留内容、修改及公开分发。皮肤还可能涉及第三方创作者，不能假设全部是 Valve 独有作品。
5. 如后续决定清理公开分发，评估仓库历史、Release、网盘和镜像：只删当前文件不会收回旧提交中的副本。仓库改私有、清理历史、撤下下载等是单独的发布决策，本次未执行。
6. 若打算长期运营、扩大宣传，或收到通知，带素材清单、来源记录和所有授权往来请熟悉游戏知识产权的律师确认。收到正式诉状或函件时保留记录，按期限处理，不要把这个技术评估当正式法律答辩。

综合建议：免费模式可以保留，但**不宜把当前含全量提取资源的发行包对外宣称为“版权完全合规”或“V 社默认授权”**。最能实质降低风险的措施是解决素材许可，而不是只补一句免责声明。

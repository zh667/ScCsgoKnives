## 一、`tools/cs2_add_gun.py`：一把枪一条命令

前八把是手工按顺序跑八个工具，每次都漏一两样。现在一条命令跑完资源管线并把代码表写好：

```
python3 tools/cs2_add_gun.py fiveseven hkp2000 ... --apply
```

1. `cs2_gun_rig.py` → `<gun>.cs2.animation.json`
2. `cs2_glb_to_parts.py` 对本体 GLB（目录里名字最短、非 physics/holster/_mag 的那个）→ `<gun>.cs2.parts`
3. `install_gun_textures_cs2hd.py --size 1024` → `<gun>_hd.png` + PBR
4. `install_gun_sounds_cs2.py` → 开火/开镜音
5. `install_gun_slot_icons_cs2.py` → CS2 原版图标
6. `cs2_sound_timings.py` → `--cues` → 再 `cs2_sound_timings.py`
7. `cs2_effects.py`（GUNS 表已按模型事件填了全部 35 把）
8. `--apply`：按 `cs2_weapons.json` 生成 `GunSpec.All` 条目（格式与已有条目一致，burst/scope/pellets/一体消音
   各带出处注释）、`guns.json` 的 `Cs2Only` 条目、两种语言的 `ScGunBlock:<variant>` 名称与说明。

每步都是幂等的：产物已存在就跳过，`GunSpec` 里已有的枪不重复追加。

## 二、这一批发现并修掉的

- **`Weapon_p250.*` 对 `Weapon_P250.*`**：时序脚本上一轮已改成不区分大小写，安装脚本没有，P250 的 9 条提示音装不上。
  两边现在共用同一个 `CaseFold`。
- **MP5-SD 一体消音**：`SilencedAlways` 从 0.18.0 起只是个声明。现在开火时 `silenced = SilencedAlways || (HasSilencer && 装着)`：
  火焰用消音烟雾系统（模型事件 `uweapon_muzsilenced_subm`）、枪口取 `muzzle2`（没有就 `muzzle`）、后坐用 alternate；
  声音文件只有一套（`WEAPON_SOUND_SINGLE` 本身就是消音射击），不另找 `_fire_silenced`。
- **CS2 对消音枪不画曳光**：MP5-SD 的 vdata `m_nTracerFrequency = 0`。自检对 `SilencedAlways` 的枪要求就是 0。
- **M249/内格夫/霰弹枪的火焰粒子数是曲线不是常数**：`Particles` 写成了 `null`，C# 的 `float` 反序列化直接抛，
  整张特效表加载失败（自检 `load/effects` 拦下）。现在 Python 不写这个键，C# 改 `float?`。
- **Galil 的 vdata 枪口离膛线 0.71 in**：自检的"同膛线"容差从 0.5 放到 1.0 in（错枪会差好几英寸），渲染仍取骨骼。
- **P250 / CZ75 的检视片段没有声音事件**：`cues.inspect` 改为报告不强制，拔枪和换弹仍必须有。
- **自检的"换弹时弹匣要动"**：MP5-SD 的弹匣骨叫 `mag`；改成量该枪所有部件骨，报最大位移那根。
- 特效表现在 35 把枪全有（含还没接的 13 把），`cs2_effects_selftest` A 段（vdata 枪口 vs 骨骼）也跑 35 把。

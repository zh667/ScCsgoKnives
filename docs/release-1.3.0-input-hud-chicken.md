# 1.3.0 全量版：开火输入、弹药界面、刀伤和小鸡

用户于 2026-09-19 确认：刀伤是原来的 **3 倍**；小鸡爆炸采用 **48 中心伤害、6 格半径**。
本次仅产出全量自包含包；作者、PackageName 和现有枪械物品布局、注册表格式不变。

## 实际改动

1. **仅按键开火**不再依赖“自定义按钮”开关或开火按钮是否可见。开启后，空白触屏的原版开火输入被挡住；自带开火按钮、映射键鼠和手柄仍可用。关闭则保留全屏操作。设置页不再声称隐藏按钮会恢复全屏开火。
2. 已识别的 CS 枪械在快捷栏／背包等原版物品格**左下角显示耐久百分比**。格子换为空格、原版物品或未知枪时隐藏旧标签；低耐久和损坏状态为红色。沿用现有耐久读取，没有改写武器记录。
3. 弹药信息移到**右下方并避开现有操作控件**。使用 CS2 弹匣图标，底部起按当前装弹比例着色，未装部分灰色；剩余不超过 20% 变红。图标右下显示背包备用弹匣数，创造为 ∞；霰弹枪显示霰弹数，电击枪显示充能比例。保留简短装弹量和装填状态。
4. 原皮和皮肤刀的轻击由 7→21、重击由 12→36。攻击距离、节奏不变，不加计数器；物品信息的基础伤害同步为 21。
5. 新增独立 **CS 小鸡**及“CS武器”分类下的生成蛋。对地面使用蛋生成；草地自然生成沿用原版数量管理。小鸡没有攻击行为，对准 3 格内的小鸡按 E 或原版交互可切换跟随；持 C4 时优先保留 C4 操作。跟随不穿墙、不传送，过远（64 格）停止跟随。
6. CS 枪械（含电击枪）击杀小鸡后播放叫声，并在后续更新触发一次高爆手雷效果，48 中心伤害、6 格衰减半径，沿用墙体遮挡、友伤和烟雾冲散规则。刀杀正常叫声，不爆炸。箭、环境伤害、手雷／C4 波及不会触发鸡群连锁。其他模组的未知枪械伤害没有凭当前手持物品猜测为 CS 枪击。

## 资源与兼容性

- 模型、贴图、待机／走／跑动画、叫声和弹匣图标来自本机 CS2 VPK。保留原提取目录 `.tmp/cs2-chicken-hud-20260919`；来源及哈希见 `chicken-hud-source-20260919.json`。
- 小鸡不是原版鸟类改名：独立实体模板、组件、生成蛋方块，不占其他模组的原版蛋编号。原作没有在所提取模型中提供死亡动画；不声称复刻 CS2 布娃娃效果。
- GLB 原始高度约 0.351 格，4492 个顶点、7305 个三角形。三段动作均使用原骨骼。省去零权重且这三段动作未使用的 morph targets，减少引擎创建额外 GPU 纹理；原提取不改。
- 跟随玩家、死亡是否处理及待触发爆炸单独保存。死亡标记和爆炸标记避免二次处理；爆炸拥有独立效果 ID。
- 引擎旧世界加载先填充当前项目模板再叠加保存值，新子系统可获得默认值。未修改枪械 ID、枪械布局版本或注册表格式。
- 本版引入新的生物实体与生成蛋。**含小鸡的存档不能据此承诺可降回不认识它的旧 DLL**；保留既有备份，不自动删除或降级。

## 玩家验收步骤

1. 手机开启“仅开火按钮”，关闭“自定义按钮”。空白处滑动／长按应只看向，不开火；铃兰绑定原版开火键应能开火，松开停止。再关闭“仅开火按钮”，确认全屏开火恢复。
2. 枪放快捷栏和背包，看左下耐久。使用磨损枪与完好枪互换，百分比随物品变化；换成石头后消失。
3. 普通枪装满后看右下图标为绿；打到少于五分之一变红，打空为灰；换弹后恢复。背包增减弹匣、切霰弹枪／电击枪，图标和数量应同步。
4. 创造“CS武器”里拿 CS 小鸡生成蛋，对地面使用。对准小鸡按一次 E／交互后走开，应跟随，再按一次停止；放墙挡住应绕路。保存重进后检查跟随。
5. 两只鸡相邻：刀杀一只只叫，不爆炸；枪杀一只会爆炸，另一只若被炸死不会二次爆炸。隔墙的目标应受墙体保护；保留友伤设置的既有行为。

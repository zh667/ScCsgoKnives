# 0.40.9 — 皮肤枪属性目录

- 原厂属性页左侧保留 35 把原厂枪，追加当前全部 11 款皮肤枪：雷击、永恒之枪、巨龙传说、野荷、火蛇、水栽竹、火神、印花集、二号玩家、渐变之色、金蛇缠绕。
- 列表图标来自该皮肤的已有官方图标资源；列表以两行显示枪名和皮肤名，右侧沿用原厂枪的完整属性卡、预览图、等级预览和配方入口。
- Lv0 为该枪原厂基础伤害的 1.5 倍，Lv10 预览为原厂基础伤害的 3 倍。其它属性同原规则，未新增战斗数值。
- 新的只读 TrySnapshotValue 区分皮肤目录 PaintId、计数器目录编码与实际枪械实例 data，避免把 PaintId 当成某条世界实例 ID。纯浏览不会调用 Materialize、分配 ID 或写记录。
- 从真实皮肤/计数器枪进入时选中对应皮肤条目，显示该物品的实际击杀数和等级。点击该枪原厂条目显示原厂 Lv0；再选回原皮肤会回到原实例，不偷换为原厂，也不改变实际枪。
- 原生帮助目录中的皮肤模板、计数器模板开启属性入口；皮肤属性→装配配方使用原厂型号的制作配方，保留来源物品值，返回查看属性仍能识别皮肤。皮肤需在装配台换肤，未新增“直接合成成品皮肤枪”的配方。

## 关于“显示此按键”

取消勾选后必须点**保存**。ScWeaponTouchPanel 的实际可见条件包含 layout.Enabled，因此对应按钮在游戏中不绘制、不接收输入；编辑器故意保留淡显，以便拖动和重新勾选。左右手布局各存一套，右手布局的修改不覆盖左手布局；取消退出不会应用这次改动。这里没有修改该既有行为。

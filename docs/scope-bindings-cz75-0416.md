# 0.41.6：视野状态、CZ75 前置弹匣、键盘绑定

## 范围与兼容

按 2026-09-09 用户反馈实施。物品布局 v5、枪械记录 schema 3、型号顺序不变；
不改已有枪械的弹量、耐久、充能、计数、等级或伤害。不写入玩家真实世界。
Full / Lite 共用同一 DLL。仓库原有未提交的属性界面三个文件与皮肤规划未纳入本次提交。

## 视野：不是只在设置页退出时补一次恢复

旧代码开镜直接修改 `SettingsManager.ViewAngle` 和 `LookSensitivity`，
游戏在开镜期间保存原版设置时可能存入缩放后的值。旧 Dispose 清空枪械状态表前也没有退出瞄准，
因此切换世界/退出可以失去恢复所需的旧值。设置背景另有重新 Measure/Arrange 实际 GameScreen 的路径，
将设置页 GlobalTransform 放进游戏布局，相机依赖的 ViewWidget 绝对变换也会被影响。
这是源码确认的风险路径，不宣称已在所有玩家设备上重现每一种表现。

本版：

- 开镜不再写全局视野或灵敏度。`RecalculateCameraProjection` 只缩放当前玩家相机投影的 M11/M22，深度投影不变。
- 视角输入在所有输入源采集完成后、ComponentPlayer 消费前按倍率缩小；鼠标、触屏、手柄共用这一步。
- 暂停/菜单/屏幕切换/失去焦点时取消开镜和待自动回镜；切枪、死亡沿已有退出路径处理；Dispose 也清理开镜。
- 设置背景不重新布局或重挂真实 GameScreen，绘制后清除相机投影缓存，保留渲染目标/viewport/scissor 的异常恢复。
- `[CS_SCOPE_0416]` 记录开镜/退镜、设置进入/离开时的原版基础视野与灵敏度。

已经被旧版写入原版 Settings.xml 的值不能可靠倒推成玩家偏好的值。
不自动强设 100%，不重置整个设置文件。设置页显示当前基础视野，并指引玩家到原版图形设置恢复自己的数值；
原版控制设置中的灵敏度同理。新版阻止本模组再次把瞄准倍率保存为全局偏好。

## CZ75

0.41.5 将前置 `magazine2` 的隐藏绑定在 `WPN_RELOAD_ADD_AMMO`（装弹入账），过晚。
原始首次换弹轨迹在这之前就已经把 magazine2 移离安装位，后面还有回到安装位的骨骼轨迹。

本版以首次换弹的官方 `Weapon_CZ.Clipout2` 事件作为取下/隐藏时机，
不再渲染其后的额外飞出、回位轨迹；主弹匣 `magazine` 和双手仍使用原始 CS2 曲线。
后续换弹仍使用原始 reload2 / reload2_empty。没有修改原始 DMX、伪造手部曲线或增加弹药。
此事件是取下弹匣的官方音效时间点，选择它作为模组可见性切换点是本实现的适配，
不是宣称已完整执行 Source 2 动画图。

消耗状态按当前注册表中的枪实例分别记录，同一世界会话内切槽、切枪后拿回不会重生前置弹匣，
另一把 CZ75 不受影响。它仍是临时视觉状态，不增加存档字段；重载/切换世界后重新开始这一视觉周期。
弹匣与手掌的实际观感仍须用新版实机录像复核，离线时序测试不能代替视觉验收。

## 用户本意：键盘绑定，不是触屏按钮列表

入口：原版设置 → CS 枪械 → **键盘绑定（适配触控映射）**，在设置顶部。
手机可直接从滚动列表选键/解除绑定，不要求连接键盘；玲兰触控设置相同键即可。

覆盖开火/轻刀、换弹、开镜、消音器、连发、R8 速射、检视（含投掷物）、重刀、强投、轻投。
旧默认保留 R 换弹、G 检视，其余额外键默认不绑定。原版鼠标及原版游戏操作不被关闭。
兼容映射器真正发送到引擎的 Keyboard/MultiKeyboard 按键；没有反编译/修改第三方触控模组。

- 与模组触屏按钮总开关独立：关闭自带触屏按钮后仍可用映射键。
- 自动作持键连射，半自动通过现有 FireLatch；投掷按下准备、松开投出，菜单/失焦取消。
- 防止被关闭的触屏按钮的 Cancelled 信号取消独立键盘投掷。
- 同时可执行的模组功能拒绝重复键；互斥枪型的不同副功能可以共用一个键。
- 不重新绑定游戏移动、背包等原版键，因此 UI 明确提示避开原版键冲突。
- 设置页固定保存/取消区，按键列表可滚动。编辑在副本上，取消不修改，写盘失败恢复原配置。
- `ScCsgoUi.json` 的版本 1 增加可选 KeyBindings 字典；缺字段旧文件仍沿用默认，沿用已修复的 Android 可写目录和原子保存。

原来的“选择全部武器按键”和可选触屏开火保留，但不再把这两项冒充键盘重绑定。

# CS 武器 1.1.1 全量版：玩家反馈改进

本轮按 `player-feedback-analysis-2026-09-16.md` 实施，资源和逻辑合并在一个 scmod 内。只制作全量版，保留之前的 1.1.0 全量/轻量文件。本轮不写入游戏 Mods，不修改玩家世界。

## 怎么用

- **设置**：模组设置 → CS 武器，直接进入完整编辑器，不再点第二个“打开设置”。改完保存，取消不应用。
- **制作**：枪械台选中配件、枪或刀 → 点“数量”输入 1～100 → 看需要/持有材料 → 点“制作 N 件”。宽屏另有 1/10/100 快捷按钮；手机窄屏用数量输入。材料区域可横向拖动。成功留在本页，材料优先补进已有同类堆叠。枪刀仍需独立格子。维修、涂装、计数器等仍走各自确认流程。
- **触屏开火**：CS 设置 → 手机按键 → “仅开火按钮（关闭为全屏操作）”。下方说明当前实际状态；关闭自定义按钮或隐藏开火键时，沿用原来的全屏操作回退。
- **配件配方**：图鉴选金属坯件等五种配件 → 装配配方。原版及本机 RecipaediaEX DLL 路径均已接通。
- **C4 设时**：持有 C4，电脑默认按 **R**；手机点独立 **“C4 设时”**。输入 **5～300 秒**，默认 20 秒。默认值按本机玩家索引记住；开始安装时冻结该颗时间，改设置不会改地上的炸弹。安装中不能设时。
- **铃兰触控**：在 CS 的键盘绑定页找到“C4 设时”，可保留 R 或改为其他键；铃兰触控按钮发送同一个键即可。即使关闭本模组自定义触屏按钮，键盘映射仍可用。无需新增物品或重做炸弹配方。
- **电击枪**：造成实际伤害、目标存活且有标准移动组件时，眩晕最长 **2.5 秒**；对同一目标至少间隔 **5 秒**，多人也共用该目标间隔，不叠加成永久控制。普通子弹不占用这条电击间隔。
- **掉落物**：小枪、刀、手雷及未安装 C4 更醒目；背包图标、持枪、飞行投掷物和已安装 C4 不随之放大。

## 保存及兼容

枪型/皮肤编号、枪械布局 **v5**、记录 **schema 6** 均未变化。正常“计数并升级”的规则未改；修复旧档 CountOnly 模式 3000 杀/Lv0 被误转为高等级的问题，保留其等级、耐久和弹量。

从正式 1.0.0（schema 4）升级，继续走已有完整世界备份及转换。首次进入会说明备份位置和体积增长原因。新版存档不能靠换回旧 DLL 无损降级；要回 1.0，保留当前世界，用升级前完整世界备份恢复另一份世界，新版期间进度不会自动带回。

C4 保留既有 schema 1，新增可选的音频阶段字段；旧记录无这些字段时推导阶段，避免末段重播完整警报。倒计时使用游戏时间；不按离线现实时间扣时长。瞬时大卡顿跨过爆炸点会立即爆炸，不为补声音延后爆炸。电击临时控制不存档，重进后解除。

批量制作一次先核对整批材料和扣料后的空间，事务失败尝试撤销；容器拒绝退款时沿用世界补偿队列并阻止该持有者继续交易。创造模式只写实际快捷栏，不修改目录槽。库存或模式切换、离台、等级不够时拒绝制作。

## 世界大小只读排查

退出世界后，对原始世界目录运行：

```powershell
./tools/dev.ps1 python tools/world_size_report.py '实际世界目录' > world-size.json
```

也支持 `.scworld`，但导出包可能不含备份。报告分为 backups、project、terrain、other，逐文件列字节数。工具只读，不解压、不删除、不修改世界。

## 验证与边界

使用 API 1.9.3.1 实际 DLL、原版 Content.zip、本机 Mods 中的 Sushi/Logistics/RecipaediaEX/Subnautica DLL，以及正式 `D:\下载\[API1.9]CS武器1.0.0.scmod`。最终结果和包哈希在下方追加。

重点覆盖批量 1/10/37/100、跨堆叠扣料、扣料腾格、成品堆叠、满库存、失败前/后退款、重复操作、创造十格；原生 Widget 多尺寸固定按钮、配件原版/EX 导航、设置返回；C4 5/20/60/300 秒和两轮 XML；绑定与设时序列化；旧 DLL 生成的 35 枪状态矩阵、CountOnly 两轮 XML；实际掉落网格边界；电击控制时长、免伤/死亡、间隔及原生攻击 hook。

新检查同时更新了历史测试中过时的假设：动作总数从 11 到 12；满背包用未满材料堆叠制作可成功；成长通知边界按既有 25 杀，旧的 Zeus 期望值按既有 RulesVersion 7 核算。本轮未重调成长曲线。

尚无本轮安卓/铃兰硬件触控、音频实际试听、多 GPU 掉落观感的实机证据。Subnautica 使用真实组件/原 hook 验证控制与防御边界，不等于加载全部模组跑完战斗。未知模组自己实现的移动、直接伤害、已发射弹丸和独立技能可能继续；不能承诺所有怪物完全停住。玩家所报世界的异常增长仍需对应目录统计。

# 战术同伴拓展 1.1.2

2026-09-20。修复三／五人敌队信标在雪地无法召唤、手动召唤受到人数与距离门槛、CT/T 不主动攻击以及转向冲突。继续配合本体 **1.4.2 全量版**；本轮只更新拓展包。

## 行为变化

- 手动三／五人召唤不再检查 `MaxActive`、原生生物总数、玩家最小距离、自然刷新冷却或世界天数。保留创造模式和 12 格地面交互。按离点击点由近到远搜索最多 8 格范围，整队一次创建；保留承重、身体空间、避水和实体碰撞检查，避免生成在墙里。自然刷新沿用原来的预算。
- **雪地根因**：安装版 `Content.zip/Assets/BlocksData.txt` 的 SnowBlock 是 `IsCollidable=FALSE`。旧代码使用列最高格作为地面，然后强制要求可碰撞，整片积雪因此被拒绝。现在在点击高度附近寻找真正承重方块，跳过非碰撞积雪／草，读取支撑面的实际碰撞高度；照明待更新不再阻止已生成地形上的手动召唤。实体创建错误和落点不足使用不同提示，创建异常保留完整日志。
- 移除救援同伴的创造列表、工作台配方与信标召唤入口。旧信标 data 0 保留为停用品，CT=1、T=2、维修包=3 不重排。旧实体模板、模型、库存加载和装备取回／解散仍保留，避免升级丢失存档中的枪械。
- CT/T 每 0.5 秒搜索身边 24 格内可见敌人：敌对 T、陆地／水中捕食者，以及原生追击组件会攻击主人或同伴的生物。主人实际攻击一个目标会立即通知所属同伴，并覆盖当前目标；自己／主人受击时仍还击。其他玩家、友军同伴和有人骑乘的坐骑排除。未知模组完全自定义的敌意若没有分类或原生追击组件，仍依靠攻击事件识别。
- 不凭空赠送枪械。空手时靠近目标，1.7 格内每 0.8 秒执行一次原生近战，基础威力 6；有枪时消耗真实弹药和耐久，沿用换弹、墙体／身体阻挡和停火。持盾继续防护，不同时攻击。自动追击保持在主人附近，守卫指令不主动离开岗位。
- 移动转向交给原生导航，不再每半秒强写身体旋转；目标未变化时不重复下发寻路。停下后清除残留导航转向，用平滑的原生转向指令面向目标。取消受阻后的随机游走，受阻停下 2 秒再试。以水平距离判断到达，同时容许小幅地形高度差。

- 雪地／普通地面三人和五人整队、贴近玩家、原生人数限额设为 0 且超出敌队限额仍可手动生成、中途创建失败整队回滚。
- 草层、半高碰撞面、屋顶下地面、照明重建状态、低矮天花板拒绝与明确提示。
- 主动选择敌人、墙体阻挡、主人攻击中立目标后的优先协助、空手实际伤害与冷却、停火、原生追击组件模组怪物识别、持枪真实伤害／扣弹。

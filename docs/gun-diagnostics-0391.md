# 0.39.1 枪械诊断日志

用户要求增加日志，以替代难以目测的散布／射程路径核验。此版只增加可关闭的观测，不继续实现属性页、计数器或成长，不修改0.39.0的35枪参数、射线选择、随机取样、命中容差或存档结构。

## 开启与关闭

进入世界时读取游戏应用目录现有 `ScCsgoGunplay.json`：

```json
{
  "Version": 1,
  "Preset": "survival",
  "Diagnostics": "sampled"
}
```

- `sampled`：默认，射击明细最多全世界每0.5秒一条，所有完成开火都计入汇总。
- `summary`：不输出抽样明细，仍统计全部完成开火。
- `off`：不创建诊断射击对象、不计算额外偏角统计、不输出本次新增日志。
- 0.39.0配置没有Diagnostics字段时，内存默认sampled，**不重写旧文件**。已有Preset保持原样。
- 参数在进入世界时读取，修改后重进生效；未知Diagnostics值只关闭诊断，不改变合法Preset。未知配置版本／整体解析失败沿用原配置保护机制。
- 本轮不修改本机实际游戏配置或替换已安装模组，需要安装新包才能开始记录。

## 日志格式与单位

新增记录为 `[GUN_DIAG] {JSON}`，写入现有Game.log，不上传网络、不单建不断增长的文件。只记录本地会话ID、玩家数字索引和世界内枪械实例号，不记录玩家姓名、世界坐标或目标名称。

### session

记录版本、诊断模式、采样间隔、汇总间隔、8 MiB会话字节预算。该预算只针对新增日志，不代表整个Game.log大小限制。

### shot（抽样）

- 枪型、Preset、GunNumbers、会话射击序号、帧号、游戏时间、帧耗时。
- 实际输入是否触控、创造模式、开镜、消音、连发、副模式、水平速度、蹲姿比例、空中／落地状态、瞄准过渡比例、水中／梯子。
- 最终散布半角，拆成姿势基础／移动／空中落地／Bloom分量；Bloom开火前与开火后值。classic不伪造新预设分量，Components为null。
- 实际随机方向相对瞄准方向的偏角min/max/RMS，以度为单位，不再抽随机数生成“测试弹点”。
- 本次实际最大射程、近距总威力、弹量前后、开火后耐久，以及真正施加的上跳／横摆角度。
- 所有弹丸分类：Head、Body、Terrain、RangeEnd。RangeEnd仅指射线到上限没有命中，不代表已证明目标在射程外，也可能只是瞄空。
- 命中的最小／最大距离，完全落空时为null。模型逻辑姿态命中、窄身体回退分别统计。
- 粗候选数量、精确测试次数、精确落空次数、缺少可用模型的回退候选数量，反映实际既有查询分支，不二次发射线。
- submittedPower是按既有伤害公式计算的提交攻击力；observedHealthLoss是攻击前后读到的目标生命差，二者不同。无生命组件不编造扣血。
- traceMs只计地形／身体射线选择区间，**不是整帧耗时或完整开火耗时**。
- 检查实际角度是否超过声明锥角（浮点容许0.003°），命中／终点距离是否超范围，观测弹丸数是否与该枪一致。

### summary（完整窗口统计）

每10秒按本世界枪型输出活动窗口，在世界Dispose时补发尾批；没有新射击的窗口不输出空汇总。最多35个枪型桶，不保存无限明细。

包含窗口内全部已完成成功开火，**不限于已打印的shot样本**：射击次数、弹丸数、头／身体／地形／终点数量、至少一颗几何命中的射击次数、模型回退、开镜／移动／空中／触控等数量、散布范围与均值、实际角度RMS、查询耗时、实际观察到的扣血和致死次数、越界计数。

同一发霰弹有9颗弹丸仍是1次shot、9个pellets；一次致死只反映按目标合并伤害后的观测。日志不在此引入StatTrak计数规则，也不声称这些数值适合作为持久击杀统计。

达到8 MiB预算后输出一次budget_exhausted并停止新增诊断，游戏继续；输出异常也只停止观测，不影响武器事务。突然进程退出可能没有尾批，预算耗尽也会让末批不完整，读取时不能宣称全会话统计齐全。已有CPU skinning、动画等日志不受此预算控制，本版不修改无关日志。

## 能验证与不能验证的内容

能够核验：实际散布值是否切换、开镜过渡与状态是否正确、扫射累积是否增长、停火后再次开枪时是否恢复、落空是否发生、射线范围与几何回退是否异常。

不能单凭日志推导：玩家主观手感、任意目标的真实命中概率、故意瞄空和随机偏离各自比例、目标在射程之外的具体距离。shot明细限频，稀有短暂状态可能未被采样；summary状态数量会保留，但没有把混合状态统计假装成严格实验。该日志不自动判定35枪全部实机验收完成。

玩家只需按正常玩法尝试站立／移动、开镜／不开镜、连射／停火；提供最新Game.log后可直接汇总，不必目测具体角度。

## 验证与交付

新增自动检查：off静默、summary无明细、限频不丢汇总、重复Complete不重复计数、霰弹shot/pellet分离、几何命中不等于扣血、落空距离null、超锥／超距显式检测、字节预算终止、日志接收器失败不抛回游戏、旧配置缺字段默认值，以及全部35枪分量解释与原始Cone公式逐位一致。

Full/Lite使用同一DLL；0.39.0资源文件逐字节保留，仅DLL和modinfo改变。v5／schema 2、原枪数据和0.28.2迁移不变。包检查不能替代本版新增日志的真机输出验收。

```powershell
python tools/summarize_gun_diagnostics.py PATH_TO_GAME_LOG
```

汇总脚本只累计summary，不重复累计抽样shot；它明确标注尾批、预算和目标命中率解释边界。精确包验证结果见 `gun-diagnostics-0391-verification.json`。

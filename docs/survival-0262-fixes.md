# 0.26.2 — 投掷操作与物品栏显示

## 本轮实现

- 投掷物图标绘制倍率从 1.45 调整到 0.8，缩小约 45%，保持完整图片和统一留白。此前离线验证少计了 BlockIconWidget 到屏幕坐标的二倍缩放，本轮修正验证脚本，使用实际栏位变换。
- 打开物品栏/对话框时，枪、刀、投掷物的动画控制器保留当前真实手姿势，不再返回空姿势而触发原版世界模型绘制。菜单中换物品会显示所选型号的真实手待机姿势，关闭菜单后正常切入。
- 按住左键准备强投；按住右键或“轻投”按钮准备近抛。拉环完成后可以一直瞄准，不会因等待过久而自动投出或起爆。松开后才开始投掷动画；提前松开会先完成拉环，再投出。
- 触屏/鼠标的轻投按钮改为按住准备、松开投出，按住期间移出按钮范围仍保持捕获。打开菜单、切换槽位、移动物品或死亡会取消未出手的准备，且不扣物品。
- 世界里的投掷物只在 CS2 出手事件到达时创建，消耗和引信均从此刻开始；不在准备阶段创建倒计时实体。原高爆、闪光、烟雾、燃烧、诱饵效果持续时间及伤害保持不变。
- 投掷动画由准备流程推进，单帧/零时长的 holdHigh/holdLow 不再因“播放结束”而自动切回 idle；拉环→准备→出手不经过拿出/待机动作。取消菜单延迟切刀标记，避免新投掷被延迟 deploy 覆盖。
